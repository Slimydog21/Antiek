# interfaces/creation/

Creation-side outline-plus-tab-completion writing interface.
**Scaffolded, not implemented in this build.**

## What this would be

A writing surface where the operator can:

- Sketch an outline
- Press tab at any point to get a context-aware continuation that pulls
  from the graph, the skill layer, and the relevant archived syntheses
- Cite-as-you-go with full source attribution
