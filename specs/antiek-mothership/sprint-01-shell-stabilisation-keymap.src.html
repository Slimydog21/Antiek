What this sprint is about. Grounding on main 15e78e276 proved four shell defects by running the real modules in jsdom (ground/lane-a-shell-workstations.json). A refuter added a fifth.

  • F1: ⌘K cancels itself, because CommandPalette's own keydown handler and AppShell's PALETTE_TOGGLE both toggle.
  • F2: on fresh storage, AppShell's hydration effect runs after the route's PanelHost starters open (child effects run first) and wipes them.
  • F3: AppShell calls useParams outside the inner <Routes>, so the per-investigation layout key is never used.
  • F4: a nested PanelLayout (AppShell.tsx:151 + PanelHost.tsx:79) renders every docked panel twice.
  • F5: ResearchWorkstation never remounts across /inv/:id, so starters open only once.

F9: the app has no single keymap owner. At least three window-level handlers claim ⌘ combos, and every plain ⌘+letter is already bound. The operator ruled (D2) for a herdr-style prefix (ctrl+b) plus ctrl+alt direct chords. That supersedes the ratified SPR-08 no-leader rule. herdr's own keyboard doc is saved at research/herdr-keyboard-v0.9.1.mdx, and the key table is in DESIGN-MODEL.md §2 and §2a.

Where this sprint sits: Wave 0, the first lane-A sprint. MS-03, MS-04 and MS-05 build on its keymap and its stable shell. It needs nothing from lane B.

Goal

Every shell defect found in grounding is re-proven, fixed and pinned by a test that fails on the base. Every key in the app is dispatched from ONE table that renders its own key sheet.

After this sprint, the operator presses ctrl+b and sees a quiet prefix armed chip. The next key does what herdr's would, and prefix+? shows every binding with a / filter. ⌘K opens the palette from anywhere. A fresh investigation docks its sidebar and chat, once each. Nothing about the product's surfaces changes yet. This sprint gives MS-03 and MS-04 a shell and a keymap they can trust.

ONE keymap table + dispatcher (the prefix engine)

Create src/components/hotkeys/keymap.ts. It is a single typed table of {action, prefixKey?, chord?, scope, origin}, where origin is herdr-default, D2 or legacy-SPR-08. One window-level dispatcher owns every global key.

  • Prefix: default ctrl+b, configurable. It stays armed until the next key or Esc, with no timeout, as in herdr/tmux. A visible "prefix armed" chip shows while it is armed.
  • Chords: the ctrl+alt family, matched on KeyboardEvent.code so macOS option-composition (alt+1 → ¡) can never mis-fire.
  • Migration: every existing binding moves in (⌘K, ⌘J/⌘E/⌘Y/⌘U/⌘O/⌘I doors, ⌘[ ⌘] panel cycle, ⌘W, ⌘⇧P, ? HUD). No other addEventListener('keydown') may claim a global combo.

Acceptance criteria

  • Every legacy binding still works (one test per binding).
  • The focus-scope matrix passes: text input, contenteditable (the Write editor), FloatMenu, a focused WorkspaceWindow (which owns ←/→), an open modal, and the arXiv iframe. Each has its expected behaviour asserted.
  • git grep "addEventListener('keydown'" outside the dispatcher shows only element-scoped handlers. List them in the handoff.

Rigor — operating manual for this sprint

How to execute well. Each value has been adapted to this sprint's specific work.

1 · Intellectual honesty

Calibrate confidence to evidence

F1–F5 were proven by a grounding agent that bundled main's modules with esbuild under jsdom, using another worktree's node_modules. Your base is the design chain, and W3 rewrote AppShell. So re-prove each defect on your base before touching it. If one no longer reproduces, record "fixed upstream by W3 <sha>", never "fixed", and keep the test as a guard.

2 · Fairness

Steelman the rejected alternative

Steelman the rejected option in the handoff. It keeps SPR-08's no-leader rule and puts the mothership on the 22 free ⌘⇧+letter combos that the refuter found (MISS7). That means no mode to learn and one keystroke fewer. D2 still wins: the operator ruled it, herdr muscle memory is the point, and 22 letters cannot address 174 tabs, while a prefix plus the switcher can. Note who pays: the one-handed ⌘ user, now faced with a two-step prefix. That is why every prefix action also has a ctrl+alt chord.

3 · Rigor

Claims are mechanically checkable

Enumerate the focus contexts before writing the dispatcher: text input, contenteditable (tiptap), FloatMenu, a focused WorkspaceWindow, an open LemonModal, and the arXiv iframe (which cannot receive keys). Give each an expected outcome for prefix, chord and plain keys, and assert all of them in one table-driven test. The prefix has no timeout. It is armed until the next key or Esc, as in herdr, so the plan carries no invented millisecond number.

4 · Diligence

Read before writing

Read in full before editing: bindings.ts (including the SAFE_ASSIGNABLE range at :521-535 and the browser-reserved list at :438-462), shortcuts.ts, AppShell.tsx, CommandPalette.tsx, HotkeysHud, WorkspaceWindow.tsx:172-215 (its own ←/→ ownership), and AssignHotkey.tsx (per-entity keys, unreachable today). Then run git grep -n "keydown" apps/reading/src and list every handler you migrate or deliberately leave element-scoped.

5 · Defensibility

Decisions survive turnover

keymap.ts is the only place a binding may be defined. Every row carries its origin (herdr-default, D2 or legacy-SPR-08) and, for D2 rows, a link to docs/decisions/mothership-keys-herdr-prefix.md (milestone 7) and DECISIONS.md D2. A future maintainer asking "why ctrl+alt and not alt?" finds the macOS composition reason in the file itself, not in chat.
