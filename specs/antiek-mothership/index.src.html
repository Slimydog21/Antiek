The Antiek motherships

Research, Writing and Reading, each a herdr-grade shell over the same projects. Branch tabs form an infinitely nested logic tree. Reading is embedded everywhere. A highlight raises a subagent island, and every subagent's process and outcome is kept, addressable, mergeable and forkable.

Goal

What success looks like and how we measure it.

The operator runs his research the way he runs his agents in herdr: many projects open at once, hopped by keyboard, each holding many tabs, with state that survives a closed laptop. Today Antiek organises work by workflow and route, not by project. It has no workstation, no tab, and no way to hold two things open and hop between them (GAPS.md §1).

This spec builds three motherships, Research, Writing and Reading, over one shared set of projects (D1, D5). Inside them:

  • tabs grow as an infinitely nested branch tree, the operator's logic tree (D6);
  • any document can be read in place;
  • a highlight raises an island where a deep-research subagent works on that passage;
  • every subagent run is a durable, addressable thread that can be asked again, merged with others, rendered into a human-facing companion (D3), merged into a document as a fork, and diligenced autonomously on consent (D4).

Success criteria

  • Scale. The operator can hold his herdr-scale load and hop anywhere in two keystrokes: 20 workstations, a 174-tab branch tree, hierarchical numbers like 3.2.1. This is proven by a rendered walkthrough on that fixture, in MS-11.
  • No lost passages. From any passage in any mothership, one keystroke raises an island bound to that passage. Its question, process and outcome survive a reload, and a margin mark on the passage reopens it. No path navigates away and loses the passage.
  • Ask a thread again. Any earlier subagent thread in a document or project can be picked and asked a follow-up that carries its held context. Two or more threads can be merged with their conflicts shown.
  • Findings get a home. Every workstation has a Companion tab, and every evidence document a companion rail. Merging an insight into a writing document produces a fork with lineage and a per-hunk diff to accept; the original is never touched.
  • Craft. An independent re-score of the frontend-craft rubric reaches at least 42/48 (87.5%) with no critical-failure veto; the baseline is 24/48. Every new surface ships every state in both themes at 1280 and 390, and the entry chunk stays under its 700 KB gz budget.

Failure mode to avoid

A fourth parallel substitute. This means building a new document model, a new thread store, a new layout system or a second keymap beside the ones already on main. Most of what the motherships need exists but is disconnected (GAPS §1). The work is to connect and to finish, under one chassis. It is not to invent. The CEO directive's P0 clause says the same: "avoid parallel substitutes for the reader, research artifact, or merge contracts". Every sprint's diligence card enforces it.

Architecture overview

Only what is load-bearing for the sprints. The full model is in DESIGN-MODEL.md and the lane contract in THREAD-CONTRACT.md.

account ├─ attention inbox ................. thread done · needs you · flag consent · cap reached · merge suggestion (D4) └─ workstations (= projects, shared by all three motherships; lane B registry, edges not copies) └─ workstation W ├─ Research mothership ─┐ ├─ Writing mothership ─┼─ each keeps its own FOREST of branch tabs for W (D6) └─ Reading mothership ─┘ tab 1 (root: a reader, research, document, companion, thread or flags surface) ├─ tab 1.1 (opened from a footnote / reference / citation / island / research in tab 1) │ └─ tab 1.1.1 … unbounded depth └─ tab 1.2 pane: main surface + at most ONE docked pane (reader beside a doc · companion rail · thread) thread = an investigation (lane B). Branch edges live in the PARENT's event log (provenance). tab = navigation state, server-side per account. Pruning a tab never deletes a branch. island = a thread created on its first question, anchored by a text-quote locator; kept/promoted = presentation. keys = ONE keymap table → dispatcher + key sheet (prefix+?) + aria-keyshortcuts. herdr prefix ctrl+b and ctrl+alt chords (D2); tree panel prefix+t / ctrl+alt+y.

Key invariants

  • One of everything. There is one keymap owner, one document door (openDocument), one Island primitive and one thread identity (the investigation). New surfaces extend existing stores (WorkspaceStore, windowsStore, RegionStore). They never sit beside them.
  • Tab ≠ branch. Tabs are navigation state, and branches are provenance, written to the parent's log before the child starts. Closing or pruning UI never deletes evidence.
  • No invented facts. An unknown is never drawn as a zero or an empty list; this is the rubric veto W7 closed on five pages. Every surface designs loading, empty, error, partial, refused and offline.
  • No spend without sight and consent. Every island and autonomous run shows its model and estimate before it spends. Autonomous diligence needs per-flag consent and respects the user's daily cap, reserved before spend (D4).
  • Budget. The entry chunk stays under 700 KB gz. New surfaces are lazy; the pattern is proven in W7.
  • Merging. Merges go only through Antiek Nudge's train. Lane A never edits lane B's in-flight files (DECISIONS.md, lane split).

Glossary

Terms of art. If a sprint instance would have to guess one, it's here.

TermDefinition
MothershipOne of three shells: Research, Writing or Reading. It is a mode of work, not a container of data. Switching mothership keeps the workstation.
WorkstationA project, shared by all three motherships. Lane B owns the registry; membership is edges, not copies.
Tab / branch treeA navigation node. Children are opened from a passage (footnote, reference, citation, island, research), at unbounded depth, addressed by hierarchical number (3.2.1).
Branch (provenance)The parent → child investigation edge plus its origin. It is written to the parent's event log before the child starts, and is independent of tabs.
ThreadA subagent run. It is an investigation, identified by thread_id = the investigation id.
IslandA thread created on its first question and anchored to a passage. It can be kept (as a margin mark), promoted (to a tab) or merged.
CompanionThe human-facing derived account of subagent findings, as a project tab and a per-document rail (D3). It is distinct from lane B's agent-facing evidence base.
ForkA new version of a writing document created by a merge-into-document, with lineage and a per-hunk diff. The original is untouched.
FlagOne entity with intent read or diligence and an actor (user or agent). Diligence runs only after per-flag consent, within the daily cap.
Prefixherdr's leader key, ctrl+b by default and configurable. prefix+x means press ctrl+b, release, then press x.
Design chainThe unmerged branches W1 (tokens), W3 (shell, states, prose), W5 (motion), W7 (crashes and vetoes), plus W2, W6 and W4 still in build. Lane A stacks on them.
