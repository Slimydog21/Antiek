The frontend is apps/reading: React 18, react-router 6, Vite, Tailwind with the W1 semantic tokens, Lemon UI primitives in src/components/lemon, and Zustand stores (for example src/workspace/WorkspaceStore.ts). Run these from apps/reading (npm --prefix <wt>/apps/reading …):

Rigor — operating manual for this sprint

How to execute well. Each value has been adapted to this sprint's specific work.

1 · Intellectual honesty

Calibrate confidence to evidence

W3 was finished by a standalone builder after its workflow step died on the session limit. Its gate (2506/2506) was re-run by the orchestrator, but its critic loop never ran. Say so in W3's PR body, and do not present it as "critic-accepted" until a critic has actually run on 0d68b6213 or later.

2 · Fairness

Steelman the rejected alternative

Steelman landing W1+W3 first, since they are the foundation W7 builds on, and they merge cleanly with each other. It loses because W3 alone leaves 60 B of headroom. Any small change in between would redden the required tsc job, while W7 first frees about 2.2 KB. Record who pays for W7-first. W1 and W3 wait behind it in the train. W7 lands on a base without the tokens it was designed beside. Any conflict it creates is resolved on the W1/W3 re-merge, not on W7.

3 · Rigor

Claims are mechanically checkable

The W7 → W1 → W3 → W5 order is a claim about bytes, so check it at each step. After each landing, rebase every remaining wave on the new main and record the entry headroom build:check prints. Expected: about +2.2 KB after W7, then W1's cost (~0.9 KB), then W3 falling toward its 60 B. Assert that W1+W3 together still fit after W7, and that W5 fits after W3. Any negative is a stop, never a budget raise. W2/W6/W4 are this sprint's other milestone: each needs its critic verdict and pushed SHA quoted, and W6 needs its injected dark-only regression shown caught.

4 · Diligence

Read before writing

Before queuing, read each wave's .lane/PR_BODY.md and its NOT MEASURED section. Check with git merge-tree that each still merges cleanly with current main, because main moved twice overnight.

5 · Defensibility

Decisions survive turnover

The order and the headroom arithmetic go into each PR body, so the train's owner, or anyone later, can see why W7 went first.
