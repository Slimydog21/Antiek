Goal

One function, openDocument(id,{where: child_tab|pane|window, at: locator}), is the only way anything in the app opens a document, and it never navigates away from the workstation.

Every door routes through it: citations, claims, source cards, notebook blocks, DocumentsIndex, Library, ⌘K and DRW evidence. In Research and Writing the reader docks as the pane beside the main surface, so the operator reads while he writes. Opening at a citation lands on that passage without moving the book's saved position.

Rigor — operating manual for this sprint

How to execute well. Each value has been adapted to this sprint's specific work.

1 · Intellectual honesty

Calibrate confidence to evidence

origin/snapshot/2026-09-21/detached/antiek-rebase-preflight was stranded by a rebase. Its openDocument resolver and rich Reader.tsx may depend on APIs that have since changed on main. Every ported file gets a ledger line in the handoff: ported as is, adapted (how), or dropped (why), each citing the main SHA it was diffed against. Do not present a salvage as new work, or new work as a salvage.

2 · Fairness

Steelman the rejected alternative

Steelman writing a fresh openDocument. The code would be smaller and would fit the new tab model, without archaeology. It loses to the P0 clause ("avoid parallel substitutes for the reader") and to the Unified Reader spec's already-reviewed design. Who pays: this sprint's builder pays the porting time once. MS-06 to MS-09, which all call openDocument(id,{where,at}), inherit any quirks of the adapted API. The operator gets no new reading capability this sprint beyond the door itself.

3 · Rigor

Claims are mechanically checkable

The door inventory is mechanical. Use git grep -E (no \b: POSIX ERE silently ignores it) for navigate(`/read/, navigate('/read/, <Link to=…/read/, href="/read/, every openWindow('reader', every window.open of a document, and every route to /wrestle from DocumentsIndex or the Read tab (RE-05, MISS9). Record the origin/main counts as the "before" number and the after list in the handoff. A door the grep missed still navigates away.

4 · Diligence

Read before writing

Before porting, run git diff origin/main...origin/snapshot/2026-09-21/detached/antiek-rebase-preflight on the Reader and openDocument files. Read antiek-reader's planned resolver contract, and openWindow.ts (the window policy and out-of-contract pages). Also read usePosition.ts:14,18,53 (the shared sessionStorage key behind MISS6 and the R4 clobber that M4 fixes) and readingFocus.ts (the MISS3 global bus).

5 · Defensibility

Decisions survive turnover

openDocument's options (where, at) are the contract every later sprint calls. Document each option's default and the reason at the definition. A guard test enforces "never navigate away". It matches the same patterns as the inventory, allows zero occurrences outside openDocument, and is proven live by adding one mutant call and watching it fail. Record the where/at defaults in DECISIONS.md so later sprints can rely on them.
