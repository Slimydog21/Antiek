All products

Five workspaces do the work. Everything else is here or in ⌘K — kept out of your way until you need it.

Why this layout

Antiek had grown to 33 sibling modes in a flat namespace. Only 11 fit the old rail; the rest were reachable only by URL. That is the feature overload.

The fix is PostHog's 2025 cure, in Antiek's skin

PostHog stopped navigating tools in a flat list. Instead: navigate content in a project tree, pin a few shortcuts, push everything else into a products overlay + command palette. We adopt the pattern; sun-yellow edge, chunky shadow, Werner, and Charter-serif prose are unchanged (§5.6: pattern transfers, tone does not).

Before — 33 flat modes
  • One sibling route per feature
  • Rail shows 11, hides 22
  • Nav by tool; content has no home
  • No way to pin or group
After — 3 honest layers
  • Products (verbs): 5 pinned + overlay
  • Content (nouns): the project tree
  • Settings / governance: demoted, ⌘K-reachable
  • Pin / reorder / search everything

Each scene is now shaped to its workflow

Beyond the shell: every surface carries a contextual action bar (the verbs that workflow uses), in-scene tabs where one object has several views (a Research investigation is Synthesis · Trajectory · Sources · Notebook), and a context-aware Max whose opening turn knows what you are looking at.
