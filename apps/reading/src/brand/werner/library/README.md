## Pixel contract

The prompt required an empty limestone-and-walnut polar archive with no mascot, people, animals, books, paper, screens, controls, text, logos, or semantic product state. The asset supplies atmosphere only. Titles, rights, loading, errors, actions, and shelf contents remain accessible HTML driven by authoritative product data.

It is rendered only on the full-page Library as a decorative, pointer-inert sibling beneath `GlassSurface`. Workspace windows retain their own glass and do not render this environment.
