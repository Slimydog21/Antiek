# compounding/extraction/

Post-research distillation. After a research cycle, extracts the
durable insights from the investigation and prepares them for Phase 8
merge into the relevant domain skill.

## Input

The full event log slice for an investigation plus the archived
synthesis.

## Output

A structured "skill update proposal": which sections of which domain
skill to append/edit, with citations back into the investigation's
events.

## Discipline

Distillation is conservative by default. The proposal is what *could*
be added; the Phase 8 merge decides what *does* get added, gated by
content quality heuristics and (eventually) human review for
high-stakes additions.
