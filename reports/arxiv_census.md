## Reproducing query

| field | value |
| --- | --- |
| metadataPrefix | `arXiv` |
| date window (from .. until) | `2024-01-01 .. 2024-01-31` |

The license is read from arXiv's own per-paper `<license>` element via OAI-PMH — the only interface that carries it. It is NOT taken from OpenAlex (which has no such element and is null exactly for the preprints this measures). See the packet's fairness note.
