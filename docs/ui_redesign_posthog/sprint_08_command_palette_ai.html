1 · Goal

Two things: (1) a universal Cmd+K command palette that drives every panel-system action (open panel, dock, float, popout, close, switch route, recent investigations) — Linear/PostHog-style; (2) the AISidecar becomes a Max-style ubiquitous chat that lives as a workspace panel the operator can dock-right, float, or popout from any route. Plus the full keyboard-shortcut map.

2 · Why this sprint exists

After S5/S6/S7, the operator has powerful panels but limited ways to invoke actions on them. The kebab menu works but is mouse-heavy. The palette is the keyboard surface for everything the panel system can do. AISidecar as a docked panel matches the operator's mental model ("ask my agent anywhere") and was Wedge 4 of the prior PostHog spec (integration_posthog.md §8).

3 · Non-goals

  • No new AI capabilities. AISidecar consumes the existing AI hook; this sprint only re-shells it.
  • No "fuzzy memory" search across investigations in the palette. Palette searches the static action list + open panels + recent items; full-text is S10 stretch.
  • No voice / mascot character for the AI. Per integration_posthog.md §2.5, Antiek does not copy PostHog's "Max" personality.

4.2 · AI sidecar as a panel

Current AISidecar.tsx is a floating div. After S8: PanelKind = "AISidecar", default mode docked-right, default width 360 px, pinned. The operator can drag it to floating, pop it out, or close it; Cmd+/ toggles its visibility.

WP-8.1

Command palette rebuild on LemonModal

File: src/components/CommandPalette.tsx Effort: 1.0 d

Rebuild on LemonModal size="md" with a LemonInput + grouped results. Search algorithm: case-insensitive substring match with simple ranking (exact prefix → full match → contains). No external fuse.js dependency — <30 LoC matcher is enough at this scale. 

type CommandAction = {
  id: string;
  group: "Actions" | "Recent" | "Panels open" | "Routes";
  label: string;
  hint?: string;             // right-side hint, e.g. "G then I"
  perform: () => void;
};

export function CommandPalette() {
  const open = useCommandPaletteOpen();    // tiny zustand store
  const actions = useCommandActions();     // see WP-8.2
  const [query, setQuery] = useState("");
  const results = useMemo(() => rankCommands(actions, query), [actions, query]);
  // …keyboard nav: ↑ ↓ Enter Esc
  return open
    ? (
      <LemonModal open onClose={closePalette} size="md" title="Command palette">
        <LemonInput value={query} onChange={...} iconLeft={...} autoFocus />
        <CommandList results={results} />
      </LemonModal>
    )
    : null;
}
WP-8.2

Command-action registry

File: src/components/commandActions.ts Effort: 0.8 d

A composable hook useCommandActions() that aggregates:

  • Static actions: all route-switches, panel-system actions, "New investigation", "New notebook", etc.
  • Open panels: derived from useWorkspace; each open panel exposes its actions (dock-left, dock-right, float, popout, close, pin).
  • Recent items: last 10 investigations + 10 documents + 5 notebooks (from existing hooks).
export function useCommandActions(): CommandAction[] {
  const navigate = useNavigate();
  const ws = useWorkspace();
  const recents = useRecents();
  return useMemo(() => [
    // routes
    { id: "go-research",   group: "Routes", label: "Go to Research",   perform: () => navigate("/") },
    { id: "go-wrestle",    group: "Routes", label: "Go to Wrestle",    perform: () => navigate("/wrestle") },
    // … one entry per top-level route

    // panels (static actions)
    { id: "open-aisidecar", group: "Actions",
      label: "Open AI sidecar",
      perform: () => ws.open("AISidecar", {}, { mode: "docked-right" }) },
    { id: "open-projecttree", group: "Actions",
      label: "Open Project tree",
      perform: () => ws.open("ProjectTree", {}, { mode: "docked-left" }) },
    // …

    // open panels — dynamically generated per current workspace
    ...Object.values(ws.panels).flatMap(p => [
      { id: `${p.id}.dock-l`, group: "Panels open",
        label: `${p.title} → Dock left`,
        perform: () => ws.setMode(p.id, "docked-left") },
      { id: `${p.id}.dock-r`, group: "Panels open",
        label: `${p.title} → Dock right`,
        perform: () => ws.setMode(p.id, "docked-right") },
      { id: `${p.id}.float`,  group: "Panels open",
        label: `${p.title} → Float`,
        perform: () => ws.setMode(p.id, "floating") },
      { id: `${p.id}.popout`, group: "Panels open",
        label: `${p.title} → Pop out`,
        perform: () => ws.setMode(p.id, "popout") },
      { id: `${p.id}.close`,  group: "Panels open",
        label: `${p.title} → Close`,
        perform: () => ws.close(p.id) },
    ]),

    // recents
    ...recents.investigations.map(inv => ({
      id: `recent-inv-${inv.id}`,
      group: "Recent" as const,
      label: `Investigation: ${inv.title}`,
      perform: () => navigate(`/inv/${inv.id}`),
    })),
    // …
  ], [navigate, ws, recents]);
}

WP-8.4

AISidecar → panel

File: src/components/AISidecar.tsx Effort: 0.7 d

Current shape: a fixed-position absolutely-positioned div toggled by a top-bar button. After: a regular renderer registered as PanelKind = "AISidecar". Default starter for every route: { kind: "AISidecar", mode: "docked-right", title: "AI" } but only if the operator opted in (default off; toggle via Cmd+/).

The chat surface inherits the workspace's focusedPanelId: when the AI asks "open this PDF", it dispatches a workspace open("PdfViewer", {documentId, page}, {mode:"floating"}) action. The AI is now first-class panel-system citizen, not an overlay.

6 · Acceptance criteria

  • Cmd+K opens the palette; ↑/↓/Enter/Esc work; clicking outside closes.
  • Palette searches static actions + open panels + recents; ranks reasonably.
  • Every panel-system action (dock-l/r, float, popout, close) is invokable from the palette.
  • Cmd+/ opens AISidecar docked-right (if closed) or focuses it (if already open).
  • Cmd+B toggles ProjectTree.
  • Chord shortcuts G+I, G+W, G+N navigate correctly with the 800 ms window; ignoring nonsense follow-ups.
  • Every panel header kebab + Topbar search shows the relevant kbd hint.
  • No new dependencies (no fuse.js, no cmdk, no mousetrap).
  • Bundle delta: ≤ 8 KB gzipped.
  • Strict TS clean.

7 · Risks & mitigations

  • Chord shortcuts conflict with text input. Mitigation: shortcut handler ignores events when the active element is an <input>, <textarea>, or has [contenteditable].
  • Palette grows too long with many open panels. Mitigation: "Panels open" group caps at 12 actions; rest accessible via scroll.
  • Operator hits Cmd+W and closes the browser tab instead of a panel. Mitigation: Cmd+W only intercepts when a workspace panel has explicit focus state; otherwise default browser behaviour passes through. Or — safer default — skip Cmd+W and rely on the kebab close + Esc.
  • Cmd+/ conflicts with Find on some non-Mac browsers (Cmd+/ is unbound on most). Mitigation: Linux/Win use Ctrl+/ default; Mac uses Cmd+/. Documented.

8 · Open questions

  1. Should the palette have an "Ask AI" mode toggle? I.e., press Tab inside the input → palette switches to AI-prompt mode. Default: no in S8; explore in a later sprint.
  2. Default AISidecar location: docked-right or floating? Default: docked-right (matches PostHog's Max).
  3. Should there be a "?" shortcut that opens a cheat-sheet of all shortcuts? Default: yes — a static page rendered via LemonModal; small effort.

9 · Verification protocol

  1. Hit Cmd+K from each route; verify palette opens; type "wrestle" → "Go to Wrestle" highlighted; Enter navigates.
  2. Open three panels; Cmd+K → type panel title → choose "Dock right"; verify panel moves.
  3. Cmd+/ from /; AISidecar appears docked-right. Cmd+/ again; it closes. Cmd+/ again; reopens with same content.
  4. G then I within 800 ms → /investigations. G alone, wait → no nav.
  5. Inside ChatInputArea, hit Cmd+K → palette opens, Chat input does not capture the keystroke.

10 · Rollback plan

Each WP is independent. WP-8.4 (AISidecar → panel) can revert to the pre-S8 floating-div implementation without affecting the palette. WP-8.1 + WP-8.2 (palette) is a self-contained rewrite of an existing component; rollback restores the pre-S8 CommandPalette.
