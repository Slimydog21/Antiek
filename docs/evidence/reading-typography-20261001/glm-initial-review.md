Cross-tab updates, storage clearing, corruption, blocked writes, remount restoration, and reset behavior are tested.

The CSS keeps prose, interface type, and monospace distinct. `rem` sizing respects browser base text size; `ch` width is correctly described as zero-glyph width rather than literal character count.

The new regressions exercise stale overlay geometry when glyph metrics move inside an unchanged root box. I found no stale-measurement path in the reviewed implementation.

The supplied full frontend result, type checking, build budgets, and security scan were not rerun here and are accepted as parent-provided context.

I found no promotional overclaim.
