# Decision: normalize source framing at the canonical Werner seam

The deterministic motion sheet exposed a source-asset mismatch rather than an
animation bug. Alpha measurement shows the lost pose at 1.4% canvas coverage;
idle, thinking, and celebrate occupy 24.3–32.5%. Rendering all four with the
same `object-contain` rule therefore makes empty Werner illegibly tiny.

The existing lost raster remains the canonical art. Only the `empty` mood gets
a clipped viewport and a 4.6× center crop aligned to the subject's measured
center. The four-mood API, asset provenance, other mood geometry, reaction
timing, and reduced-motion behavior do not change.
