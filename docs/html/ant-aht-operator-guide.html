AI-agent-friendly HTML in Antiek

This page is the operator-facing form-factor spec for the Thariq thesis: HTML as the efficient transport layer between agents and humans. DuckDB + the typed event log remain canonical; HTML is how you read, share, merge, and hand off work across context windows.

Form factor (machine + human)

Every deep research export is one self-contained file:

  • Human channel — findings, gaps, synthesis excerpt, agent-notes UI (add note + copy JSON).
  • Machine channel — <script type="application/json" id="antiek-artifact-v1"> with schema v1 body + content_hash.
  • Audit — artifact.generated on export; per-note import emits deduped research_artifact_agent_note_v1: intents.
graph (insights/questions) → distill → ResearchArtifactBody → render HTML → ~/.antiek/research-artifacts/
ingest URL → chunks + mandatory canonical HTML projection or non-viewable receipt
merge investigations → compose-*.html index (hash conflicts surfaced)
Write (partial) → GET /research/{id}/artifact/blocks → ArtifactOutlineShelf in DistillView
