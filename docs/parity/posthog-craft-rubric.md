# PostHog craft rubric — four dimensions, 0–3 anchored, every anchor cited

**Sprint:** ALC SPR-03 · **Rubric version:** pinned to PostHog SHA `9c06e96956f68b6cd67e39e30df8ff736e1fcaad`
**Companion docs:** `docs/parity/posthog-reading-log.md` (the read), `tools/parity/AUDITOR.md` (how to grade).

This rubric is written so a **COLD second agent can grade from it without the author's context**. Every grade level is COUNTABLE (a thing you count or observe, never "feels polished"). Every level-3 cell — and every level-2 cell where PostHog's tree exhibits the bar — cites ≥1 pinned PostHog file as `path@SHA`. Levels 0 and 1 are **absence anchors** (what failing looks like); they are correctly marked `n/a` for PostHog citation because the pinned PostHog tree exhibits neither failure mode, and citing it for a failure would be dishonest. Their countability lives in the **Antiek-side counts** the grader performs.

All `@SHA` below = `@9c06e96956f68b6cd67e39e30df8ff736e1fcaad`. Antiek pointers are `file:line` in `apps/reading/` on the tree being graded; line numbers are baseline-2026-06 spot-checks — the grader re-resolves on the live tree.

---

## How to use this rubric

1. Pick a surface in scope (see `AUDITOR.md` § surfaces): scene layers, shell controls, Werner, reading-mode states, and the FALLBACK/procedural floor.
2. For each of the four dimensions, count the things the level criteria name, on that surface, citing Antiek `file:line`.
3. Award the highest level whose criterion is fully met. If the level-3 bar is met but for a single named, justified exception, award 2-with-exception and name it.
4. Record every grade with its evidence. No uncited grades.

## What this rubric does NOT measure

This rubric is deliberately silent on these — grading them would breach the firewall or the dimension scope:

- **Voice / microcopy flavor.** Whether Antiek's words "sound like" PostHog. Antiek voice is its own §5 discipline; PostHog's conversational-irreverent tone is a standing REJECT (§16.1). Character grades *intentionality of state coverage*, never tonal register.
- **Brand / identity.** Colors-as-brand, logo, typography-as-identity, naming. Antiek's ice/glacial palette and Werner mascot are Antiek's own; nothing here rewards resemblance to PostHog's brand.
- **Hedgehog-equivalents.** Mascot presence/absence/charm. Werner is in scope only as a *motion/state surface to grade for craft*, never compared to the hedgehog.
- **Feature breadth.** Number of features, products, integrations, acquisition adapters. The spec scopes this harness to the living-background experience + its shell surfaces (SPR-05..08 terrain), not Research/Write/Speak feature parity. "PostHog has 25+ destinations" is explicitly a REJECTed parity target (§16.1).
- **Absolute counts across library-vs-app.** Raw story/test/snapshot totals are not comparable between PostHog's primitive LIBRARY and Antiek's APP surfaces — this rubric uses per-component discipline + ratios.
