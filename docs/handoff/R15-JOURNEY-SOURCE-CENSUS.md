## Security and denominator gates

The executable MCP stdio server initializes real handlers in `tools/antiek_memory/__main__.py:375–391`; HTTP serves only its manifest, and repository deployment does not establish a live client registration. `ANTIEK_MEMORY_OWNER` is a process-launch environment binding, not signed or OAuth identity proof; the server only compares a client claim with that configured owner. The binding is applied to `search_personal`, but `resources/read` passes only a client URI to the resource handler (`server.py:198–212`). Committed subprocess tests bound to `testuser` retrieve an `__operator__` private note (`tests/tools/test_antiek_memory_e2e.py:269–301`) and `search_public` returns `__operator__` chunks (`:376–395`); these are local cross-owner disclosures, not live-production observations. `cite_source` (`__main__.py:201–239`) also lacks an owner/rights filter and can disclose private document title, author and IDs by chunk ID. `record_attribution` (`:242–280`) accepts client-supplied chunk/investigation IDs and writes an audit row without owner authorization, leaving cross-account mutation denial unproved. `antiek://books/{isbn}/{chunk_id}` selects chunk body without an entitlement, ISBN-match or source-rights check in `__main__.py:335–360`; a body exploit was not exercised in the inspected tests. All these paths need fail-closed repairs and actual-subprocess denials before MCP can count toward R15.

Connected tools/imports are an additional producer beyond the ten journey rows; the source/owner/rights census must inventory each registered import normalization and memory publication path, including a source-backed nonparticipation decision where appropriate. For each J01–J10 row and connected-import path, the implementation owner must join the actual route/tool to owner and project identity, source revision and rights, a later-session positive, a wrong-authority or stale-source negative, an inspectable serialized provider request where relevant, and a different-lineage review. A journey with no eligible memory edge needs a source-backed nonparticipation decision that also proves no accidental private read/write. Neither a code search nor this checkpoint closes a slot.
