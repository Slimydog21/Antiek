Derived Companion Offline Evidence Briefing

Status: Cycle 67 executable spec. Provider-free, deterministic, owner-scoped.

Objective

Turn an admitted derived-revision evidence pack into an immediately useful reading brief while model execution remains unavailable. The brief organizes retrieved passages; it does not summarize, infer, answer, rank truth, or manufacture claims.

Artifact contract

  1. Bind the exact question, derived asset, revision, content hash, generation, and evidence-pack digest.
  2. Group citations by their existing section path in first-seen order. Preserve citation order and exact excerpt text inside each group.
  3. Expose counts for sections and passages plus stable citation IDs, anchors, paths, chunk ordinals, and text hashes.
  4. Render canonical escaped HTML using only the bound question, section labels, and exact excerpts. No raw HTML from evidence may execute.
  5. Compute independent JSON, HTML, and artifact SHA-256 digests. Rebuilding the same pack must be byte-identical.
  6. Reject malformed packs, digest mismatch, duplicate citation IDs, missing scope, oversized output, and citations outside the exact pack.

API and UI

prepare_evidence and saved conversation turns return a public briefing only for evidence_ready. The reading rail presents the question, section groups, exact excerpts, open-section action, and follow-citation action. The existing provider qualification status remains visible. A model answer, when later admitted, remains a distinct artifact above the briefing.

Non-authority

  • No model, provider, SDK, credential, network, spend, reservation, dispatch, or adapter registration.
  • No claim of summary, answer, support, contradiction, completeness, or relevance beyond the existing deterministic retrieval result.
  • No write back into canonical revision content, twin notes, knowledge graph, or merge drafts.
  • No client-side rendering of server HTML; React renders typed fields as text.

Acceptance

  • Artifact unit tests cover determinism, grouping, escaping, malformed packs, duplicate citations, digest drift, and byte limits.
  • Repository/API tests prove replay equality, saved-turn reconstruction, owner isolation, and insufficient-evidence omission.
  • Frontend tests prove immediate and saved briefing rendering, citation actions, no server-HTML injection, and no wording that implies model synthesis.
  • Backend tests, frontend tests, strict typing, Ruff, frontend typecheck, production build, visual inspection, diff check, and HardenX pass.
