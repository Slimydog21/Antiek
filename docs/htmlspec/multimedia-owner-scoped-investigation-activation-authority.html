Cycle 27: Owner-scoped investigation activation authority

Status: executable specification. Base: Cycle 26 head 578aac4277b40e748540bd10681f272f114034d8.

Outcome

An authenticated owner may explicitly approve one immutable mpi_ prepared-investigation snapshot for later activation. The receipt binds the exact prepared integrity digest, route policy, server-resolved provider and model, dispatch-config provenance, quote provenance, a positive integer-cent hard ceiling, issuance time, and expiry.

This cycle records authority only. It never consumes authority, starts execution, emits events, writes graph state, calls a provider, reserves or debits money, or creates background work.

Five load-bearing values

  1. Owner privacy: every lookup and uniqueness boundary includes the authenticated owner digest; cross-owner absence is indistinguishable from missing data.
  2. Exact binding: authorization targets one persisted prepared snapshot and repeats its integrity digest, source plan identity/version, intent/evidence digests, and tree counts.
  3. Server authority: callers select only a closed route policy and ceiling. Provider, model, tier, pricing, quote ID, config digest, and quote expiry come from a server resolver.
  4. Money honesty: cents are exact positive integers. Unknown, zero, stale, or malformed pricing fails closed. Approval ceiling must cover the conservative quoted ceiling.
  5. Non-execution: receipt fields explicitly prove false/null execution, event, graph, provider, spend-reservation, consumption, and background-work state.

Domain contract

InvestigationActivationQuote is an immutable server result containing: schema version; route policy (cheapest|balanced|highest_quality); resolved tier; provider; model; 64-hex dispatch-config digest; pricing source; pricing digest; workload digest; positive quoted ceiling cents; quote ID; issued-at; and expires-at. Canonical JSON determines its quote digest. Expiry is UTC, later than issuance, and no more than 24 hours.

InvestigationActivationAuthorization contains an opaque mia_ ID, owner-hidden prepared bindings, quote fields/digest, approved ceiling cents, the persisted requested ttl_seconds, request digest, issued/expiry timestamps, state authorized, and explicit negative authority fields. Actual expiry is exactly the earlier of the requested TTL horizon and quote expiry. Its integrity digest covers the complete canonical record.

Request identity is (owner_digest, investigation_id, idempotency_key, route_policy, approved_ceiling_cents, ttl_seconds). Exact replay returns byte-equivalent authority with 200; first creation returns 201. Reusing an idempotency key with different terms is 409. Only one activation authorization may exist per owner and prepared investigation; a second key is 409.

Storage and migration

Migrate the private research-plan SQLite ledger from schema v3 to v4. Add multimedia_investigation_activation_authorizations with explicit scalar binding columns, canonical authorization JSON, authorization integrity digest, owner-scoped idempotency uniqueness, owner-scoped investigation uniqueness, and a foreign key to the prepared investigation. Migration is additive and transactional. Schema SQL and exact column order remain fail-closed invariants.

Reads re-decode canonical JSON, validate the complete dataclass shape and timestamps, recompute request/quote/authorization digests, compare every scalar column, and re-read the referenced prepared row to prove its integrity still matches. Historical expired records remain readable and report is_expired; no mutable status transition is written.

Private API

  • POST /multimedia/investigations/{investigation_id}/activation-authorizations: body has strict idempotency_key, closed route_policy, strict positive approved_ceiling_cents, and strict ttl_seconds (60..86400). Resolve the owner first, fetch and verify prepared state, request a server quote, then atomically persist.
  • GET /multimedia/investigations/{investigation_id}/activation-authorization: owner-private read of the immutable record.

All responses use Cache-Control: private, no-store. Missing or foreign resources return the same 404 investigation is unavailable. Validation is 422; stale/unknown quote, ceiling shortfall, duplicate authorization, replay mismatch, or integrity conflict is 409; authority storage/resolver failure is value-free 500/503. Responses never expose owner digests or internal idempotency keys.

The production resolver maps cheapest to flash, balanced to pro, and highest quality to synthesis. It parses the server-owned dispatch configuration, assumes one full uncached context/output call per tree node plus one per leaf, uses exact Decimal arithmetic with upward cent rounding, and binds the config, pricing, and workload digests. The current zero price placeholders are unknown rather than free and therefore return a value-free unavailable response until the operator supplies verified positive prices.

  3. Tests assert no dispatch registry call, provider call, event emission, graph mutation, budget-ledger table, reservation, debit, task, thread, or process is created.
