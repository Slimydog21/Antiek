Authored transition palettes

Make dawn and dusk visibly intentional through six named roles, without disturbing day/night or scene geometry.

Wave 1 Status: executing Budget: 6 milestones Owner: MiMo workhorse, Codex last mile

Parent context

PR #2097 activates bounded dawn and dusk semantics but ProceduralSky.tsx groups dawn/day and dusk/night for every color role. Only deterministic ridge seeds differ. The externally held living-caliber sprint requires every matrix cell to look distinct.

The intended correction is atmospheric, not structural: dawn is cold glacial air with a narrow weathered-straw horizon; dusk is deep slate/indigo with a restrained desaturated teal afterglow. The generated diptych guides hue and restraint only.

Position: stacked directly on exact PR #2097 head 90c0102ab33ef0fe122936df5f66842750b4b45c.

Goal

Ship four unique, deterministic, tokenized landscape tuples.

Preserve today’s exact day and night gradient/ridge classes in meaning and pixels. Add static dawn/dusk roles that can coexist in one DOM regardless of OS theme.

Rigor — operating manual

1 · Intellectual honesty

Pixels outrank labels

If the six tuples differ in code but dawn/day or dusk/night still look alike at any fixed viewport, report failure. Do not call token uniqueness visual distinctness.

2 · Fairness

Protect the reading user

Steelman the current restrained binary ramp: it is quiet and legible. The transition palette earns its complexity only if it stays low-chroma and keeps captions/ridges readable.

3 · Rigor

Pin old and new claims

Tests must prove unique six-role tuples, unchanged day/night roles, no raw component colors, deterministic rerenders, and fixed-viewport pixels. Snapshot churn alone is not proof.

4 · Diligence

Respect three token mirrors

Read and update tokens.ts, tokens.css, Tailwind, and parity tooling as one contract. Do not create a fourth palette in the existing canvas weather resolver.

5 · Defensibility

Preserve the reversal path

Record exact values, generated-image provenance, rejected aliases, and what visual evidence would justify retuning. A future maintainer must not need this chat to reconstruct the choice.
