Semantic Scholar corpus CLI

Status: implemented as an operator-reachable child of durable cache PR #792.

Commands

  • enrich ID... --yes: one explicitly authorized live request through the governed S2 client; success is printed only after durable publication.
  • search QUERY: offline ranked JSON hits from the reopened cache.
  • fetch PAPER_ID: offline JSON content and provenance, or exit 6 for a typed miss.

Safety

The API key is accepted only as S2_API_KEY, never as a command-line value. Live enrichment refuses without --yes, batches are bounded and unique, provider failures print no upstream body, and search/fetch construct no HTTP client. Cache and contract failures are machine-readable with stable nonzero exits.
