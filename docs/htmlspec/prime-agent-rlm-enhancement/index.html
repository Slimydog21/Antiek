Prime Agent additive RLM enhancement

Give every Antiek RLM workflow an optional bounded Prime Agent evidence lane while existing Hermes/callable execution remains canonical.

Spec lineage

Root spec; no child specs. Protocol, integration and closure are the complete decomposition.

    Success and invariants

    • One backend invokes prime-agent -p with bounded time, bytes, tools, cwd and provenance.
    • REPL, DAG, tool batch, long-corpus and iterative investigation can request supplemental evidence without changing default output.
    • Ordinary failure, timeout, malformed output or absence preserves canonical execution and yields an explicit receipt. Operator or task cancellation kills the child and propagates immediately.
    • Prime is never dispatch, RemoteExec replacement, graph writer or training authority.

    Failure to avoid: silently replacing the canonical answer, unbounded children, or access to personal state.

    Architecture

    existing callable/Hermes → canonical result
request + opt-in → PrimeBackend → supplemental evidence + receipt
canonical result + labeled evidence → existing synthesis boundary
