SPR-01 · Protocol and policy

Wave 1 · inline · 5 milestones

Context and goal

Build one bounded opt-in backend returning supplemental evidence plus an execution receipt, and record the narrow superseding §16 decision.

Milestones

  1. Immutable request, evidence, receipt and outcome types.
  2. Stdin prompt transport with prompt/output limits, fixed caller cwd, sanitized environment, disabled context discovery and no tools.
  3. Typed disabled, unavailable, timeout, failed, malformed and success states.
  4. Environment factory defaulting disabled.
  5. §16 amendment: additive RLM only; no dispatch, RemoteExec replacement, DB writes or training.

Five-values rigor

Honesty: launched is not success; receipts distinguish every terminal state. Fairness: preserve Prime's useful tool role while applying least privilege. Rigor: test argv, env, bytes, timeout and child cleanup on propagated cancellation. Diligence: bind flags to current CLI help. Defensibility: authority limits appear in policy and tests.

Dependencies, out of scope, gates, handoff

Optional installed Prime CLI. Out: workflows, UI, production enablement, credentials and hosted RL.
