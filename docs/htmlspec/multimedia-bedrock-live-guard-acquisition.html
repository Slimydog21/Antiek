Cycle 35 / Cycle 36

Bedrock live guard acquisition

Acquire Cycle 35 evidence through credentialless injected boundaries, observe revocation last, and recover crashes without replaying stale authority.

Status: executableRead onlyProduction refused

Spec lineage

Cycle 35 validates caller-supplied canonical evidence. Cycle 36 defines how that evidence is fetched and journaled. It owns no AWS credentials, signer keys, policy mutation, production route, or background scheduler.

  • A future child may bind deployed workload-identity credentials and external attestor infrastructure only after this read-only protocol is exercised against independent accounts and audited failure injection.

Verdict

Recovery re-observes; it never replays truth. One immutable command may have append-only attempts keyed by command digest, trusted observation time, and an explicit 128-bit caller nonce. A retry uses a new nonce or later second, reacquires Organizations evidence, obtains a signed attempt-bound attestation, reruns Cycle 35, and authenticates a final revocation observation.

Threat model

  • Detect substituted command, account topology, policy identity, API request, API response, attestation request, predecessor, attempt, verifier, revocation source, clock, or completed receipt.
  • Reject ambient client construction, mutating API methods, incomplete pagination, noncanonical mappings, read drift during qualification, stale replay, revoked custody, future/stale revocation watermarks, and journal conflicts.
  • Assume injected Organizations and external custody adapters may fail, equivocate, or return malformed values. Treat every exception and shape conflict as a closed attempt.
  • Do not claim that a point-in-time final observation constrains the management account, service-linked roles, AWS, or future policy state.

Contracts

ContractExact semantics
CommandCanonical immutable intent binds command ID, Cycle 34 receipt digest, organization/management/member IDs, SCP/RCP IDs, optional predecessor receipt digest, and requested maximum revocation lag. The passed Cycle 34 receipt and predecessor must match these digests.
AttemptThe attempt ID is derived from the command digest, canonical trusted start, and explicit 128-bit nonce. The journal records intent before external reads and appends a completed result only after all checks. Same-ID conflicts fail; an incomplete attempt grants no authority. The completed result embeds the exact validated Cycle 35 receipt and revocation times so a restart can reconstruct renewal authority without an ambient cache.
Organizations adapterAn injected read-only protocol exposes only DescribePolicy and ListTargetsForPolicy. Requests are exact. Responses are copied into JSON-native bounded mappings, duplicate-free canonicalized, and passed to Cycle 35. Pagination must terminate in the single accepted response; any token fails rather than hiding additional targets.
Custody adapterAn injected external service receives exact command and attempt JSON plus snapshot, Cycle 34, and predecessor digests and an idempotency key equal to the attempt ID. The returned canonical Cycle 35 attestation includes the SHA-256 of that complete request in its signed identity. No local signer exists.
RevocationAfter Cycle 35 qualification and a second exact Organizations read, an injected revocation source returns canonical evidence binding attempt, attestation, Cycle 35 receipt, audit source, observation time, and completeness watermark. An independent verifier returns the exact evidence digest and approved authority identities. Revoked, stale, future, malformed, or unapproved evidence fails.

Protocol

  1. Validate the command, nonce, and exact Cycle 34/predecessor bindings; read canonical trusted start and derive attempt ID.
  2. Record immutable command and attempt intent before external reads. Existing exact intent is recoverable; any conflicting bytes fail.
  3. Fetch SCP and RCP DescribePolicy and ListTargetsForPolicy using exact IDs. Build the Cycle 35 snapshot with trusted start.
  4. Request an externally issued attestation using exact command/attempt bytes and evidence digests; require its signed acquisition-context digest.
  5. Run the injected Cycle 35 qualifier. It independently authenticates custody, Cycle 34 authority, audit freshness, renewal continuity, and trusted time.
  6. Fetch both policies and targets again. Every observed semantic byte except observation time must equal the initial snapshot. Byte drift fails, but equal reads do not claim exclusion of unobserved mixed-epoch or ABA changes because Organizations exposes no consistency token.
  7. After the final reads, read trusted time, request and independently authenticate revocation evidence bound to the final snapshot, and require its watermark not to regress behind Cycle 35. Revoked must be exactly false.
  8. Recheck revocation and custody freshness at completion. Append the receipt, reopen exact canonical bytes, cross-bind its embedded Cycle 35 evidence, then read trusted time and recheck both freshness windows again before return. A lost commit acknowledgment is reconciled by exact readback; absent or conflicting bytes fail.

Acceptance

  1. Exact fake adapters deterministically produce one canonical acquisition receipt and append-only completed attempt.
  2. Every request is exact; wrong policy ID, pagination token, response type, extra/missing target, malformed canonical JSON, or observed byte drift fails before completion.
  3. Attestation context substitution, wrong idempotency key, predecessor mismatch, Cycle 35 failure, revoked state, wrong revocation verifier/source, regressed/stale/future watermark, or clock regression fails.
  4. Crash recovery may reuse immutable intent but reacquires evidence. A later trusted second or distinct nonce derives a different attempt and never returns the prior receipt as current.
  5. Journal command/attempt/result conflicts fail closed; incomplete attempts cannot be opened as completed receipts. A write-then-error succeeds only if exact readback proves the durable receipt.
  6. The receipt fixes read-only acquisition true and management constraint, prospective unrevocability, production eligibility, Bedrock version selection, and Bedrock read observation false.
  7. No boto/client factory, credentials, token source, policy mutation, signer, KMS/HSM, scheduler, worker, route, spend, settlement, release, event, graph write, or UI is added.

Five Values

  • Truth: a completed attempt proves bounded observations, not future persistence.
  • Care: revocation and audit are independently authenticated and checked last.
  • Agency: operators inject clients, verifier authorities, clock, and durable journal.
  • Craft: exact requests, canonical evidence, two reads, append-only attempts, and adversarial replay tests make behavior hard to vary.
  • Restraint: credential acquisition and every production authority remain absent.

Out of scope

No deployed IAM role, STS exchange, Organizations credential, attestor implementation, signer key, audit consumer, policy change, daemon, production route, provider dispatch, exhaustion, settlement, release, event, graph mutation, or UI.

Harness hint

Implement strict dataclasses, injected read-only protocols, an append-only journal protocol, and one coordinator. Fake adapters record every call. Fault injection covers each boundary, before/after drift, journal replay/conflict, revocation, clocks, and all false capability claims. Require two sharpen rounds and HardenX.
