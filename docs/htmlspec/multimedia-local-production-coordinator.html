Compose cheapest-local production without weakening authority

Executable child spec of the cheapest local production master. The coordinator turns already trusted local chapter WAVs and explicitly attested graph-grounded source cards into Antiek's existing canonical narration, visual packet, Ken Burns render, educational receipt, verified playback, and exact-revision production link. It never calls a provider, reads provider credentials, estimates media duration, invents evidence, or falls back to a paid lane.

Five values

  • Truth: every phase reopens its upstream bytes and authority before committing completion.
  • Ownership: owner, asset, revision, plan, chapter, scene, and graph snapshot identities are cross-bound.
  • Economy: reported and settled cost is exactly USD 0.000000; provider and network seams are absent, not mocked successes.
  • Recovery: durable leases distinguish not-started, producing, succeeded, and unknown outcomes; unknown external execution requires explicit recovery.
  • Reuse: canonical narration production, educational video production, receipt issuance, verified playback, and revision registration remain the sole downstream authorities.

Frozen input snapshot

A MAC-protected run binds the authenticated owner, asset and current revision, canonical plan digest, ordered spoken chapters, ordered timeline scenes, local TTS artifact IDs and output digests, local source-card IDs and output digests, explicit diagram attestation digests, executable/config identities, output roots, and all integrity-key identities. The coordinator rejects foreign ownership, stale revisions, missing/extra/reordered chapters or scenes, mismatched durations, unreviewed cards, and any changed file, database row, font, executable, or request.

Phase machine

  1. snapshot: validate current ready video asset and freeze all identities.
  2. narration: reopen each local TTS artifact; adapt it to exact ChapterAudio, GeneratedFile, and private path inputs; call canonical produce_narration_track; reopen the resulting manifest.
  3. visuals: reopen each source card, verify explicit owner diagram evidence, and compile the existing visual selection packet in timeline order.
  4. render: call existing educational video production and reopen its narration, packet, MP4, captions, and render manifest.
  5. receipt: call canonical educational receipt issuance and reopen from its private file.
  6. verify: require verified playback metadata and bounded reads of both video and audio.
  7. register: re-read the owner asset, require the exact revision still current and ready, then call canonical production registration once.

Each phase records started and completed authority separately. Pure reopen phases may converge automatically. A phase that may have executed FFmpeg or another external executable cannot be retried from an ambiguous producing state until explicit recovery proves and adopts the exact deterministic output or removes a verified incomplete private bundle.

Concurrency and crash contract

One durable run ID is derived from the frozen input. A filesystem write coordinator serializes row transitions. Leases are bounded and MAC-protected but expiry never implies an external action did not occur. Concurrent exact requests converge on one run and one receipt; conflicting requests fail. Crash injection is required before and after every phase effect and phase commit.

Security boundary

All subprocesses use fixed argv and pinned approved executables; all media is private, regular, same-UID, bounded, non-symlinked, non-aliased, digest-verified, and descriptor-read. No shell, URL, DNS, HTTP client, inherited provider key, remote font/image, arbitrary markup, or browser-authored authority is accepted. Error responses contain opaque IDs and states only.

Acceptance matrix

  • A real macOS fixture uses /usr/bin/say plus approved FFmpeg/ffprobe to produce decodable PCM WAV, captions, and MP4.
  • Exact replay performs no second speech synthesis or render and returns byte-identical authorities.
  • Injected crashes at every boundary either reopen exact output or enter explicit recovery; no optimistic retry exists.
  • Owner, revision, plan, chapter, scene, duration, evidence, executable, DB, file, path, mode, digest, MAC, and registration tamper fail closed.
  • A network-deny harness and provider-call spies prove zero network/provider calls, credentials, authorization, reservations, and spend.
  • The receipt opens through VerifiedPlaybackRuntime; audio/video byte ranges verify; registration attaches only that receipt to the still-current owner revision.
  • The current generic cheapest production rejection remains unchanged until this end-to-end matrix, broad multimedia suite, lint, HTML parse, visual playback inspection, independent review, and HardenX strict gate are green.
