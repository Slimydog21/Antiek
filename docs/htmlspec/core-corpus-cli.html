CORE scholarly metadata → durable offline corpus

One explicitly confirmed, key-bearing search uses the existing CORE connector against its fixed official v3 endpoint. It records metadata and abstracts only. Provider availability and declared full-text licenses are preserved as evidence but never promoted into blanket serving authority.

Runtime contract

  • sync-search QUERY --yes requires ANTIEK_CORE_API_KEY, permits 1–100 records, one 20-second request, no redirects, and at most a 10 MiB response.
  • Validated records publish atomically to a private, schema-bound, digest-verified SQLite authority before success is emitted.
  • search and fetch reopen that authority without network access. Fetch provenance is source_terms_governed_metadata.
  • Provider bodies, exception strings, and API keys never appear in operator output.

Non-goals

No PDF/full-text fetch, servability inference, pagination daemon, arbitrary URL, application route, frontend, event, graph mutation, merge, deploy, or live CI request.
