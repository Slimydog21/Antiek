Multimedia Distillation Recovery

TW executable sub-spec. Complete PR #1049's at-most-once model protocol with an explicit owner recovery path for uncertain outcomes.

State Contract

StateMeaningRecovery
not_startedNo claim or checkpoint exists for this owner-bound source revision.Use normal finalization.
in_progressA durable claim exists without a checkpoint. The model may still be running or its outcome may be uncertain.Denied until the claim is at least 15 minutes old.
completedAn exact owner/source/hash checkpoint exists.Denied; normal replay uses the checkpoint.
integrity_conflictA checkpoint exists but its payload, digest, owner/source identity, or completed claim authority does not verify.With both acknowledgements, a recoverable completed claim quarantines the corrupt checkpoint and rotates authority for regeneration.

Recovery Authority

  1. The authenticated owner pins the current reserved asset revision.
  2. The owner acknowledges both model use and the possibility of duplicate model spend.
  3. The canonical writer verifies the claim is in progress, identity-exact, and stale.
  4. One transaction rotates the secret claim token and refreshes its start time.
  5. Finalization immediately runs with that token. Any prior worker carrying the old token cannot publish.

Fail-Closed Rules

Foreign owner, missing acknowledgement, fresh claim, valid completed checkpoint, absent claim, stale revision, irreconcilable checkpoint/claim identity, old token, concurrent recovery, or unavailable runtime returns no model output and writes no link. A digest-corrupt checkpoint is never reported as completed.

Acceptance

Tests prove read-only status, the 15-minute threshold, zero automatic retry calls, one explicitly authorized recovery call, old-token rejection, completed-state denial, owner opacity, route behavior, revision reservation preservation, and exact checkpoint/claim identity verification.

Non-Goals

No automatic retry, background timeout worker, paid media provider execution, model routing redesign, frontend redesign, publication, merge, or deploy.
