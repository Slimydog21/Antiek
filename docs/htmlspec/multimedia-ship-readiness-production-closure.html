MSR-02: Production Receipt Cost Closure

Parent program

Goal

Bind the registered production bytes to the exact paid authority closure: selected generated-visual executions from the reviewed visual registry and narration-child executions from the MAC-verified sealed narration run whose artifact matches the final receipt.

Requirements

  • Reopen and verify final playback receipt and current production link before cost projection.
  • Generated visuals contribute only their retained execution IDs; sourced/archival/diagram rows contribute no provider execution and retain their separate evidence authorities.
  • Match the receipt narration artifact to exactly one sealed parent narration run; verify its MAC and complete authorization set before admitting child revisions.
  • Reject zero or multiple matching runs, missing selected candidates, stale production links, bad receipt bytes, incomplete execution closure, and any unsettled constituent.
  • Define whether non-selected and failed attempts are reported separately as total revision spend, while the production closure reports only byte-contributing spend. Never merge the two labels.

Non-goals

No provider call, no settlement, no route mutation, no marginal-cost quality optimization, and no public publishing.
