Chapter TTS Seal Lease

Status: executable sub-spec. Parents: multimedia TTS reconciliation and reconciliation operations.

Outcome

Distinguish an active local audio seal from a crashed seal using durable signed time authority, so an operator can recover stale work without racing a live encoder or invoking a provider again.

State Contract

  • One MAC-bound lease record contains execution identity, immutable generation ID, canonical UTC acquisition time, active/released/sealed state, and canonical resolution time.
  • Lease acquisition and attempt transition from received to sealing commit in one transaction.
  • Normal failure resolves the lease as released with the attempt restored to received in one transaction.
  • Successful publication resolves the lease as sealed with the attempt and artifact receipt in one transaction.
  • Worker completion/failure and operator release are conditioned on the exact immutable lease generation, so an old worker cannot resolve a replacement lease.
  • Normalized audio and narration publication paths are lease-scoped. A rejected obsolete generation removes only its own files and cannot overwrite or delete replacement output.
  • Operator release requires a valid active lease, configured minimum age, valid private raw bytes, generation-bound signed recovery authority, and execution ownership.
  • Fresh, future-dated, tampered, resolved, missing, and legacy lease states fail closed. Migration never fabricates acquisition time.

Read Model

The operator projection exposes only seal age, eligibility, action, and safe error code. It does not expose lease MACs, raw paths, signing keys, audio bytes, or provider credentials.

Acceptance

  1. A process crash after lease acquisition leaves a verifiable active lease.
  2. A fresh lease cannot be released; the same lease becomes eligible after the threshold.
  3. Tampering, missing legacy evidence, invalid raw audio, wrong ownership, and replay fail before unsafe mutation.
  4. Release permits narration resume without another provider callback or budget mutation.
  5. Focused and full multimedia tests, Ruff, strict mypy, HTML parse, security gate, and independent review pass.
