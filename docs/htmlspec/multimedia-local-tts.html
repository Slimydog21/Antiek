Produce playable zero-network narration

First child of the cheapest local production master spec. This boundary replaces no paid path and does not unlock cheapest production by itself.

Contract

LocalTTSAdapter accepts only canonical cheapest PreparedChapterTTSRequest rows addressed to local_executable_tts/macos-say-v1. Runtime supplies absolute speech and probe executables, private output directory, voice, words per minute, audio shape, timeout, database, and independent signing key. Unknown voices or unsafe configuration fail at startup.

Execution

Text is written to a private file and passed via say -f; it is never command text. The process uses fixed argv, shell=False, no stdin, bounded timeout, and a minimal environment without provider credentials. It writes PCM 16-bit WAV. Output is made mode 0600, validated as RIFF/WAVE, decoded by the pinned ffprobe, and checked for exact sample rate, channels, positive measured duration, byte ceiling, owner, link count, and digest.

Authority and replay

The adapter hashes resolved executable bytes and canonical configuration. A MAC-protected DuckDB row records deterministic request identity, body/config/executable/probe digests, producing or succeeded state, private pending/final paths, WAV digest, measured duration, audio shape, and creation time. Exact success reopens bytes and rechecks executables. Producing state raises outcome-unknown; explicit recovery may finalize a valid pending or already-renamed WAV without invoking speech again.

Forbidden

No FakeTTSProvider, audio/fake-pcm, text-length duration estimate, paid authorization, budget hold, gateway, provider credential, network fallback, shell command, implicit retry, output overwrite, or cheapest policy change.

Acceptance

  • Real macOS fixture produces private decodable PCM WAV with positive measured duration.
  • Exact replay invokes no synthesis and returns identical receipt.
  • Command-like narration remains inert text.
  • Timeout with valid bytes requires explicit recovery and no second invocation.
  • Executable/config drift, voice absence, malformed request, DB/file tamper, unsafe path/mode/symlink, invalid WAV, wrong audio shape, timeout, and nonzero exit fail closed.
  • Focused and broad multimedia tests, Ruff, HTML parse, HardenX, and heterogeneous review pass.
