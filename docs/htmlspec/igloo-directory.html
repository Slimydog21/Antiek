Problem and truth boundary

The current page says it lists every surface, but its 20 entries omit live product doors, include retired redirect paths, and describe the reading loop as PDF-based. A manually curated page cannot honestly certify router completeness.

Invariant: this is a human field guide, not a route manifest, availability monitor, permission oracle, dependency graph, or product-completion claim.

Information architecture

Make and investigate

Canonical daily doors for research, deep research, evidence intake, reading, notes, writing, speaking, and multimedia.

Review and steward

Canonical doors for calibration, substrate cardinality, privacy, trust, settings, billing, payouts, coordination, and operator review.

Specialist rooms

Secondary but intentional doors for creation, federation, citation, skill-rule, biography, replay-adjacent, and experimental governance work.

Do not advertise redirect aliases (/investigations, /interviews), parameter-only deep links, unauthenticated token routes, panel implementation routes, or Storybook.

Visual contract

  • Use one ChatGPT Image polar directory-hall raster as a decorative img with empty alt text, aria-hidden, no pointer events, and no semantic hot regions.
  • Central content is ordinary HTML links. Image generation never owns navigation, labels, route claims, focus order, or availability.
  • Day and night themes use repository tokens and opaque-enough veils; cards retain readable contrast over the image.
  • At narrow widths the masthead and cards collapse to one column without horizontal scrolling. Reduced motion removes card translation.

Five values

Intellectual honesty

Call the page a curated directory. Never infer route health, access, or completeness from a static link list.

Fairness

Keep specialist and governance work discoverable without letting operator plumbing dominate daily research doors.

Rigor

Test positive canonical destinations and negative redirect/parameter routes; a screenshot alone cannot prove route truth.

Diligence

Reconcile labels against App.tsx, command palette, and workflow taxonomy before writing the directory.

Defensibility

Record generated-asset provenance and rejected alternatives so future agents can reconstruct why the image remains decorative.

Rejected alternatives

Alternative Why rejected
Auto-parse App.tsx A brittle source parser would confuse aliases, parameter routes, public routes, and implementation plumbing with intentional human doors.
Clickable image regions Hotspots would make navigation crop-dependent, inaccessible, and model-authored. The user’s Flipbook inspiration does not justify surrendering route truth.
Node-edge product map The directory does not possess dependency or knowledge-graph evidence; edges would fabricate relationships.
Keep the generic registry and only reskin it That preserves false completeness and stale PDF language.

Harness hint
