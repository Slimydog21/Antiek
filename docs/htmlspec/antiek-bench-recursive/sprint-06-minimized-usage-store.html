SPR-06 — Minimized usage telemetry store

← master

Antiek-bench owns evaluation telemetry, not a second copy of the user’s research corpus.

Contract

  1. Never persist prompt_hint, goals, selections, passages, URLs, rationale, or unknown caller fields.
  2. Persist a closed versioned schema: task, outcome, source, model, week, body-state, prompt-present flag, opaque source reference, and accepted reviewed seed only.
  3. Rejected reviewed seeds persist only a rejection flag, never rejected text.
  4. Return the same minimized row to API callers so write responses cannot echo private text.
  5. Retain at most the versioned event limit; persist cumulative eviction count and expose it in Settings.
  6. Knowledge-graph/source systems retain the actual asset and may provide an opaque reference; benchmark code never dereferences it.
  7. File-backed appends serialize across worker processes and replace the store atomically.
  8. Reading a legacy row eagerly rewrites it through the closed schema so private text does not remain at rest.

Acceptance

  • Raw Midnight Oil goals, highlights, marketplace titles, secrets, and arbitrary extra fields are absent from memory/file stores and API JSON.
  • Safe reviewed benchmark seeds remain available to Sprint 5 proposal generation.
  • Limit+1 writes evict exactly the oldest event; restart preserves eviction count.
  • Malformed task/outcome/model/week/source references fail before write.
  • Concurrent process writes retain every admitted event, and legacy read migration removes raw prompt text from disk.

Non-goals

No deletion of knowledge assets, no benchmark dereference into the graph, and no retention policy for other Antiek stores.
