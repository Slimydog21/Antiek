Canonical Multimedia Graph and Twin Registration

TU executable sub-spec. Multimedia HTML enters Antiek's canonical graph and recursive note substrate without creating a parallel knowledge authority.

Authority Composition

  1. insert_document, insert_chunk, insert_node, and insert_edge remain canonical graph writers.
  2. run_document_pass and the existing insight/question promoters remain the note deposit path.
  3. Private nodes carry a nullable owner_user_id. Shared legacy nodes remain NULL-owned; private nodes require an exact accessing owner even under a privileged policy tag.
  4. The source and twin are owner-scoped personal_reading HTML documents.

Replay Contract

BoundaryRule
SourceDeterministic document, chunk, and entity IDs. Existing rows must match all authoritative fields.
DistillationThe first typed output is canonically serialized and hash-pinned in multimedia_twin_runs before promotion. Retries read it and never invoke the model again.
Graph depositNodes and edges commit atomically with graph events suppressed. Post-commit reconciliation emits missing typed events and verifies they are readable from the append-only trajectory.
TwinDeterministic script-free HTML binds owner digest, source digest, asset revision, and exact deposited node IDs. Existing rows must retain private classification.

Threat Gates

Wrong owner, cross-owner node access, malformed HTML or citations, conflicting rows or checkpoints, partial provenance, missing committed rows, missing post-commit events, non-inert HTML, and nondeterministic retry output fail closed.

Acceptance

Tests must prove public and foreign-owner search/traversal cannot resolve private nodes, matching-owner access succeeds, a failed twin write reuses the checkpoint, an event append failure is visible and recoverable, and replay converges without additional model calls.

Non-Goals

No live provider request, spend, publication, frontend redesign, merge, or deploy. Cross-store atomicity is not claimed; committed-row event reconciliation is the explicit recovery protocol.
