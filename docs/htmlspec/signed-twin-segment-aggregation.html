Signed Segment Completion and Parent Aggregation

Status: transport-free completion authority. It verifies externally signed work and never signs, dispatches, reserves, or spends.

Contract

  • Each segment receipt binds tenant, manifest, parent source, exact index/range/content hash, proposal hash, model, budget authority, expiry, and authority signature.
  • Current canonical source bytes and the Cycle 106 registry are reverified; commitments alone cannot authorize completion.
  • Exact replay returns the existing binding without signature-expiry revalidation or repeat work. Any changed completion conflicts.
  • The aggregate receipt binds the complete ordered segment-binding digest. Missing, duplicated, reordered, or substituted segments refuse aggregation.
  • One immutable parent binding materializes a canonical advisory ResearchArtifactBody with synthesis withheld. It is not graph-grounded evidence.
  • Source bodies remain only in canonical document storage. Completion ledgers retain proposals, signed claims, hashes, and the derived parent body.
  • This authority does not alter canonical coverage. A later projection sprint must verify the parent binding before removing requires_segmentation.

Failure Matrix
