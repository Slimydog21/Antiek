Chase a passage without leaving the page

A highlight opens an independent, bounded research window over the book. The reader, companion, page position, evidence, and spending authority remain intact.

Parent: Source SpineOne sprintWindow-native

Five values

ValueInvariant
Professional researchSeveral questions may remain visible beside the source; each keeps its own context.
AuthorityOpening a window never starts or spends. Only Follow this launches research.
Evidence custodyServability and outbound-text checks remain upstream. The host displays honest document/page context and never invents a chunk anchor.
ReversibilityClose, expand, restore, focus, and open-in-main use the existing window lifecycle. Reading position is not replaced.
Bounded craftDesktop windows cascade; narrow viewports open full. The existing eight-window cap remains authoritative.

Execution contract

  1. Register a purpose-built readingChase window renderer; never host the dock-owning Research Workstation.
  2. Replace Reading's inline chase state with a multi-instance spawn helper. IDs are opaque, unique per raw highlight, and stable only when a reserved child ID exists.
  3. The window carries passage, parent reading thread, document title, and one-based page. It renders source context plus the existing ChaseThread.
  4. Add an optional host callback to ChaseThread so “open in main view” closes the exact workspace window; existing panel behavior remains the default.
  5. Always retain ReadingCompanion. Selection collapse closes the menu, not the book context.

Acceptance and harness hints

  • [data-reading-chase-window] identifies the glass-native content; the outer host remains an accessible dialog.
  • Two eligible highlights create two descriptors with distinct IDs and correct payloads.
  • At <1024px the descriptor is full; at wider sizes it is a bounded floating window.
  • Opening does not call startInvestigation. Restricted/taken-down material cannot open a chase.
  • The companion and current page remain rendered after spawn.
  • Open-in-main navigates to the child and closes only its host.
  • Focused unit tests, TypeScript, token/type lint, Storybook a11y, and independent adversarial review pass.

Future child: merge research into source

Deliberately unexecuted here. A future spec must define an immutable target revision, preview/diff draft, claim-level source links, rights re-check, conflict and supersession rules, explicit user commit, rollback, and a single writer. No button may claim “merge” until that authority exists.

Open questions and rejected alternatives

Assumption: the current session-only, eight-window cap is acceptable; cap disclosure remains existing shell behavior. Persisted arrangements are future work. Rejected: nested Research Workstation (double dock), inline replacement (loses parallel context), auto-launch (spend without approval), invented passage anchors, and decorative generative imagery inside a professional evidence surface.
