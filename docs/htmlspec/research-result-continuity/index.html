Research result continuity

Werner’s arrival broadcast must lead into the exact selected research organism—and back to the exact origin—without inventing another result or twin surface.

Spec lineage

Root spec. Predecessor: Werner research-arrival broadcast.

  • No child spec: one owning concern, one implementation sprint.

Problem, proven in code

ResearchWaitArcade sends an investigation ID to Monitor, but the callback only focuses an inert terminal card. The existing header action opens the first completed investigation, not the selected one. The organism Canvas already owns the authoritative insight/question surface plus honest loading, retryable error, and empty states.

Werner broadcast → exact ID + current terminal truth → done: organism Canvas
                                                  ↘ no result: exact status card
organism Back → exact originating card/action → monitor heading fallback

Decisions

One resolver. Broadcast and terminal-card entry share current authoritative session lookup. Unknown, missing, or nonterminal identities fail closed.
One result surface. Successful research opens the existing Canvas; block detail remains the bridge into evidence and follow-on research.
State-honest language. Success says “View result” or “View this result.” Failure, stop, and budget halt say “View details” and remain on their status card.
Origin-aware focus. Result state stores the return target. Back restores it after the monitor DOM commits, then falls back to the monitor heading.

Rejected alternatives

Second result viewer: duplicates Canvas truth and creates two interpretations of one investigation.
Always focus the card: safe but product-inert for success.
Always open Canvas: lies for failed, stopped, and budget-halted work.
Merge the divergent twin rail now: this stack lacks its shared twin substrate and its branch diverged hundreds of unrelated commits ago. Preserve one future session rail; do not smuggle that campaign into this seam.
Generate new art: this is continuity, not a missing visual asset. Existing Werner broadcast art is the exact semantic fit.
