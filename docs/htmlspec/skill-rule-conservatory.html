Skill Rule Conservatory

Turn canonical /skill-rules into a privacy-literate archive of practices that cleared cross-user promotion. Generated glasshouse art establishes atmosphere only; native HTML owns every rule, label, count, filter, and privacy measurement.

Goal and catastrophic failure

Goal: let a researcher inspect recurring practices and their promotion metadata without exposing source content or overstating what confidence, contributor count, or ε mean.

Catastrophic failure: confidence reads as calibrated probability; ε reads as quality; current-query counts read as substrate totals; empty filtered results read as no rules exist; private contributor material appears recoverable; artwork conveys authoritative measurements.

Five-values acceptance

  1. Truth: every potentially misleading metric carries its epistemic boundary.
  2. Legibility: rule text and IDs wrap; provenance uses lists and definition lists.
  3. Agency: filters apply explicitly and clear explicitly.
  4. Restraint: one decorative environment, canonical Werner moods, no gauges or verdict theater.
  5. Continuity: API and routes remain unchanged; pure view supports deterministic stories.

Proof and non-goals

Required: deterministic stories for promoted, two empty meanings, loading, error, unknown metadata, narrow, and night; behavior tests for epistemic copy, query counts, provenance, filters, states, fallbacks; TypeScript, production and Storybook builds; tagged axe/overflow/visual gates; security and merge review.

Non-goals: accumulator/promotion math, confidence semantics, privacy-budget policy, API/schema/query changes, rule detail redesign, Antiek-bench scoring, recommendation routing, contributor identity, global navigation, or graph writes.
