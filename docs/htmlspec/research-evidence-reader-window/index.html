Goal and proof boundary

The current Canvas already knows whether a block carries source_document_id, but the live Canvas never passes onCiteSource; grounded provenance is therefore only an inert sentence. Success is not click intent. Success is a stable window descriptor carrying the exact encoded document identity into the existing BookReader, which then fetches through the existing rights-aware book APIs.

done investigation → exact Canvas → grounded block “read source” → openWindow("reader", { documentId }) → canonical BookReader in window mode → existing servability gate decides full text / snippet / refusal Canvas remains mounted; reopening the same document focuses the same window.

Key invariants

  • One reader: route and window both render BookReader; no forked HTML renderer.
  • No HTML trust regression: never revive the deleted HostedHtmlDocumentHost or add dangerouslySetInnerHTML.
  • Exact identity: only a non-empty source_document_id creates a reader window; the payload and stable window id use that exact value.
  • Continuity: opening evidence does not navigate away or unmount the result Canvas.
  • Rights truth: the window receives an identity, not caller-provided HTML; BookReader keeps ownership of fetching and servability.
  • Bounded fan-out: one window per document reuses the existing MAX_WINDOWS and focus semantics.
