Goal and proof boundary

ordered IDs + exported hashes → canonical v1 contract → SHA-256 identity → visible trust ticket

Non-authority: this digest is not a persisted draft, model route, cost estimate, spend receipt, synthesis, graph record, or merge approval.

Acceptance criteria

  • The identity binds the contract name, exact caller order, every investigation ID, and every full content hash.
  • Identical inputs reproduce it; reordering or changing one hash changes it.
  • The response returns version 1 and a full digest without paths or HTML.
  • The UI states that no model, spend approval, synthesis, or merge has run.
