Child specs

Goal and failure boundary

A new evidence reader uses the clicked source control’s live rectangle to choose a fully visible, non-overlapping adjacent placement when one exists. If none exists, it uses the established cascade; it never claims impossible spatial continuity. The reader renders Werner’s sanctioned loading asset and emits the existing evidence_source_opened reaction once only after current gate-served readable content commits.

Failure to avoid: reacting to click intent, stale fetch completion, gated/taken-down absence, or route reading; or forcing an off-screen/overlapping rectangle merely to satisfy a visual story.

Architecture

BlockCard click + DOMRect → Canvas callback preserves exact node + anchor → pure chooseEvidenceWindowRect(anchor, viewport) → right | left | below | above (full fit + no overlap) → undefined (existing cascade fallback) → stable canonical reader window → BookReader loading: existing WernerTobogganSpinner → current readable gate response commits → existing notifyEvidenceSourceOpened() exactly once

Invariants

  • Geometry carries no document authority; identity remains byte-exact from the graph.
  • Stable reopen focuses the existing window and does not relocate or replay its reaction.
  • Reduced motion is inherited from the sanctioned Werner asset; no new motion engine or bitmap is introduced.
  • Full-page /read/:documentId never gains evidence-window reaction semantics.
