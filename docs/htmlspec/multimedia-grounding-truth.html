Multimedia Grounding Truth

Status: implemented as a narrow compatibility-preserving hardening sprint.

Invariant

Research intent is not evidence. Topic, must-cover instructions, and source-scope labels must never mint citations or satisfy the unsourced-claim guard.

Contract

  • source_scope records the operator's retrieval intent and survives persistence and reopen.
  • sources remains a legacy input for explicit operator-provided excerpts only.
  • Explicit excerpts receive visibly synthetic operator-excerpt provenance.
  • Without evidence, factual lines remain unsourced and approval remains blocked.

Acceptance

  1. A scope-only request returns no citations and reports weak source coverage.
  2. An explicit excerpt can support citations identified as operator-provided.
  3. The workstation sends source_scope, never a scope label in sources.
  4. Malformed persisted scope data fails projection instead of being silently accepted.

Deferred

Graph retrieval and evidence attachment remain separate future work. This sprint does not claim that descriptive scope text performs retrieval.
