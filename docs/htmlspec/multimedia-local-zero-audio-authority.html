MSR-03B: Registered Local Audio Authority

Parent MSR-03

Spec lineage

Leaf sprint under MSR-03.

    Contract

    Add a public read-only backend on the configured local audible coordinator. Discover exactly one terminal registered row for the authenticated owner, asset, and exact current audio revision; verify its row MAC, deterministic run ID, current config digest, executable identity, and identity bindings without reconstructing production or accepting a caller run ID.

    Receipt and link closure

    • Reopen the exact AudibleExperienceReceipt, local production artifact, and AudibleRun with existing integrity keys and bounded private readers.
    • Match production and receipt row digests, owner, asset, revision, input/config digests, audio hash, duration, chapter/marker identity, and the current MultimediaAudioProductionLink.
    • Re-read the row and link after verification. A changed row, file, or link rejects the result.

    Refusals

    • Missing database/table/row, zero or multiple eligible rows, nonterminal state, missing receipt/link, or unsupported old row is evidence_unavailable.
    • MAC, deterministic ID, config, executable, identity, digest, nested artifact, byte, duration, marker, or link contradiction is evidence_conflict.

    Acceptance tests

    • Registered local audible chain reopens through exact current audio link.
    • Missing table is read-only and does not create the database.
    • Duplicate row, in-flight/recovery state, wrong owner/revision, bad MAC, changed executable, production tamper, receipt tamper, audio tamper, and link drift fail closed.
    • Existing audible produce/recover/register/playback tests remain green.

    Files

    substrate/multimedia/local_audible_coordinator.py and focused audible coordinator tests. Do not edit video, hardening, provider accounting, or report schemas.

    Five-values rigor

    The row, receipt, nested production, playback bytes, and current link are one exact chain; descriptive cost_usd fields do not participate.

    Out of scope

    No production, recovery, schema creation, provider query, evidence signing, hardening, or removal of legacy display fields.

    Harness hint

    Refute row, executable, artifact, receipt, playback, and link boundaries independently.
