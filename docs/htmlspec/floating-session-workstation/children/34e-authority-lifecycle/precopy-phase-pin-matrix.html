Normative pre-copy phase and pin matrix

A fresh recovery executor must never infer whether a missing pin represents an expected lifecycle state or corruption.

Exact progression

schema_only→barrier_acquired→sources_sealed→copy_prepared→copied_epoch0. Every arrow is a signed external-journal CAS using the issuer reserve/replay/commit protocol. Journal string/hash fields use JSON null only where permitted below; empty strings are forbidden. Root inventory and root manifest are required in every phase.

Abort-origin pin inheritance

Every transition into abort_prepared preserves the originating phase's five-field pin tuple byte-for-byte through every abort_* record; normalization is forbidden. No abort_origin_phase field is added: the tuple's nullability class is the signed origin oracle. The allowed classes are exactly: all-null from schema_only; barrier/freeze/witness only from barrier_acquired; those plus manifest from sources_sealed; or all-five from copy_prepared|copied_epoch0. Any other null pattern or any pin change during abort rejects.

Inherited classRoot-state oracle during final abort phases
All-nullRoot proves no barrier was acquired. abort_sources_revalidated authenticates the unchanged signed inventory; abort_barrier_released is a journal-only CAS and performs no root release.
Barrier/freeze/witnessRoot proves that exact barrier remains frozen and no source seal exists. Revalidate child freeze identities, then write abort completion and release that barrier exactly once.
Plus source manifestRoot and child adapters reproduce the exact sealed manifest, then write abort completion and release that barrier exactly once.
All-fiveRoot/children reproduce the exact manifest and target evidence agrees with the audit intent or completed audit, then write abort completion and release that barrier exactly once.

The pre-release/already-released replay rule in 34E-01 applies to every barrier-bearing class. It does not permit inventing a barrier for the all-null class.

Recovery API override

open_recovery_epoch0 accepts a tagged pin bundle whose fields must match this table and the abort-inheritance rule exactly; it covers all four pre-copy phases plus abort_*. Supplying a value where null is required, omitting a required value, or disagreeing with authenticated root/journal state rejects. It exposes only recover_seal_and_copy and authenticated abort. Crash tests are required on both sides of barrier acquisition, root seal, every external CAS, and every abort-origin class.
