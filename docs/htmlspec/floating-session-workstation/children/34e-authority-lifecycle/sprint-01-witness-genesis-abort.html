34E-01Wave 1Status: ready

Root witness, typed genesis copy, and recoverable abort

Cold-executable operating manual for reopening production migration lifecycle methods without recreating the false authority and deletion hazards found in Cycle34 review.

Parent context

Cycle34D certified schemas, bounds, role ownership, child transition evidence and a structural frozen-corpus model. Production seal/copy/abort intentionally reject. Review proved that module/name checks were spoofable, target genesis scaffolding had no source provenance, and unlink-before-fsync recovery could strand or misdirect deletion.

This sprint owns the shared authority state machine across production, support fixtures and tests. It may not claim real predecessor-store revocation; all successful behavior remains synthetic fixture eligibility only.

Goal

Implement a non-spoofable synthetic root witness, extract and copy all required genesis rows from their owning child adapters, and make epoch-zero abort recoverable at every persistence boundary—then enable seal/copy/abort only when the complete adversarial matrix passes.

Technical milestones

1. Freeze exact witness material

Add FixtureRootWitnessIssuerV1 as an independently supervised support process. It generates an Ed25519 key after spawn, returns only the public key, and never serializes key bytes. Its private SOCK_SEQPACKET listener authenticates the initial store peer with LOCAL_PEERCRED/SO_PEERCRED. At root creation it issues a signed, non-secret recovery ticket binding issuer key id, root/store ids, root and target-parent device+inode, target basename and maximum monotonic sequence. A replacement store process may connect only while the same issuer process/key remains live, present that ticket, transfer matching root and parent descriptors, and request exactly issuer_sequence+1 from the external signed state. Descriptor roster is phase-conditional: before database rename, also transfer the opened target fd; while the tombstone exists, transfer its fd and require its inode equal the witnessed target inode; after tombstone unlink, transfer no target fd and let the issuer prove target+tombstone absence with no-follow fstatat through the authenticated parent fd while retaining the signed target inode from the chain. The issuer independently measures descriptors/absence, opens root durable state and external lifecycle state via received directory fds with no-follow, verifies both chains/phases, and signs no free-form payload. Issuer death/restart permanently disables recovery; it does not generate a replacement key. SignedSyntheticRootWitnessV1 covers schema version, key id, root and target-parent device+inode, target basename, signed target device+inode, descriptor-presence mode target|tombstone|absent, root/store ids, authenticated current peer PID, store boot nonce, random 32-byte handle nonce, root manifest, inventory, barrier, freeze nonce, phase, monotonic request sequence and issued time under antiek.midnight-oil.private-paid-root-witness.v1\0. Store pins the issuer public key at open, verifies canonical bytes/signature, then independently repeats the phase-appropriate descriptor/absence checks.

Acceptance: dynamic class/module spoof, signing-oracle/free-form request, copied slots, pickle, fork/spawn, wrong peer PID or recovery ticket, skipped/replayed sequence, wrong descriptor roster, wrong root/store/path/target inode, false absence, stale phase, issuer death/restart, signature substitution and durable-state rewrite all reject. Store-process restart succeeds only against the same supervised issuer/key. Explicit claim: this protects the synthetic ceremony from fabricated values and filesystem races, not from arbitrary same-UID memory-reading code or host/issuer restart.

2. Make target creation schema-only

Separate schema construction from floor-pin runtime opening. create_epoch0 creates only paid_lane_schema; no provider/source genesis row is inserted out of band. Precutover reopen accepts phase-pinned source manifest/audit values without enabling runtime consumers.

Acceptance: immediately after creation every non-schema table count is zero and runtime open with unresolved floor pins rejects.

3. Extract typed provider/source genesis rows

Populate child adapters with the exact signed provider revocation genesis head/current and source genesis head/current rows. Export using normative column order and binary preservation. Role row counts/digests and manifest include them; target floor pins join only after copy.

Acceptance: every target non-schema row hash appears once in the owning source collection; missing/extra/reordered/resigned/cross-role rows reject.

4. Commit-like seal and copy

Barrier returns the corpus plus root-issued witness. Store revalidates witness and corpus. External CAS first records copy_prepared with the complete expected source-manifest and copy-audit hashes. The target then writes rows in one immediate transaction, audits schema/FKs/signatures/chains/budgets and creates the byte-identical CopyAuditV1 with normative [column,type,value] hashes. Recovery at copy_prepared accepts only an empty schema-only target or a fully populated target whose recomputed manifest and audit equal the signed intent: empty retries the transaction; exact completion advances; partial or divergent content rejects. Only then does external CAS record copied_epoch0. Construct result and successor before consuming predecessor.

Acceptance: injected exceptions at every pre-return line, including both sides of the target commit and external CAS, leave the correct predecessor usable and recover by the exact matrix; no target-only row or schema-row shortcut succeeds.

5. Durable abort journal

Checkpoint WAL, close every target connection and require -wal|-shm|-journal all absent before writing abort_prepared; any present or newly appearing sidecar rejects without mutation. Pin the parent directory fd; use basename-relative rename to a deterministic database tombstone, fsync, unlink the tombstone, fsync, revalidate sources, then release barrier. Recovery resumes from every durable phase while the same issuer is live and never follows a replacement parent path.

Acceptance: crash/fault injection before and after every state-write/rename/fsync/unlink is idempotently recoverable; parent symlink swap cannot affect a victim directory; held connections or sidecar creation block abort preparation.

6. Re-enable narrowly and certify

Enable only create/seal/copy/same-process abort/restart abort. Keep marker, forward recovery, admission, transition, backup and pinned runtime closed. Run focused/broad gates, independent architecture/correctness review, hardening, then exact staging.

Acceptance: no unconditional success beyond methods proven by the matrix; public results remain non-authority-bearing.

External lifecycle journal V1 and recovery matrix

The frozen target remains exactly eighteen tables. Lifecycle state lives in the target parent as mode-0600, regular, single-linked, no-follow file .<target-basename>.migration-state-v1.json; it survives target/tombstone deletion. Every update writes a unique mode-0600 temporary through the pinned parent fd, fsyncs the file, renameats over the state basename, then fsyncs the same parent fd. The record contains exactly: schema_version=1,target_store_id,root_id,root_manifest_sha256,barrier_id,freeze_nonce,source_manifest_sha256,copy_audit_sha256,target_parent_dev,target_parent_ino,target_basename,target_dev,target_ino,tombstone_basename,lifecycle_phase,phase_version,issuer_sequence,prepared_at_ms,updated_at_ms,witness_sha256,previous_state_sha256,state_sha256,issuer_key_id,signature_ed25519. Canonical encoding is UTF-8 JSON with sorted keys, no insignificant whitespace, JSON integers and lowercase hash strings. state_sha256 = SHA256("antiek.midnight-oil.private-paid-migration-state.v1\0" || canonical_json(record excluding state_sha256 and signature_ed25519)); previous_state_sha256 and issuer_sequence remain inside that material. signature_ed25519 = Sign(issuer_key,"antiek.midnight-oil.private-paid-migration-state-signature.v1\0" || bytes.fromhex(state_sha256)).

Issuer durability protocol. For exactly stored sequence N, the issuer accepts one canonical candidate for N+1, persists an in-memory pending tuple (N+1,state_sha256,signature), and returns it. Repeating the byte-identical candidate returns the byte-identical signature; a different candidate at N+1 rejects. After the store has durably renamed and parent-fsynced the signed journal, it sends commit(N+1,state_sha256); the issuer independently rereads the journal through the pinned directory fd, verifies the exact bytes, advances committed sequence, and clears pending. On store restart, the same live issuer permits byte-identical pending replay or observes the already-durable candidate and commits it; it never skips a pending sequence. Each legal journal CAS increments phase_version and issuer_sequence once. Witness-only issuance between CASes is forbidden.

Pre-abort phases are schema_only→copy_prepared→copied_epoch0. Abort phases are abort_prepared→abort_renamed_to_tombstone→abort_rename_fsynced→abort_tombstone_unlinked→abort_deletion_fsynced→abort_sources_revalidated→abort_barrier_released. The completed record is retained for exact replay; later operator cleanup is a separate future protocol.

Five-values rigor

Intellectual honesty

A witness that merely recognizes a Python class is not a witness. Demonstrate durable root and directory identity with executable spoof and swap tests before enabling seal.

Fairness

Attribute provider and source genesis rows to their actual owning adapters. Do not make target bootstrap an invisible exception that downstream auditors cannot reproduce.

Rigor

Enumerate every abort persistence edge and every handle-consumption edge. “Retry works” requires a crash-injected test from the exact durable phase.

Diligence

Recompute hashes, inode joins, schemas, FKs, chains and counts after reopen, not only in the happy process that created them.

Defensibility

If a required primitive cannot be made non-spoofable inside the synthetic fixture boundary, keep production methods disabled and amend this spec; never weaken the claim.
