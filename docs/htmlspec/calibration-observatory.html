Turn Outcomes into Antiek's Calibration Observatory

The canonical /outcomes index is the operator's cross-investigation record of judgments. Give that existing record a legible, authored home without inventing grades, altering the Phase 8 gate, or implying that an outcome is objective truth.

Five values

  1. Intellectual honesty: call each row a recorded judgment, not a fact or score; never use decorative imagery to imply correctness.
  2. Fairness: validated, falsified, and indeterminate remain equally available concepts; observer identity stays visible.
  3. Rigor: preserve exact requests—blank filter /outcomes?limit=200, trimmed filter /outcomes?observer=<encoded>&limit=200—and encoded synthesis navigation.
  4. Diligence: prove loading, empty, populated, filtered, and private-safe failure states at 768, 1024, and 1280 pixels.
  5. Defensibility: live HTML owns every fact and action; generated art is decorative, inert, empty-alt, and contains no grades, labels, data, controls, or mascot.

Surface contract

A compact observatory masthead explains that Outcomes is a history of judgments used to improve future work. The observer control remains a controlled text filter. Populated history preserves synthesis id, observed time, observer, outcome id, stable row identity, and row navigation. Empty copy explains the three existing verdicts without exposing routes or implementation sections.

Architecture invariants

  • The AppShell already owns the route-level main; this surface uses a scrolling div and must not nest another main landmark.
  • No API, schema, outcome creation, grading policy, synthesis detail, route, auth, shell, model, spend, or backend changes.
  • Failures show a fixed private-safe message and retry action; raw HTTP status, request path, and exception text never reach the page.
  • Filtering retains current fetch-on-change semantics and trims surrounding whitespace.

Visual contract

A restrained polar calibration chamber sits full-bleed behind a strong legibility veil: brass optical instruments at the edges, ice-blue aurora, and a quiet center. It is atmosphere, not interface. Cards and table remain restrained paper-and-ink HTML with obvious focus, hover, and responsive behavior.

Acceptance

  • Tests pin exact blank/filtered queries, loading and retry, safe failure copy, empty explanation, row facts, stable key behavior, and encoded navigation.
  • At least six deterministic stories cover the state model, plus one production-raster proof.
  • Fixture baselines cover 768, 1024, and 1280 pixels; the fixed-height AppShell boundary has explicit overflow proof.
  • Axe, TypeScript, design-token/type/parity checks, Storybook, production build, security scan, and heterogeneous hostile review are green.

Non-goals

No new outcome semantics, score visualization, chart, API/schema, grading form, Phase 8 policy, synthesis detail, route, backend, shell, Werner, cursor, model/spend authority, merge, or deploy.
