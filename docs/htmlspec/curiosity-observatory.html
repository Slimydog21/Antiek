Curiosity Observatory

Base: goal/library-archive-shelf@432b787fa. Owner: curiosity-observatory.

Authority

  • PanelHost owns the docked watch-list and thought-partner wings; this sprint does not edit their registry, store, or lifecycle.
  • The list API owns parked questions. The launch API owns the new investigation handle. Navigation occurs only after a current successful launch.
  • The raster is decorative architecture only. All questions, identifiers, counts, errors, actions, and Werner are HTML.

Behavior

  • The first returned question occupies the central desk; an existing selected ID survives refresh only while it remains in the authoritative response.
  • Monotonic generations fence superseded list/launch completions and unmount. A synchronous ref prevents duplicate paid or side-effecting launch requests.
  • Loading, unavailable, empty, selected, launching, and launch-failure states are authored and do not expose backend exception text.
  • A successful launch remains authoritative even when its best-effort list refresh fails.

Visual and access

  • Canonical Werner stays fixed at the thought station; local ambient motion never follows the cursor and stops under reduced motion.
  • The central desk remains readable at 1280, 1024, and 768 px; the watch list appears inline below 768 while desktop PanelHost authority remains unchanged.
  • Storybook fixtures for populated, empty, loading, and error states are deterministic and receive responsive LostPixel baselines.
