← Paid operation authority · SPR-01

Canonical intent + owner/CAS store

Wave 1Provider-inertOwner: one implementation instance

Parent context

Antiek’s collective interrogation preview deliberately makes no paid call. A closed historical Midnight Oil branch contains useful authority invariants but cannot be merged as current authority. This sprint creates the smallest shared, durable record on the current stack.

It must support multiple closed operation kinds without knowing how any provider, research runner, or product UI executes. It stores authority, not answers.

Goal

Persist an owner-bound, versioned operation intent and enforce exact create/replay/conflict semantics with CAS state transitions.

The initial API may be internal-only. No token issuance, enqueue, lease, provider adapter, product projection or UI launch belongs here.

Technical milestones

  1. Define canonical intent. Implement exactly the root spec’s frozen v1 JSON profile and two operation-kind field sets in substrate/paid_operations/contracts.py. Reject floats, nulls, missing/unknown keys/kinds/versions, non-NFC strings and unstable serialization; commit golden vectors at tests/fixtures/paid_operations/intent-v1.json.
  2. Implement one durable owner store. Use one SQLite WAL database at the injected runtime path, implemented in substrate/paid_operations/store.py with migration in substrate/paid_operations/migrations/001_authority.sql. Table paid_operations has primary key operation_id; required owner/account/kind/intent hash+canonical bytes; quote/ceiling cents; state; version; created/updated/expiry milliseconds; consent token hash/key ID/issued/expiry/claimed timestamps nullable until SPR-02; lease worker/generation/expiry nullable until SPR-03; and terminal/reconciliation metadata. Index (account_id,owner_user_id,created_at_ms). All money columns have non-negative integer checks and quote ≤ ceiling.
  3. Freeze the state graph. intent_created → consent_issued → queued → running → complete|failed|budget_halted|timed_out|failed_reconcile; failed_reconcile → complete|failed only through the SPR-03 reconciliation API. Every mutation executes BEGIN IMMEDIATE and UPDATE ... WHERE operation_id=? AND owner_user_id=? AND account_id=? AND version=? AND state IN (...), increments version once, and requires exactly one changed row.
  4. Enforce replay semantics. Exact owner/account/ID/canonical-intent replay returns the same record; foreign subject is non-enumerable; same identity with changed material conflicts; malformed durable rows fail closed.
  5. Add hostile tests. Implement in tests/test_paid_operation_contracts.py and tests/test_paid_operation_store.py: concurrent create/CAS, stale version, overflow cents, every per-kind field drift, malformed rows and restart.

Internal API: create_or_replay(subject, operation_id, kind, payload) → OperationSnapshot, get_owned(subject, operation_id) → snapshot|None, and compare_and_swap(subject, operation_id, expected_version, allowed_from, to_state, patch) → snapshot. No HTTP route is added in SPR-01.

Rigor — operating manual

1 · Intellectual honesty

Do not call a hash “authorization.” Record which fields are canonicalized and which remain unbound; if prompt bytes or the collective compose fingerprint cannot yet be reconstructed exactly, the operation kind must remain unavailable.

2 · Fairness

Steelman adapting the historical DurableOwnerJobStore. Retain it only if a bounded extraction proves its schema and transaction model are not Midnight-Oil-specific; otherwise document why a fresh current-stack store costs less risk.

3 · Rigor

Race two writers against the same expected version and require exactly one transition. A unit test of sequential calls does not prove CAS.

4 · Diligence

Read current migrations, owner-scoping middleware, collective compose fingerprint generation, and historical store tests before fixing the canonical fields. Cite source SHA/path in the decision record.

5 · Defensibility

Commit canonical JSON vectors and every-field sensitivity tests. A future executor must be able to reproduce the hash without consulting this conversation.
