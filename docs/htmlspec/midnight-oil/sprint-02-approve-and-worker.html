SPR-02 — Approve gate + offline worker loop

← master

Deliverables

  • approve_job(job, ceiling_usd) — requires ceiling ≥ recommended OR explicit force_below flag.
  • run_worker_iteration(job, spawn_fn, clock) — one step; injectable clock; stops when duration elapsed or budget exhausted.

Acceptance

  1. Start without approve raises.
  2. Charge that would exceed approved ceiling halts job with status budget_halted.
  3. Fake clock advances duration → status timed_out with partial results retained.

Non-goals

No real LLM calls in unit tests (inject spawn_fn).
