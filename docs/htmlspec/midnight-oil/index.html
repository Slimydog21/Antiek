Midnight Oil — autonomous research sub-agent swarm

Users engage deep research without sitting in the workstation. They set a work window and goals; the system recommends a price ceiling; after approval the swarm executes offline-from-UI and deposits HTML artifacts + twin notes.

Problem

Interactive cascade requires the operator present. Continuous daemon (orchestration/continuous) chases evidentiary gaps but is not a user-facing “set timer + budget + goals and walk away” product. Midnight Oil is that product surface over existing runner + budget substrate.

Seams (reuse, do not rebuild)

  • runtime/research_runner.BudgetManager — per-research + aggregate USD ceilings
  • orchestration/continuous.DaemonBudget — daily + per-investigation caps
  • substrate/engagement_spine — reserved spawns, twin notes, merge, HTML project
  • substrate/model_control — driver selection + pre-flight cost projection
  • orchestration/cascade_session / cascade routes — fan-out investigation trees
  • Acquisition: acquisition/{arxiv,substack,books,urls} as tools, not new connectors

Acceptance bars (master)

  1. Operator can create a Midnight Oil job: {goals[], duration_minutes, model_id?}.
  2. System returns recommended_price_ceiling_usd computed from duration × tier rate × estimated fan-out depth (documented formula), and refuses start without explicit approve of a ceiling ≥ recommended or a lower override with warning.
  3. While running: status is queryable; spend never exceeds approved ceiling (hard halt with partial HTML deposit).
  4. On complete/timeout: HTML research artifact(s) + twin insights/questions written for a job asset id; optional merge draft.
  5. No workstation UI session required after approve (daemon or worker process).

Non-goals

  • Guaranteed quality of prose (quality is eval/Antiek-bench later).
  • Self-hosting models; second runtime beyond Hermes-primary dispatch.
  • Mobile push notifications (optional later).
  • Authoritative third-party routers (NotDiamond authority REJECT).
