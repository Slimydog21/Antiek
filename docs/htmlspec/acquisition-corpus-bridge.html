Acquisition cache → corpus bridge

Status: implementation composition of PR #760 and PR #751; no production wiring.

User outcome

Cached scholarly and newsletter evidence can enter deep research through one immutable search → fetch boundary without a network fallback or paywall bypass.

Contract

  • arXiv OAI-PMH, OpenAlex, and accessible Substack cache snapshots pass the reusable corpus conformance kit.
  • Every fetch preserves source, record identity, acquisition time, and a non-empty rights class.
  • Substack HTML is reduced to inert research text; script, style, template, and noscript content never enters synthesis.
  • Inaccessible Substack entries expose metadata search only and return a typed policy miss on fetch.
  • Construction detaches from caller dictionaries; later mutation cannot alter search or fetch.

Semantic Scholar is deliberately excluded: PR #760 enriches in memory and does not create a cache record with fetched_at. Claiming a cache adapter for it would be unreachable test-only code; a later persistence owner must establish the snapshot contract first.

Non-goals

No network calls, PDF fetching, paywall fallback, rendering, routing, production wiring, campaign mutation, merge, deployment, or live spend.
