Durable, owner-bound marketplace library

Make purchased and hosted books survive application restarts without weakening account isolation or HTML-native viewing.

Evidence-backed gap

The original marketplace routes resolved a process-local store. MDL-SPR-01 added explicit durable composition, but a corpus audit then proved that production systemd still imported the in-memory default and nightly recovery omitted the SQLite file.

implemented capability: create_app(explicit store) -> restart survives
production closure: env path -> explicit store -> verified snapshot -> stopped restore

Invariants

  • Middleware identity remains the only owner authority.
  • Marketplace and generic hosted-document routes use the same app-scoped store.
  • Production never silently falls back after an explicit durability configuration.
  • Backups use database consistency primitives and are validated before upload.
  • No card data, checkout, network call, model routing, deployment, or PDF viewing is added.
