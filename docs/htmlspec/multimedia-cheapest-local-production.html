Make cheapest a real zero-network documentary route

Master execution spec. The current cheapest route is honest but incomplete: it plans at zero cost and rejects every production authority. The target is a separate local lane that creates playable narration, graph-grounded source-card visuals, a Ken Burns MP4, canonical receipt, and verified playback without reaching Krea, a TTS gateway, paid authorization, credentials, DNS, or HTTP.

Permanent separation

Cheapest never enters paid narration authorization, paid visual authorization, provider execution, or the paid production worker. Those rejections remain permanent. A dedicated local coordinator derives all inputs from the current owner asset and carries its own local execution receipts, integrity keys, leases, and recovery states. There is no automatic fallback from local to paid.

Production phases

  1. Trusted local narration: configured executable speech, measured PCM WAV, independent executable/config provenance, chapter-level replay.
  2. Deterministic local visuals: fixed PNG source cards and diagrams from canonical plan and graph snapshots, pinned fonts/layout, explicit source_card or diagram disclosure, no remote assets or arbitrary markup.
  3. Local coordinator: durable input snapshot, per-chapter audio and per-scene visual completion, visual packet, existing Ken Burns renderer, educational receipt, exact revision registration, and crash recovery.
  4. Workstation: capability preflight, Produce locally · $0, phase progress, evidence disclosure, recovery controls, and verified playback.

Evidence model

Local visuals do not claim archival truth. Every output binds asset, revision, scene, canonical input digest, ordered source chunks, current graph text/document digests, renderer/font digests, PNG digest, label, and producer/reviewer signature. Evidence is reopened immediately before visual packet compilation. Missing, reordered, changed, or deleted chunks invalidate the visual.

Crash and replay

One owner/asset/revision/input digest elects one local run. Completed children reopen from private signed receipts. Producing states never rerun implicitly after an unknown executable outcome; explicit recovery validates expected pending/final bytes. A completed render or receipt is reopened, never overwritten. Same request ID with changed terms conflicts.

Threat model

Reject shell interpretation, inherited provider credentials, executable replacement, unsafe output paths, symlinks, permissive files, unbounded text/media, fake TTS bytes, estimated durations, network access, graph drift, visual-label confusion, stale revision completion, duplicate workers, and receipt substitution.

Completion evidence

An end-to-end real fixture must create decodable WAV and MP4 plus captions, report exactly zero spend, make zero network/provider calls, survive injected crashes at every phase without duplicate synthesis, register only the current revision, and play through existing authenticated byte-range endpoints. Until those proofs pass, the current generic cheapest production rejection stays in place.
