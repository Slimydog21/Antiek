CandidateVerdictReason

Hard-to-vary contract

  1. Only taxonomy Write routes mount the scriptorium.
  2. The bitmap contains no Werner, character, document, paper, book, pseudo-text, graph, cursor, control, tool, workstation, or semantic evidence.
  3. The layer is aria-hidden, empty-alt, pointer-inert, non-draggable, and paints beneath frosted SceneChrome content.
  4. The provenance PNG never ships to runtime; runtime uses a ≤128 KiB WebP and performs no provider call.
  5. Responsive cover crops preserve a calm HTML field at 768, 1024, and 1280 pixels.
  6. Research keeps its observatory; Read, Speak, shared routes, live Werner, cursor instruments, product data, and accessibility semantics remain unchanged.

Acceptance

  1. Taxonomy-derived source tests prove Write-only mounting, exact layer order, decorative semantics, WebP identity, and byte ceiling.
  2. Isolated and real SceneChrome stories prove selectable HTML and native controls.
  3. Focused shell tests, TypeScript, builds, token lint, scoped LostPixel, axe, HardenX, and heterogeneous review pass.
  4. No merge or deployment.

Withheld authority

No generated draft, bitmap editor, additional mascot, animated/video stream, Krea/Modal call, hotspot map, route/activity change, content mutation, network, spend, merge, or deploy.
