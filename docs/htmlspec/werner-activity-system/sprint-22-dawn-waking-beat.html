Spec lineage

Parent: Werner Station Activity System. This sprint executes the runtime half intentionally withheld by SPR-17 after SPR-20 established genuine waking semantics and SPR-21 established a real bounded dawn signal.

    Parent context and goal

    The scene now has one OS-theme-sovereign civil-time authority. It can commit night → dawn, but wernerMoments is consumed only by Storybook and explicitly pins that pair to silence. The shell mounts Scene and PenguinMascot as siblings, so the live Werner cannot observe the semantic transition without a deliberate bridge.

    Build a one-way typed cue path: Scene derives and compares; AppShell transports identity; PenguinMascot arbitrates and renders. Share the centrally owned waking artwork, never the long-rest lifecycle state. Initial dawn is not a transition.

    Technical milestones and acceptance

    1. Truthful transition vocabulary. momentForTransition returns daybreak only for exact night → dawn. Initial dawn, night → day, day → dawn, same mood, and weather-only changes return null. Preserve other moments.
    2. Committed Scene cue. Add one optional typed callback to derived Scene only. Compare a committed previous mood with the current mood after render; seed the previous ref without emission. StrictMode, identical rerenders, explicit mood overrides, and unmount emit no duplicate or false cue. Scene remains the only media, civil-time, visibility, and boundary-timer owner.
    3. Opaque shell transport. AppShell stores only a monotonically identified Werner cue and passes it to PenguinMascot. It never reads a clock, theme, daypart, or weather and never mounts another Werner.
    4. Sole-mascot arbitration. PenguinMascot keeps scene beat state separate from StationRestPhase and ordinary stage emotes. It consumes each cue at most once, starts only when foreground is free, marks preempted cues consumed, clears completion, replacement, and unmount timers, never moves the station, and never calls noteInteraction. Reduced motion renders the same semantic beat statically for the bounded duration.
    5. Proof surface. Add a deterministic Storybook plate covering normal, static, and preempted dawn behavior and LostPixel baselines at 768, 1024, and 1280 only if stable. Tests prove one button, one visible Werner pose, unchanged rest phase, exact cue cardinality, full precedence, timer teardown, and no extra time or theme authority.

    Five-values rigor

    Intellectual honestyCall the cue a bounded Antiek dawn acknowledgment, not sunrise detection. A real cue normally requires OS light mode to arrive during the dawn window; 05:30 alone cannot override dark mode. Do not claim the local accessibility wrapper if its stories fail to load.
    FairnessReduced-motion users receive the same recognition as a static authored pose, while keyboard and pointer behavior remain untouched. Hidden or busy users do not receive a stale delayed performance after dawn has passed.
    RigorProve exact transition pairs, StrictMode emission count, cue identity deduplication, every precedence edge, one visible pose, and zero timers after teardown. Search production for any new matchMedia, daypart clock, or raster import outside canonical owners.
    DiligenceExercise product emote, outbound walk, return-home, drag, arcade suspension, long-rest sleep and wake, reduced motion, initial mount, visibility recovery, and unmount. Keep existing fixed-station and rest suites green unchanged.
    DefensibilityRecord why a typed callback beats a global event or store, why artwork can be shared while lifecycle state cannot, and why preempted ambience is consumed rather than replayed. A future generalized episode scheduler must earn a separate spec.

    Rejected alternatives

    Second mood hook in PenguinMascotRejected: duplicates media, time, and timer authority and can disagree with the rendered scene.
    Global custom event, store, or contextRejected: wider lifetime and hidden subscribers for a one-parent sibling transport seam.
    Add scene waking to StationRestPhaseRejected: dawn is not human interaction and must not reset or counterfeit the long-rest lifecycle.
    Ordinary WernerStage emoteRejected: the authored waking pose is not in the four mood slots or emote vocabulary, and stage cleanup would blur semantic ownership.
    Replay after foreground workRejected: delayed ambience becomes interruption and can perform dawn after dawn has passed.
    New image generationRejected: the identity-anchored waking artwork already exists and is centrally mapped; duplication adds variance without a new visual job.
