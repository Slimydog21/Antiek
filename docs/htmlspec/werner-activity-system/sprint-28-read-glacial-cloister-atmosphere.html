Hard-to-vary contract

  1. Only taxonomy Read routes mount the cloister.
  2. The bitmap contains no character, book, page, paper, text, shelf content, furniture, cursor, control, evidence, annotation, or semantic state.
  3. The layer is aria-hidden, empty-alt, pointer-inert, non-draggable, and paints beneath frosted SceneChrome content.
  4. Runtime uses a ≤128 KiB WebP and performs no provider call.
  5. Crops preserve a calm HTML field at 768, 1024, and 1280 pixels.
  6. Research, Write, and Speak retain their worlds; shared routes, books, rights, reader state, and accessibility semantics remain unchanged.

Acceptance

  1. Taxonomy-derived tests prove Read-only mounting, layer order, decorative semantics, WebP identity, and byte ceiling.
  2. Isolated and real SceneChrome stories prove selectable HTML and native controls.
  3. Tests, TypeScript, builds, token lint, scoped LostPixel, axe, HardenX, and heterogeneous review pass.
  4. No merge or deployment.
