Five values

Intellectual honesty

A generated picture proves mood, not cursor behavior. DOM tests prove mechanics; compilation proves buildability; only live browser inspection can prove appearance.

Fairness

A model-generated full-frame interface could reshape freely, but would sacrifice selectable writing, accessibility, deterministic editing, latency, and cost. Preserve the visual aspiration through decomposed HTML-native instruments.

Rigor

Test all taxonomy Write rows and hostile boundaries. A prefix named “write” is not enough; the taxonomy owns meaning.

Diligence

Reuse the existing cursor sampler and route hook. Leave reaction bus, games, hotspots, generated runtime poses, navigation, and shared dirty work untouched.

Defensibility

Keep one inspectable mapping and one powerless contract. Record hashes and exact evidence classes so no future agent can promote pixels into product truth.

Out of scope and collision boundary

  • No PenguinMascot, reaction bus, shell experience signals, arcade, hotspots, session assets, workflow taxonomy, navigation, network, content inspection, save behavior, or spend changes.
  • No writing nib on /brainstorm; its product taxonomy is Research.
  • No generated image in runtime UI and no claim that this sprint implements an editor.
  • No streamed Flipbook/video path, Modal GPU work, Krea call, or Grok generation.
Stop rule: if the route cannot be derived through the existing taxonomy and station seam, return to this spec rather than opening a new shell owner.
