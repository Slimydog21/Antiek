Hard-to-vary contract

  1. Initial dusk, same mood, and weather-only changes emit nothing; the first committed non-dusk→dusk edge emits once.
  2. Dawn and dusk share one monotonic cue identity without sharing mascot lifecycle state.
  3. The new art is a private authored pose, never a fifth canonical product mood.
  4. Exactly one Werner remains mounted; the beat never moves the station or resets interaction/rest state.
  5. The runtime image has real alpha and no checkerboard, text, prop, scenery, icon, or second character.
  6. No time listener, theme listener, network call, provider call, route change, content mutation, merge, or deployment.
