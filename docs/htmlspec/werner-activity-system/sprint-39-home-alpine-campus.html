Turn Home into Antiek's alpine knowledge campus

Replace the generic four-card front door with one authored world whose visible landmarks are controlled by four real semantic HTML workflow buttons. Pixels own geography only; taxonomy owns identity, order, labels, and navigation.

Implemented5 milestonesChatGPT ImageZero runtime generation

Verified gap and falsifiable thesis

/home currently presents a conventional centered card grid over generic glass. The Flipbook no-go record claims scene/interactiveRegions.ts and an interactive hotspot map shipped, but repository history, branches, worktrees, and source search contain neither. The claim is stale.

Thesis: one spatial campus can make Antiek's four workflows feel like rooms in one knowledge home without becoming an inaccessible image map, if the DOM remains a four-button ordered list and CSS placement is presentation only.

Failure condition: if the art must be inspected, sampled, or loaded to determine a route, accessible label, hit target, focus order, or product state, reject the sprint.

Technical milestones

1Author geography

Generate one 16:10 environment-only alpine campus with exactly four separated landmarks and one connecting trail. Preserve the 1568×1003 PNG master; ship a ≤256 KiB WebP derivative.

Acceptance: no character, mascot, UI, text, label, icon, cursor, logo, or fifth destination exists.

2Keep authority in HTML

Render one <nav>, one ordered list, and exactly four taxonomy-backed buttons. Image has empty alt, aria-hidden, and no pointer authority.

Acceptance: asset failure removes only decoration; all destinations remain named, focused, and activatable.

3Adapt without reordering

Desktop positions buttons over their landmark quadrants. Narrow layouts use the same DOM as a vertical itinerary below a cropped scenic header.

Acceptance: Research→Read→Write→Speak is DOM/Tab order at every width; no coordinate dispatch, image map, canvas sampling, or duplicate mobile markup.

4Prove the real route

Add behavior, asset-bound, failure, type, token, Storybook, axe, and 375/768/1024/1280 visual proof. Inspect both art-present and art-unavailable states.

Acceptance: no overlap/clipping; visible focus; four targets stay readable; image loss preserves full navigation.

5Correct the record

Update the Flipbook no-go to distinguish the formerly false “already shipped” claim from this bounded Home-only implementation. The shippable correction is docs/decisions/flipbook-full-generative-stream-no-go.md. Transport as a stack on SPR-38.

Acceptance: no claim of pure-pixel UI, generalized hotspot engine, runtime generation, or production deployment.
