Goal

Replace the one-off ice-fishing coupling with a typed activity boundary. An activity may declare ambient classes, a cursor instrument, and an unlock rule. The contract grants no Werner-position authority, and a focused source-boundary test rejects direct movement, navigation, and network dependencies. Ice fishing remains behavior-identical as the default.

Success criteria

  • StationActivity contains no position, movement, mascot ref, or stage-controller capability.
  • The production shell mounts the default activity's instrument; the mascot reads its idle class; current fishing tests remain green.
  • Future page activities and games register through one boundary instead of editing PenguinMascot.tsx.

Failure mode to avoid

A superficially extensible registry that quietly lets an activity chase the cursor, forks a second Werner, or changes reduced-motion behavior.

Distinctive design direction

Antiek is a researcher's illustrated alpine observatory, not a mascot-skinned SaaS dashboard.

Invariants

  • Exactly one interactive Werner exists at shell level.
  • Reduced motion disables involuntary activity motion and custom cursor layers.
  • The activity contract grants no product authority, spend, network, navigation, or mascot-position capability; the source gate catches direct violations but is not presented as a JavaScript sandbox.
  • Every generated image is presentation evidence, never interaction or research evidence.

Decision log and rejected alternatives

Decision / alternative Verdict Reconsider if
Typed registry; ice fishing remains default Chosen. Smallest behavior-preserving hinge for future activities. A future activity cannot be represented without weakening the fixed-station invariant.
Continue hard-coding fishing in shell + mascot Rejected. Every new activity would reopen both owners and invite divergent state. Antiek permanently abandons all non-fishing activities.
Full Flipbook pure-pixel stream Rejected for the pass bar: measured generation is far below 24 fps and cost is not defensible. Measured sub-second frames under a hard spend ceiling support a dual HTML/pixel path.
Activity may move Werner Rejected. It reintroduces the cursor-chasing behavior the operator explicitly reversed. Only an explicit operator re-ratification can reopen it.
Random or timer-based activity switching Rejected. It makes cursor semantics unpredictable during professional reading and research. An opt-in entertainment mode has its own visible state and never leaks into knowledge work.
Use the generated observatory PNG as the interactive UI Rejected. Its apparent text and graph are pixels, not selectable HTML, accessible controls, or product evidence. Never for core work; it remains design evidence and may inform decomposed assets.

Execution harness hint

All eighteen implemented sprints are file-coupled and run inline. Verification must be heterogeneous and try to prove behavioral drift: route determinism, transition cleanup, exactly-one-instrument mounting, custom-cursor visibility, edge-only product reactions, fixed-step input cardinality, focus leakage, responsive pointer drift, reduced-motion stillness, opt-in lazy boundaries, renderer mutation, deterministic motion proof, HTML authority, and illicit position or product capability.
