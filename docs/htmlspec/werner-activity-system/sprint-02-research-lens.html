Parent context

This page is cold-executable; the master spec is not required.

Antiek is a professional reading and research workstation. Werner is the one interactive penguin and lives at a fixed, draggable station. SPR-01 introduces a typed activity registry and preserves ice fishing as the default. The operator's session brief asks for the cursor to control Werner's product-world behavior without making Werner chase it.

A ChatGPT Image concept depicts Werner at an alpine observatory while a luminous lens connects to reshaping research surfaces. That PNG is design evidence only. This sprint implements the load-bearing interaction as ordinary HTML/CSS: the route chooses an activity deterministically, the custom lens follows the pointer without capturing input, and the research content underneath stays real, selectable HTML.

Goal

Use one explicit pathname policy to select research-lens across reading and research routes, while all other routes keep ice fishing.

The mascot and cursor shell must read the same activity. The lens may consume only live pointer, idle, and hidden-tab signals; it receives no content, navigation, network, spend, or Werner-position capability. Reduced motion removes the custom lens and restores the native cursor.

Rigor — operating manual

1 · Intellectual honesty

The generated observatory PNG proves only a visual direction. The ResearchLensCursor DOM tests prove behavior; Storybook compilation proves buildability; only an actual browser screenshot can prove appearance. Keep those three evidence classes separate in the handoff.

2 · Fairness

Steelman an operator-selectable activity picker: it provides agency. Reject it in SPR-02 because a professional pointer changing semantics unpredictably is costly, while explicit route policy is inspectable and leaves a future temporary override seam.

3 · Rigor

Attack the route edges /, /readings versus /read/…, nested deep-research IDs, and trailing slashes. Prove reduced motion removes the custom lens so the global cursor:none class cannot strand a user without a pointer.

4 · Diligence

Reuse useMouseFollow's imperative read seam and WernerIceBait's no-rerender pattern. Do not create a second cursor sampler, modify the dirty reaction bus, or encode route knowledge separately in mascot and shell.

5 · Defensibility

Version the ChatGPT Image frame with hash, dimensions, prompt intent, allowed use, and forbidden claims. Record the stacked dependency on PR #2047 and name browser unavailability as an unresolved acceptance gate.
