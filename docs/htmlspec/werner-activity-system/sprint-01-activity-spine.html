Typed station-activity spine

Parent context

This page is cold-executable; the master spec is not required.

Werner is the one interactive penguin in Antiek. He lives at a fixed, draggable station. He never follows the cursor. While the pointer moves, the cursor is bait on his fishing line; after two seconds idle, the own-hole never-catch animation plays. Reduced-motion freezes involuntary motion and disables the custom cursor.

The shell currently hard-wires ice fishing in two owners: PenguinMascot.tsx toggles its CSS class, and WernerIceCursorShell.tsx mounts bait plus line. This sprint extracts those exact behaviors into a typed registry without changing what users see.

Goal

Introduce StationActivity so activities declare appearance and a cursor instrument without receiving mascot-movement authority.

Ice fishing registers as the only/default activity. The mascot and shell consume the registry. A source-boundary test rejects direct movement, navigation, and network dependencies without pretending to be a runtime sandbox. Existing components, animation timing, custom-cursor policy, and click/double-click/drag semantics remain unchanged.

Rigor — operating manual

1 · Intellectual honesty

“Behavior-preserving” is a measured claim: compare the same real bait/line children, idle class, disabled semantics, and existing station tests. If build is not run, report it as NOT RUN rather than relying on typecheck.

2 · Fairness

Steelman leaving fishing hard-coded: it is simpler for one activity. Reject it only because the operator explicitly requires multiple page activities and games, making repeated shell/mascot edits the larger cost.

3 · Rigor

Attack the forbidden seam: search the activity types for coordinates, setters, refs, stage controllers, and navigation. Tests must use the real ice-fishing components, not placeholder doubles that could pass while production drifts.

4 · Diligence

Read the fixed-station decision, PenguinMascot.tsx, WernerIceCursorShell.tsx, and current fishing tests in full before editing. Preserve mount order because line/bait layering is observable.

5 · Defensibility

Record that the revived commit was replayed onto the exact current origin/main SHA, with exact gate counts. The handoff must name dirty arcade/reaction/session-asset work as excluded collision territory.
