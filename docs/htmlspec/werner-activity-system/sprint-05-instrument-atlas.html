Parent context

Cold-executable contract; no master-spec context required.

SPR-01 created a powerless station-activity registry. SPR-02 through SPR-04 assigned the lens, nib, and listening resonance to Research/Read, Write, and Speak while preserving ice fishing as the safe shared/unknown default. Individual stories and route tests exist, but no single review surface exposes the complete grammar and no one mounted-shell test proves marker cleanup across all four modes.

Goal

Add a Storybook-only selectable atlas that mounts exactly one registered instrument, plus a production-shell transition test for /write → /speak → /brainstorm → unknown.

The atlas must use the real registry components, readable HTML, explicit route/job labels, and explicit authority-withheld copy. It must not create a fifth runtime activity, change selection policy, import generated pixels, or imply product capability.

Five values

Intellectual honesty

The atlas demonstrates registered visual instruments, not that any underlying research, editing, audio, or network capability works.

Fairness

Reviewers can compare every workflow under the same HTML desk instead of judging isolated polished frames.

Rigor

Test one living shell across transitions so cleanup bugs cannot hide behind independent mounts.

Diligence

Reuse the production registry and selectors; add no shadow catalog, production route, activity, asset, or state owner.

Defensibility

One inspectable mapping, one exact transition sequence, a zero-production-source diff, and explicit unproven visual QA.

Out of scope

  • Production activity, component, CSS, registry, route selection, taxonomy, shell, mascot, or reaction changes.
  • Audio, recording, content mutation, navigation authority, network calls, spend, generated runtime imagery, games, merge, or deploy.
  • Claiming visual approval without an available in-app browser.
Stop condition: if the atlas needs a production seam to function, reject the slice and diagnose the registry instead of widening it.
