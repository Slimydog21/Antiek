The night archive holds while research runs

Replace only the prototype Zombies canvas renderer. Preserve every rule, lifecycle, input, wait-host, research, accessibility, and authority decision from SPR-07/08.

User promise

Paperclip Zombies reads as a crafted Antiek field instrument rather than debug shapes: an archive fort, evidence traces, legible paperclip threats, and exact phase directions.

Hard-to-vary visual contract

  • The single signature is an archival seismograph: every live threat rides a ruled evidence trace toward an accordion-file fort.
  • Quiet HUD tape reports wave, score, and fort lives; one stable bottom plate reports ready, playing, fallen, or exited action copy.
  • Paperclips use nested loops, aurora arms, and lemon HP pips. No gore, guns, weapons, military insignia, generic neon, or second Werner.
  • Existing Antiek tokens supply every color and type role. Generated imagery remains provenance-only; runtime rendering is canvas code.

Withheld authority

The renderer is a pure projection of the existing `ZombiesState`. It may not read or modify input, time, RNG, spawn, score, hitboxes, lives, waves, focus, research, storage, network, content, model, or spend state. Reduced-motion remains the rules engine's static click-driven mode; the renderer adds no time-derived motion.

Mechanical acceptance

  1. Canvas-command tests cover all four phase plates, fort drawers, evidence trace, paperclip loops, HP pips, HUD, and compact bounds.
  2. Two identical snapshots produce identical commands and the input state remains byte-equivalent after rendering.
  3. Source proof rejects raw color literals and generic system typography.
  4. Existing logic/lifecycle suites remain unchanged and green; coupled wait-host, typecheck, token/type lint, build budgets, Storybook, Hardenx, heterogeneous review, and remote checks pass.
  5. Live visual inspection covers ready/play/fallen/exited, dark field legibility, canvas focus, narrow containment, and reduced motion when an in-app target exists; otherwise it is recorded as NOT PROVEN.
