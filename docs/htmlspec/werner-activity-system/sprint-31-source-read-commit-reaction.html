Five-values rigor

Intellectual honestySuccessful persistence is the only reaction boundary; the low dwell bar is engagement evidence, not completion.
FairnessReduced-motion users receive the same happy semantic as a bounded still; reading is never interrupted or blocked.
RigorProve no pre-commit or failed-write reaction, metadata-only payload, closed vocabulary mapping, one stage, and existing precedence.
DiligenceKeep the established once-per-reading-session coalescing and best-effort failure behavior unchanged.
DefensibilityReuse the archival verification composition; no new pose or generic event layer is justified.

  4. Production mascot, reaction-bus, source-read, reduced-motion, precedence, TypeScript, builds, axe, security, and independent review gates pass.
