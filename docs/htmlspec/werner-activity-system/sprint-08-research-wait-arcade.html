WERNER-ACT · executable sprint 08 · 2026-07-14

Paperclip Zombies while Deep Research remains primary

Ship an optional, production-default-off wait surface inside the durable Deep Research monitor. This sprint consumes SPR-07's deterministic arcade core; it does not change it.

User promise

After a genuine research wait lasts eight seconds, the user may explicitly play a compact Paperclip Zombies easter egg. Research cards, partial results, costs, reconnect state, and steering stay visible and usable. Completion reveals nothing late because nothing was hidden.

Authoritative state machine

  • Disabled, connecting, empty, first-poll error, terminal, or reduced motion → hidden.
  • Valid nonterminal durable snapshot before eight seconds → unchanged monitor.
  • Threshold reached → offer; no cartridge construction and no focus movement.
  • Explicit Play → dynamically load and mount one Zombies cartridge.
  • Partial completion or reconnect with prior data → keep host and all cards visible.
  • All terminal, new episode, reduced motion, Exit, Escape, or unmount → teardown.

Episode identity is ${sessionId}:${sessionGeneration}. Timer, opt-in, cartridge, and focus never cross this boundary.

Interaction and visual contract

  • No autoplay or automatic focus. Explicit Play may focus the canvas.
  • Escape works only inside the playing subtree; a visible Exit game button is mandatory.
  • Exit restores Play focus. Terminal teardown restores the monitor heading only when needed.
  • The signature brass trace rail communicates live research count above a fold-down drawer.
  • All colors, type, radius, shadow, spacing, focus, and motion read existing Antiek tokens.
  • At 320 CSS pixels and 200% zoom, the drawer is one column with no horizontal overflow.
  • No runtime image or generated layout. ChatGPT Image is provenance-anchored direction only.

Mechanical acceptance

  1. Policy tests exhaust hidden/waiting/offer/playing precedence.
  2. Host tests prove exact threshold, no pre-opt-in construction, focus, Escape, visible exit, repeated fresh cartridges, episode reset, timer cleanup, and external input isolation.
  3. Monitor integration proves partial cards and reconnect truth persist, then terminal state removes the lazy host in the same render.
  4. Reduced motion and disabled/invalid states do not render the lazy module.
  5. Focused/coupled tests, typecheck, token/type-scale lint, Storybook build, production build, bundle budget, diff/scope check, Hardenx, heterogeneous ACCEPT, and remote checks pass.
  6. A live browser checks offer, play, partial completion, terminal teardown, narrow viewport, both themes, keyboard focus, and reduced motion when a target is available; otherwise it is recorded as NOT PROVEN.

Strict non-goals

No standalone cabinet/route, selection, pause-research behavior, backend or reaction changes, persistence, leaderboard, telemetry, network, content inspection, model/spend authority, second mascot, generated runtime art, merge, or deployment. Primitive visuals are not the final Club Penguin or Black Ops craft pass.
