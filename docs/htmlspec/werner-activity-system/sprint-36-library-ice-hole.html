Library ice hole

Give the dormant Ice Fishing cartridge one honest, opt-in home in Read without inventing a wait or reopening Werner's gesture contract.

Parent context

This page is cold-executable; no other spec is required.

Antiek already ships a deterministic Ice Fishing cartridge and Werner's canonical fishing station, but only Paperclip Zombies has a product host. The Library is the Read door. Its shelf fetch is normally short and must not be mislabeled as a long-running wait.

Werner's mascot button already owns click-to-float, double-click-to-home, and drag-to-restation. This sprint must not add another mascot gesture. It adds a visible Library card whose game code and authored backdrop load only after explicit Play.

Goal

Mount Ice Fishing as an optional Library activity with an authored ChatGPT Image alpine-archive background, exact procedural fallback, focus-scoped input, Escape/button exit, station-instrument suspension, and reduced-motion play.

The game never claims import, shelf, or research progress. It mutates no book, research, budget, model, telemetry, or mascot state.

Five-values rigor

Intellectual honesty

Call this optional Library play, never “while importing” or “while loading.” The generated plate is atmosphere only; code owns every fish, hazard, score, control, and state transition.

Fairness

Keyboard, pointer, narrow viewport, and reduced-motion users receive a complete bounded path. The Library remains usable without playing and without image decode.

Rigor

Prove lazy chunk construction, exact image dimensions, late-callback inertness, lease release, focus restoration, deterministic rules, and authored versus procedural draw order.

Diligence

Exercise Play/Exit repeatedly, Escape from inside only, unmount during decode, route/window Library branches, image failure, mobile containment, and dark/light themes.

Defensibility

Record why Library card beats fake waiting, why mascot gestures stay closed, why a bitmap earns only background authority, and why no new backend or persistence exists.
