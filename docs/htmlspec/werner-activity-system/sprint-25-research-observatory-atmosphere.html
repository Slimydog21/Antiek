Hard-to-vary contract

  1. Only taxonomy Research routes mount the atmosphere.
  2. The bitmap contains no Werner, character, document, pseudo-text, graph, cursor, control, or semantic evidence.
  3. The layer is aria-hidden, empty-alt, pointer-inert, non-draggable, and paints beneath the existing frosted SceneChrome content.
  4. The original PNG is provenance-only; runtime uses a ≤128 KiB WebP and performs no network/provider call.
  5. Responsive cover crops preserve a calm HTML field at 768, 1024, and 1280 pixels.
  6. Read, Write, Speak, shared routes, Scene mood/Krea/time, activity selection, live Werner, research data, navigation, and accessibility semantics remain unchanged.

Acceptance

  1. Source tests prove Research-only mounting, exact layer order, decorative semantics, WebP identity, and byte ceiling.
  2. A dedicated Storybook plate proves real selectable HTML, native button semantics, and no bitmap product claims.
  3. Focused shell tests, TypeScript, production/Storybook builds, token/motion guards, scoped Lost Pixel, axe, HardenX, and heterogeneous review pass.
  4. No merge or deployment.

Withheld authority

No additional workflow plate, mascot/pose, animated/video stream, Krea/Modal call, generated document, hotspot map, route/activity change, second scene clock, content mutation, network, spend, merge, or deploy.
