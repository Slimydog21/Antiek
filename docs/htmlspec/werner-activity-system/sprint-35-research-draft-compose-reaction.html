Werner activity system · SPR-35

Let Werner bind reviewed research into one folio

After the server creates a genuinely new multi-research HTML draft for the still-current selection, play one distinct binding composition in the sole mascot.

Implemented Inline sprint

Parent context

My Research already lets the operator select completed investigations, inspect their exact content hashes, and ask the server to create a reversible HTML compose draft. The response truthfully distinguishes a new draft from an idempotently reused draft.

The Werner reaction bus is a closed semantic vocabulary translated by the sole WernerStage. This sprint adds one precise episode without adding a second mascot, route-local animation controller, raster identity, or content-authority claim.

Goal and authority path

operator reviews exact selected sources
→ createResearchCompose resolves
→ component remains mounted
→ requested selection is still current
→ response.reused is false
→ visible draft receipt commits
→ research_draft_composed
→ composed emote
→ three evidence slips bind into one folio
→ sole WernerStage

The episode means “a new reversible research draft was assembled.” It does not mean the sources agree, the analysis is correct, the draft was read, or the writing is finished.

Technical milestones

  1. Extend the closed experience and emote vocabularies with exactly research_draft_composed → composed, preserving exhaustive type checks and one stage.
  2. Build one token-native HTML/SVG composition: three evidence slips converge into a bound folio beside the canonical idle Werner; reduced motion shows the completed folio only.
  3. Emit beside the accepted response commit only when reused === false, the selection is unchanged, and the component is mounted.
  4. Extend semantic, bus, signal, stage, producer, reduced-motion, motion-home, and proof-sheet tests.

Five-values rigor

Intellectual honestyUse a binding folio, never the verification stamp: compose creation proves assembly and stable snapshots, not factual agreement or analytical quality. A reused idempotent draft is silent because no new product event occurred.
FairnessThe still frame must remain intelligible for motion-sensitive operators: show one completed bound folio and hide the in-flight slips. Do not make animation a prerequisite for understanding the receipt.
RigorMechanically prove click and preview silence, failure silence, reused silence, selection-drift silence, post-unmount silence, exactly-once current success, exhaustive maps, sole-stage translation, and a motionless meaningful still.
DiligenceReuse shellExperienceSignals, SemanticReactions, the canonical idle Werner raster, the shared proof sheet, and the existing compose freshness check. Keep the API decoder and compose backend unchanged.
DefensibilityThe semantic name records the server-created artifact; the prop depicts many reviewed slips becoming one reversible folio. Reconsider the metaphor only if compose changes from deterministic snapshot assembly into an AI-authored synthesis requiring a separate authority state.

Out of scope

No AI synthesis, source merging, correctness judgment, compose backend change, analytics, payload on the global event, queue/cooldown redesign, new mascot raster, sound, minigame, merge, or deployment.
