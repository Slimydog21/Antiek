Five values

Intellectual honesty

A microphone drawing is not permission, recording, consent, transcription, or stored evidence. Keep those absent in code and claims.

Fairness

Speak can have warmth and identity without simulating capability. A clear decorative metaphor is preferable to a fake waveform that implies live capture.

Rigor

Attack route prefixes, invites, biography classification, cursor hotspot geometry, descendant cursor cascade, hidden tabs, unmount, and reduced motion.

Diligence

Reuse the taxonomy and pointer sampler. Leave real voice capture, consent, reactions, games, and shared shell owners untouched.

Defensibility

Keep hashes and evidence classes; one inspectable route mapping; one contract without product authority; one explicit unproven visual gate.

Out of scope

  • Microphone permission, MediaRecorder, audio input, voice capture, transcription, consent, playback, transcript inspection, or network calls.
  • PenguinMascot, reactions, shell signals, games, hotspots, runtime generated poses, workflow taxonomy, navigation, spend, merge, or deploy.
  • Using the radio-studio PNG as a product surface or presenting its blank cards/equipment as data.
Capability rule: if the visual instrument needs a real voice API to feel honest, stop; that belongs to the separately governed Speak product, not station chrome.
