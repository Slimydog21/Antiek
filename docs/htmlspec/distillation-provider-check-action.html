Distillation Provider Check Action

Status: Cycle 97 implementation contract.

Purpose

Resolve an ambiguous paid distillation hold through one authoritative provider lookup without restoring dispatch, accepting client evidence, or advancing a fallback chain.

Trust boundary

  1. The authenticated owner submits only exact optimistic-concurrency terms copied from the reconciliation view.
  2. Provider, model, endpoint, credentials, approval, projection, route authority, evidence, status, and cents are server-owned and absent from the request schema.
  3. A server resolver composes the adapter and immutable authorities. Production fails closed when no resolver is configured.
  4. The route rebuilds the Cycle 96 gateway over the canonical runtime spend database; alternate ledgers cannot be injected by a resolver.
  5. The gateway re-proves owner, run, manifest, route, hold, approval, projection digest, route authority, database identity, and reservation lock before lookup.

State machine

  • charged settles exact provider cents.
  • not_found releases the hold.
  • unknown, malformed evidence, lookup failure, and authority drift retain the full hold.
  • Terminal replay is read-only and performs no provider lookup.
  • No path calls send_once or advances to another fallback.

HTTP contract

POST /research/distillation/commands/{request_event_id}/reconciliation/actions/check-provider

Foreign and missing resources are opaque 404s. Stale terms, unavailable authority, invalid transitions, and authority conflicts are value-free 409s. Unknown provider outcome returns the refreshed authoritative view with the hold intact.

Acceptance criteria

  1. Charged, not-found, unknown, terminal replay, stale terms, foreign owner, absent resolver, and forbidden request fields have executable tests.
  2. Each nonterminal action performs exactly one resolver call and at most one provider reconciliation call.
  3. Tests prove zero provider sends and no release when authority is absent or client terms are invalid.
  4. Ruff, focused pytest, compilation, diff hygiene, independent review, and HardenX pass before transport.
