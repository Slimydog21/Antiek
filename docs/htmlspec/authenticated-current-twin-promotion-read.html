Authenticated Current Twin Promotion Read

Cycle 118. Expose only currently authorized reviewed twin nodes and citations through a private server-owned boundary.

Request Authority

  • Verified Antiek session cookie or bearer authentication supplies owner identity.
  • The request supplies only one opaque candidate ID.
  • An immutable owner-keyed server registry pins canonical graph, lock, promotion, and twin file identities plus review verification authority; production defaults empty.
  • Each request reconstructs fresh read-only ledger readers and opens DuckDB read-only under the pinned coordinator lock.
  • Caller owner IDs, paths, review keys, text, metadata, citations, adapters, and provider data are impossible request fields.

Serving Contract

The handler acquires the canonical graph coordinator for one bounded verification window, then revalidates Cycle 114 through Cycle 117 authority before returning the exact current node and ordered hash-only citations. Absent, foreign, stale, malformed, or taken-down authority is one private 404. Runtime absence is private 503.

Privacy

Success, authentication denial, validation, method mismatch, namespace miss, not-found, and unavailable responses carry private, no-store, no-cache, and nosniff. Unverified Cloudflare identity headers are refused.

Acceptance

  • Exact owner success returns one node and its canonical-twin plus ordered evidence citations.
  • Wrong owner and absent candidate are response-equivalent.
  • Evidence drift and takedown withhold while historical rows remain.
  • Default registry is unavailable; no route mutates review, graph, twin, or citation authority.
  • Focused and coupled tests, strict typing, Ruff, HTML parsing, HardenX, and hostile review pass.

Threat Boundary

HTTP callers cannot choose or replace authority files. Canonical paths and inodes are checked before and after ledger opens and after projection. A process already able to mutate server-owned files under the Antiek OS account is outside this route boundary; eliminating an atomic replace-and-restore race requires process or container account isolation because Python SQLite does not expose its opened database descriptor and the twin authority may contain current WAL state.

Deferred

No review mutation, UI, embeddings/providers, public sharing, production registry configuration, merge, deployment, or spend.
