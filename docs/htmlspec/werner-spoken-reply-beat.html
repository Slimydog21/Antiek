Werner SpokenReply playback beat

Parent: Werner thought-partner response beat.

Intent: Spoken model replies make Werner visibly listen only when browser playback has actually begun.

Truth boundary

  1. Reuse voice_playback_started; do not add a synonym or a new pose.
  2. Emit once, after the initial audio.play() promise resolves for the current attempt.
  3. Never emit for synthesis failure, rejected playback, stop, unmount, or a superseded request.
  4. The Werner observer is best-effort: an animation failure cannot alter narration state.

Lifecycle contract

  • A monotonically increasing attempt owns every async continuation and media callback.
  • Stop, replacement, and unmount invalidate ownership before cleanup.
  • Cleanup detaches callbacks, pauses audio, and revokes the owned object URL.
  • Stale success and failure paths are silent and cannot resurrect UI state.

Proof

Focused hook tests cover successful truth, rejected play, stop during fetch/play, supersession, unmount, observer isolation, and resource cleanup; typecheck and production build remain green.
