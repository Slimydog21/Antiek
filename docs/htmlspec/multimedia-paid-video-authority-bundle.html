MSR-04A: Bind both paid cost views

Parent MSR-04

Spec lineage

    Schema

    Add frozen strict PaidRegisteredVideoCostAuthorityV1 containing schema version, one canonical cutoff, direct_cost_snapshot, and production_byte_projection. Add it to the hardening report without deleting the legacy/pre-production cost_snapshot field.

    Verification

    • Verify each child with its own key and requested owner/asset/revision.
    • Require child cutoffs byte-identical to the bundle cutoff and each other.
    • Require the projection receipt digest to equal the current production-link digest supplied by the trusted store.
    • Do not require disjoint execution IDs, total ordering, or total equality. Never emit a sum.
    • Reject local zero with either paid field, projection without direct, bundle with legacy direct, malformed extra fields, or key equality.

    Compatibility

    Legacy reports with neither, direct-only, or local-only authority reopen. Parsing does not make them current; store context decides current authority.

    Acceptance

    Wrong child key, owner, asset, revision, cutoff, receipt, MAC, schema, or cardinality fails before a pass report can be built.
