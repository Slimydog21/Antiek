Carry evidence into the outline at every workstation width

Below desktop width, replace the vanished repository with one brass field-kit tray. Selecting a provenance-bearing block reveals exact HTML insertion seams in the visible outline.

Executing

Verified gap

Current behaviorWriteHome hides the only BlockRepository below lg, while Outline still instructs the researcher to tap or drag repository blocks.
Persistence defectplaceBlock and moveBlock accepted an index as a sort hint without shifting neighbors. Occupied seams could therefore create duplicate indexes, so the UI could not truthfully promise an exact final position.
Product consequenceThe evidence-to-outline-to-draft loop is broken at 768–1023 px and imprecise for tap placement at every width.

Hard-to-vary episode

  1. A clipped brass Evidence blocks tab exists only below lg; desktop retains its sole repository sidebar.
  2. The tab opens a focus-contained, Escape-dismissable field-kit tray that reuses BlockRepository verbatim.
  3. Selecting a repository block closes the tray and shows its human label plus insertion seams before, between, and after blocks in every section.
  4. Committing a seam calls placeBlock once with that section and exact index. Failure leaves the selection active and offers a truthful retry; cancel performs no write.
  5. Every existing outline block gets a dedicated keyboard-operable move grip. It invokes the same seams and commits through moveBlock once; native drag remains available.
  6. Text and provenance remain visible; node and outline IDs never render.
  7. Werner stays fixed, the Write nib keeps cursor authority, and no mascot/reaction event is added.

Design direction

Subject: a professional researcher arranging evidence in an alpine scriptorium. Single job: put a known source block at a known argument position. The one aesthetic risk is the clipped brass field-kit ticket: sun yellow, ink border, mono provenance stamp, Charter evidence copy. The tray itself stays dense and square-edged; no generic rounded bottom sheet, gradient, glass blur, or ornamental motion.

Acceptance

  1. Responsive visibility, focus return/trap, Escape, and backdrop close are tested.
  2. Exact first/middle/last and cross-section placement and movement are tested, including failure and cancel silence.
  3. Existing desktop tap-to-last and native drag paths remain intact.
  4. Reduced motion adds no animation; keyboard and accessible names cover every action.
  5. Focused/coupled tests, TypeScript, design lints, production/Storybook builds, 52-story axe, visual plates, HardenX, and independent refutation pass.

Persistence contract

The existing place and move endpoints retain their shapes. Their index becomes the final visual position: insert shifts occupied neighbors; move removes the block, compacts its source, clamps the requested destination, and inserts it once; removal closes the vacated seam. Typed events record the resolved final index. Single-writer locking remains the concurrency authority.

Non-goals

No generated image, new endpoint, generic sortable framework, section reorder, AI suggestion, auto-scoring, editor/generation change, analytics event, cursor instrument, Werner pose/reaction/dialogue, settings, model spend, merge, or deployment.

Critic mandate

Try to prove duplicate repositories, wrong index math, ID leakage, focus escape, optimistic mutation, failed-write data loss, inaccessible move controls, mobile-only regression, or a second authority.
