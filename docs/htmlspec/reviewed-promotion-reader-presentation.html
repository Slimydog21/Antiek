Owner-private reviewed insight and evidence reader

Executable presentation contract stacked on Cycle 119 commit 634a0aa81. This sprint turns verified canonical twin HTML and current reviewed promotion APIs into one usable reading surface without granting the browser authority.

Outcome

An authenticated owner opens /read/twin/:sourceAssetId?revision=:sourceHash, reads the exact server-sanitized advisory HTML, scans current owner-reviewed insights and questions, and expands exact ordered citation proof on demand. The surface is read-only and revision-exact.

The client MUST reject cross-origin, malformed, or non-canonical private hrefs. It MUST compare source/revision and summary/detail identities before rendering. It MUST NOT derive owner IDs, candidate IDs, review IDs, paths, keys, graph rows, citation rows, or confidence.

Interaction states

  • Missing revision: no network request; direct instruction to use an exact canonical link.
  • Loading: one quiet status; no stale prior revision remains visible.
  • Ready with notes: sanitized HTML plus reviewed margin.
  • Ready empty: explicit zero reviewed notes for this exact revision.
  • Collection unavailable or contradictory: no document or partial collection disclosure.
  • Detail unavailable, stale, reordered, or contradictory: summary remains, proof is withheld.
  • Retry: reloads canonical twin and complete collection together.

Presentation

Desktop uses a calm reading plane and fixed-width proof margin separated by a structural rule. The proof margin uses insight/question icons and one ordinal citation spine. At 860px and below it becomes a full-width section after the document. Text wraps at arbitrary identifiers; buttons retain stable dimensions and visible focus. Motion is limited to the disclosure chevron and disabled under reduced motion.

Acceptance

  1. Typed API tests prove URL encoding, credential inclusion, and strict same-origin private href following.
  2. Component tests prove ready, empty, missing-revision, unavailable/retry, lazy detail, identity conflict, and citation-order conflict behavior.
  3. TypeScript, focused Vitest, production build, token/type lint, and diff check pass.
  4. Deterministic Storybook states cover reviewed, expanded proof, empty, loading, and unavailable behavior without live network; rendered audits exercise desktop and narrow layouts.
  5. Rendered desktop and mobile audits show no overlap or horizontal overflow; keyboard expansion and focus are operable.
  6. HardenX reports no unwaived real finding and independent hostile review returns no actionable finding.

Non-goals

No review mutation, graph mutation, evidence excerpt bytes, arbitrary document navigation, public sharing, browser authority, embedding/provider qualification, live spend, production data mutation, merge, or deployment.
