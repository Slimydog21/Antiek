MSR-03: Explicit Local Zero-External-Cost Authority

Parent program

Goal

Admit zero external provider cost only from completed, MAC-verified local production rows and their exact production receipts.

Requirements

  • Support local video narration/render and local AudibleRun as separate run kinds.
  • Verify owner digest, asset, exact revision, terminal registered status, coordinator row MAC, config/input digests, production receipt digest, and current production link.
  • Emit integer external_cost_cents=0; remove float cost_usd=0.0 from any authoritative decision.
  • No provider execution rows may be silently ignored. A mixed local/paid closure requires explicit constituent evidence.
  • Missing run, incomplete/recovery-required state, wrong owner/revision, bad MAC, changed executable identity, receipt mismatch, or ambiguous run blocks readiness.

Non-goals

No valuation of local compute, electricity, operator time, or hardware depreciation. The claim is zero external provider charge, not zero economic cost.
