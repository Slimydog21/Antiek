MSR-03: Explicit Local Zero External Provider Cost

Parent program

Spec lineage

Child program under the multimedia ship-readiness cost authority.

  • MSR-03A: registered local video authority
  • MSR-03B: registered local audio authority
  • MSR-03C: paid-row exclusion
  • MSR-03D: immutable zero evidence
  • MSR-03E: hardening fallback integration

Decision

Zero is evidence, not absence. Antiek may assert external_cost_cents=0 only after reopening the current registered local production authority, its exact receipt and production link, current executable/config identity, and a bounded provider-execution exclusion scope. The assertion means zero external provider charge for this production path. It does not value local compute, electricity, hardware, or operator time.

MSR-03 creates a separately labeled local_registered_zero_external_provider_charge snapshot. It does not add an empty row set to direct_settled_provider_executions or production_byte_contributing_settled_provider_executions.

Authority graph

  1. The authenticated current asset and exact revision select video or audio. Callers supply no run ID, receipt path, digest, status, or cost.
  2. Video requires exactly one registered local video row and its referenced local narration row. Audio requires exactly one registered local audible row.
  3. Every selected row is shape-checked, MAC-verified, deterministically identified, owner/asset/revision bound, terminal, and bound to the coordinator's current config digest and executable identity.
  4. The coordinator reopens the exact receipt and nested media authorities, then compares its digest to both the terminal row and the current production link.
  5. A read-only DuckDB snapshot proves there are no provider execution rows in the declared parent and deterministic child revision scope.
  6. An independent snapshot key signs the immutable zero-external-cost evidence. Hardening accepts it as an alternative authority, never alongside a paid snapshot.

Refusal taxonomy

  • evidence_unavailable: no exact run, no table, incomplete or recovery-required state, ambiguous cardinality, missing receipt/link, or unsupported mixed scope.
  • evidence_conflict: bad MAC, deterministic ID mismatch, owner/asset/revision/config contradiction, changed executable, artifact or receipt tamper, link mismatch, duplicate authority role, or any provider execution row in scope.
  • The builder performs no schema creation. Missing local databases are not created. No read path takes a write lock.

Rejected alternatives

  • No provider rows means zero: rejected because missing or unreadable accounting owns no claim.
  • Reuse the paid projection with zero constituents: rejected because that changes the meaning and verifier invariants of a shipped evidence label.
  • Trust cost_usd=0.0 on artifacts: rejected because it is a descriptive float, not a reopened accounting authority.
  • Add a local discriminator to the production link: rejected for v1; the terminal MAC row and exact receipt already own provenance, while a link flag would be a second truth.
  • Query every revision for the asset: rejected because unrelated historical work would poison the exact revision. The exclusion scope must be explicit and reproducible.

Global acceptance

  • Video happy path binds local narration plus local video rows, receipt bytes, media bytes, current link, and zero provider rows.
  • Audio happy path binds the local audible row, receipt bytes, audio bytes, current link, and zero provider rows.
  • Missing, malformed, ambiguous, in-flight, tampered, stale, cross-owner, cross-revision, changed-executable, mixed-provider, duplicate, and post-cutoff cases fail closed.
  • Focused tests, adjacent coordinator/playback/registration/hardening tests, Ruff, strict mypy, HTML parse, diff hygiene, heterogeneous review, and hardenx pass.

Five-values rigor

Intellectual honesty: zero names only external provider charge. Fairness: local work is not described as economically free. Rigor: every authority is exact and independently verifiable. Diligence: video, audio, paid-row, race, and legacy surfaces are covered. Defensibility: the evidence records its basis, scope, cutoff, run authorities, receipt, link, and limitation.

Out of scope

No local-resource valuation, arbitrary historical reconstruction, mixed paid/local allocation, provider invoice truth, refund workflow, new ledger, provider call, recovery, render, registration, route mutation, publication, or automated rights approval.
