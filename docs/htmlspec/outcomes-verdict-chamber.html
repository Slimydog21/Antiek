Outcomes Verdict Chamber

Turn canonical /outcomes/:synthesisId into a calm, authored operator judgment station without nudging a verdict or changing outcome persistence and downstream authority.

Spec lineage

Root bounded cycle spec. One surface, one transport seam, one verification lane.

    Egghead verdict

    High confidence: visual polish is harmful if it makes one judgment feel safer, brighter, more central, or more successful. The redesign survives only with identical choice geometry, typography, elevation, focus treatment, and neutral materials. Semantic color may annotate already-recorded history; it may not steer the pending choice.

    Strongest counterargument: this narrow form does not need atmosphere. It survives because the route currently exposes consequential authority with implementation-flavored copy, no frontend tests, no whole-surface fixture, and no narrow or accessibility proof. The raster remains decorative and symmetrical; HTML retains all authority.

    Five values

    Value Binding decision Proof
    Intellectual honesty Describe recorded judgments and feedback effects without naming internal file paths or promising automatic improvement. Copy assertions and hostile review.
    Fairness Validated, falsified, and indeterminate receive identical pending-choice geometry, order weight, and neutral styling. DOM/class assertions and rendered review.
    Rigor Inject load/submit transports and synthesis ID for deterministic tests; production defaults remain the existing API paths. Focused behavior tests.
    Diligence Exercise loading, empty, populated history, failure, night, and 375 × 667 narrow states. Story index plus axe/overflow harness.
    Defensibility The generated environment contains no verdict semantics, evidence, counts, or controls; its provenance records exact generation. Asset README and inert decorative markup.

    Acceptance contract

    1. One main owns the route; the fixed raster and veil are pointer-inert, empty-alt, and aria-hidden.
    2. The pending choice uses one shared component and one shared neutral class for all three verdicts; labels are the only difference.
    3. Submitting is disabled in every story by a render-level hard lock that URL args cannot override.
    4. Missing synthesis ID, load failure, submit failure, empty history, populated history, and submitting state retain truthful copy.
    5. At 375 × 667, choices stack and neither the document nor component overflows horizontally.
    6. Production defaults preserve GET and POST endpoints, request shape, default note, reload, and backtest link behavior.

    Technical seam

    • Export an OutcomesProps contract with optional synthesis ID, load transport, submit transport, and execution flag.
    • Keep production defaults as thin functions over the current apiFetch calls.
    • Stories inject deterministic results and force executionEnabled=false after the args spread.
    • Tests prove balanced choice classes, production-default request shape, inert fixtures, safe failure, and decorative semantics.

    Rejected alternatives

    • Traffic-light choice colors: green/red/grey pre-bias the operator before evidence is judged.
    • Put verdict symbols in the raster: duplicates semantics in inaccessible, non-responsive pixels.
    • Automatic model recommendation: invents grading authority and undermines operator observation.
    • Rewrite backend outcomes: unrelated to the visual/evidence gap and risks downstream skill-growth behavior.
    • Clickable Storybook mutations: review infrastructure must not persist operator judgments.

    Out of scope

    Outcome API/schema/backend/gate semantics, observer identity, skill-growth logic, backtest behavior, automatic grading, scoring weights, mascot movement, merge, deploy, and spend.
