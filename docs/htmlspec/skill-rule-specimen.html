Skill Rule Specimen

Carry the Skill Rule Conservatory into canonical /skill-rules/:ruleId. Reuse the conservatory art as decorative continuity; native HTML owns the promoted rule and audit metadata.

Goal and catastrophic failure

Goal: expose one normalized practice and exactly what its stored promotion record establishes and does not establish.

Catastrophic failure: promotion reads as universal truth; confidence reads as probability; contributor count reads as popularity; ε reads as quality; private identity/source content appears; malformed transport becomes fabricated metadata.

Five-values acceptance

  1. Truth: no promotion signal becomes a stronger claim.
  2. Legibility: full rule and ID wrap at 375px.
  3. Agency: clear return links and retry only at system failure.
  4. Restraint: same environment and canonical Werner; no new asset, gauge, or score.
  5. Continuity: API/route unchanged; pure view powers deterministic stories.

Proof and non-goals

Stories: ready, loading, 404, error, malformed record, unknown metadata, long content, narrow, night. Tests: epistemic boundary, measurement semantics, privacy boundary, ID/navigation, all states, retry, malformed handling. Gates: focused tests, TypeScript, production and Storybook builds, axe/overflow/visual CI, security and merge review.

Non-goals: index changes, API/schema, promotion math, contributor identity, private provenance retrieval, confidence calibration, rule editing/deletion, Antiek-bench integration, global shell.
