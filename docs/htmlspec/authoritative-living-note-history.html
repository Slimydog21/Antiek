Inspectable authoritative living-note history

A researcher must be able to inspect how a living note changed without mistaking an attempted or legacy refinement for current truth.

Sources of truth

  • The live graph node supplies current text, investigation ownership, and total applied refinement count.
  • The transactional write_event_outbox supplies immutable refinement outcomes in commit order and is validated against each row's SHA-256 before use.
  • The delivered JSONL stream is a projection for replay and broadcast, not a prerequisite for this read model.
  • Only complete typed note.refined outcomes for the exact investigation and graph node enter history.

Authority and completeness

  • An applied outcome records the authoritative transition from previous text to new text.
  • A superseded outcome is shown as a rejected attempt and never as a historical version of the note.
  • History is complete only when authoritative applied outcomes equal the graph node's durable refinement count.
  • A lower authoritative count is returned and rendered as known-partial history; missing legacy bytes are never reconstructed or guessed.
  • An impossible excess count, digest mismatch, malformed typed event, identity mismatch, or invalid outcome chain fails closed as an integrity error.

Transport and interaction

  • GET /research/notes/{node_id}/history?investigation_id=... is read-only and returns current text, counts, completeness, and ordered outcomes.
  • A foreign or missing note returns the same not-found response and leaks no history.
  • The same investigation membership guard also rejects foreign challenge commands before journal claim or resolver dispatch.
  • The completed-research insight row lazily loads history through an explicit disclosure; no background request is made for collapsed history.
  • The compact timeline labels applied changes and superseded attempts distinctly and exposes a retryable failure state.

Acceptance

  • Applied and superseded outcomes are ordered by durable outbox sequence, independent of JSONL delivery state.
  • Corrupt bytes and cross-investigation or cross-node substitutions never reach the response.
  • Legacy count mismatch is visible as incomplete, not silently treated as full history.
  • Opening, closing, and reopening the disclosure does not duplicate entries or mutate graph state.
  • No provider call, graph write, event emission, sequence decision, spend authority, or child research launch is added.
