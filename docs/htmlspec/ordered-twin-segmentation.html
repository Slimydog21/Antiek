Ordered Twin Segmentation and Parent Aggregation Contract

Status: execution contract. This sprint creates no provider transport and no completion authority.

Outcome

An oversized canonical document has one deterministic, lossless, ordered segment manifest and one durable parent aggregate obligation. Segment work is intermediate. It can never satisfy the document twin or corpus universality.

Invariants

  • Every source character belongs to exactly one contiguous segment, in source order, with no truncation, overlap, gap, normalization, or duplicated body storage.
  • Each segment is at most the materializer ceiling. Newline boundaries are preferred by a versioned algorithm; long lines use a deterministic bounded fallback.
  • The manifest commits to tenant, asset identity, title, class, source events, complete body, every range, every segment hash, algorithm version, and one aggregate obligation.
  • Execution must rederive the manifest from current canonical bytes. Hashes are evidence, not a substitute source.
  • The registry stores hashes, ranges, and canonical metadata only. Legal takedown leaves no hidden source-body copy.
  • All segment obligations and the parent aggregate obligation are created in one SQLite transaction and remain pending in this transport-free sprint.
  • No API can mark the parent ready. A future sprint must bind authorized segment receipts and one exact aggregate completion before coverage can become universal.

Future Aggregate Sprint

  1. Verify each segment against current canonical bytes immediately before authorized dispatch.
  2. Bind each signed segment completion to manifest hash, index, range, and content hash.
  3. Generate the parent proposal from the ordered complete set under a separately approved budget hold.
  4. Bind one parent twin to the exact original source identity; never register segment twins as canonical document twins.
  5. Cancel or quarantine pending obligations when canonical bytes are legally removed; never infer completion from stale commitments.

Acceptance

Boundary, long-line, drift, tenant substitution, replay, concurrency, corruption, restart, privacy, and false-completion tests pass. The control plane records that final aggregation and takedown lifecycle mutation remain unimplemented authority.
