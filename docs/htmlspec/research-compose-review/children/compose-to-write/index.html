Bind a reviewed folio into Write

Turn one immutable multi-research compose into one editable analysis workspace without generating prose, spending money, or weakening provenance.

Ready1 serial sprintZero model calls

Spec lineage

Parent: Research compose review. This child begins only after the parent has produced a reviewed immutable compose.

  • No child specs. The boundary is intentionally one bounded vertical slice.

Goal and success

  • The frozen member HTML, not a rebuilt live artifact, selects source node identities.
  • One explicit action yields one stable Write workspace and a durable link back to the compose.
  • Shared node identities appear once in first-seen order; deleted nodes remain visible as unavailable provenance.
  • The response and UI say exactly what happened: members, occurrences, unique blocks, duplicates, conflicts, and unavailable sources.
Failure mode: a polished “analysis” action that silently rereads live research, invents a single root, duplicates evidence, dispatches a model, or creates a second workspace on retry.

Architecture

immutable compose manifest + members/*.html → validate schema, member identity, canonical content hash → ordered frozen node occurrences → first-seen node dedupe + live type/liveness lookup → atomic deliverable + section + provenance blocks + compose mapping → explicit /write/:deliverableId link (no generation)

Load-bearing invariants

  • investigation_root_id = NULL: the source is plural; the compose mapping is authoritative.
  • Frozen bodies choose IDs; live graph may only classify type and dangling state.
  • Idempotency is enforced by a unique compose mapping, not a JSON metadata search.
  • Workspace creation, mapping, and blocks commit together; retries never delete or reset user edits.

Open questions resolved by operating defaults

Default title: “Analysis of N researches.” Default kind: research_memo. Empty but valid frozen sources create an honest empty workspace. A retry with a different title/kind returns the existing workspace unchanged.
