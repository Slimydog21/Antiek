Master spec · ANT-RCR-01

Research compose review

Turn several finished researches into a reversible, provenance-exact HTML light table before any semantic synthesis.

Executed1 sprint · 1 wave2026-07-15

Goal

A researcher selects two or more completed investigations in the canonical research log, reviews every member’s exact canonical hash and any identical-content pairing, then creates an immutable HTML index that preserves each source separately.

Success criteria

  • No LLM, dispatcher, source overwrite, or artifact event runs.
  • A stale preview fails closed with HTTP 409.
  • No host path or file:// URL reaches the browser.
  • Keyboard users can select, review, create, and open the draft.

Failure mode to avoid

Calling a concatenated body “merged research,” hiding provenance changes or implying synthesis that never happened.

Product and architecture

The signature interaction is an editorial light table: check finished dossiers, raise a compact bottom tray, inspect their exact spines (IDs + full hashes), then bind them into a reversible folio.

completed investigation rows → POST /research/artifact-composes/preview (no writes) → exact ordered fingerprint + identical-content review → explicit confirmation → POST /research/artifact-composes (stale check + atomic write) → authenticated HTTP index → hash-locked member HTML

Key invariants

  • Ordered member IDs plus canonical hashes plus schema version define identity.
  • Member bodies remain separate and source mutations are surfaced, never silently regenerated.
  • Only server-derived compose IDs name persisted files.
