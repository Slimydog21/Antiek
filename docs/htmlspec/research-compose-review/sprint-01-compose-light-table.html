Compose light table and immutable HTML draft

Select, inspect, freeze, and serve a multi-research folio without pretending to synthesize it.

Wave 1Executed5 milestonesOwner: primary orchestrator

Parent context

Antiek already exports a canonical ResearchArtifact body and had a CLI compose page. That page overwrote member exports, linked through file://, exposed no HTTP contract, and was absent from the workstation.

This sprint activates the user’s “select multiple finished deep researches, merge their instances, inspect before fully merging” workflow at its honest first boundary: an exact HTML index. Semantic analysis remains a later, separately consented action.

Goal

Ship one reversible editorial compose episode from My Research to served HTML.

Rigor — operating manual

1 · Intellectual honesty

Call equal hashes “identical canonical content,” not cryptographic collisions; never label the index a synthesized analysis.

2 · Fairness

Steelman a one-click LLM merge: it feels magical, but hides spend and provenance. Keep it as a later explicit action.

3 · Rigor

Change a member between preview and create and require 409; inspect HTML for both file:// and artifact-root leakage.

4 · Diligence

Reuse ResearchArtifactBody.content_hash(), global auth middleware, Lemon controls and the canonical research list.

5 · Defensibility

Persist schema version, ordered IDs and full hashes so a future maintainer can reconstruct why two drafts differ.
