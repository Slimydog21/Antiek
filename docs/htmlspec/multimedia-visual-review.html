Preview and attest a generated visual

Child of the quarantine spec. It exposes private bytes for owner review and signs generated provenance only after an explicit action. Neither action creates a final reviewed set.

Preview

GET /multimedia/assets/{asset_id}/visual-candidates/{candidate_id}/content?revision_id=... derives the quarantine receipt from candidate ID, verifies receipt MAC/file bytes and signed execution owner/asset/current revision, and returns the exact image with Cache-Control: private, no-store and X-Content-Type-Options: nosniff. Paths, digests, and provider data remain server-side.

Attestation

POST .../attestation accepts expected revision and explicit generated-provenance acknowledgement only. The authenticated owner becomes the reviewer identity. The server repeats all receipt/execution checks and invokes the existing Ed25519 generated-attestation authority. Exact replay returns the same safe receipt/reviewer/time; changed reviewer or bytes conflict.

Separation

Preview is not approval. Generated-provenance attestation proves origin and bytes, not aesthetic quality. Final chapter/candidate selection remains the reviewed-visual-set command.

Non-goals

No provider network, generation, download, automatic attestation, browser path/digest/reviewer control, final selection, renderer, publication, merge, or deploy.

Done bar

Foreign, stale, tampered, symlinked, unacknowledged, or mismatched candidates fail closed. Headers and safe response are exact. Keys are independent and startup is all-or-nothing. Broad tests, lint, HardenX, and independent review pass.
