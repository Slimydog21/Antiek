Biography Memory Archive

Make the biography template feel like one humane place for research, writing, and gathered voices while keeping every authority boundary exact.

Status: executableBase: #2756 @ cf72b58811 inline sprint · 7 milestones

Spec lineage

Root cycle spec derived from the Antiek vision and a live audit of canonical /biography. No child specs; route behavior, stories, atmosphere, and recovery share one seam.

    Egghead verdict

    Proceed, but do not invent a fifth biography product or promise persistence the API cannot project. The current template correctly composes Research, Write, and Speak. The load-bearing defect is partial composition: if Research succeeds and composition fails, retry starts another investigation. The visual intervention survives only if it repairs that truth boundary.

    Goal and catastrophic failure

    Give the operator a Werner-led Antarctic memory archive with deterministic landing, preparing, recoverable-partial, failure, composed, inviting, invite-failure, link-ready, night, and narrow states.

    Failure mode: an attractive page that duplicates research folders, claims an invite was delivered, suggests memories were captured before they were, exposes raw transport details, or turns the decorative raster into semantic evidence.

    Authority topology

    operator name → startInvestigation (once) → confirmed investigation id
confirmed investigation id → createBiography → Research + Write + Speak composition
retry after composition failure → reuses confirmed investigation id
makeShareLink → link created (not sent, delivered, accepted, or used)
raster + Werner → decoration/reaction only

    Technical milestones

    1 · Freeze injectable states

    Optional initial state and execution lock make stories transport-inert.

    2 · Recover partial composition

    Keep the confirmed investigation in component state and retry only composition.

    3 · Clarify authority

    Say “link created,” never sent, delivered, accepted, or memory captured.

    4 · Author the archive

    Use the empty ChatGPT Image environment as pointer-inert atmosphere and live Werner moods.

    5 · Complete semantics

    Named controls, live status, focus, copy fallback, and keyboard-complete actions.

    6 · Prove responsive/night

    375×667 layout, no horizontal overflow, forced night selector, reduced motion.

    7 · Test transitions

    Assert no duplicate investigation on retry, no transport in stories, exact navigation, and invite truth.

    State matrix

    StateRequired truth
    LandingNo project exists; name input and three-part explanation.
    PreparingOne disabled action, Werner thinking, status announced.
    Research confirmed / composition failedFolder is safe; retry reuses its id; subject stays locked.
    ComposedThree exact destinations; no claim that sources or voices exist.
    Inviting / failed / readyLink creation only; no delivery or participation claim.
    Night / narrowReadable, focusable, zero horizontal overflow.

    Five-values rigor

    Honesty

    Do not call the composition durable across reload; no read API exists. Do not treat a share-link response as delivery.

    Fairness

    Preserve the template-not-fifth-product decision; a dedicated biography store would make gathered voices a silo.

    Rigor

    Drive the failure between startInvestigation and createBiography, then assert retry call counts and the reused id.

    Diligence

    Keep exact routes and APIs; inspect Speak invite and Write composition semantics before changing copy.

    Defensibility

    Asset provenance and rejected claims live in the repo; stories use execution lock rather than mocked optimism.

    Rejected alternatives and non-goals

    • Dedicated biography graph/store: rejected; destroys the shared knowledge substrate.
    • Automatic cleanup of a confirmed investigation: rejected; no authorized delete contract.
    • Persist partial recovery in localStorage: rejected; local browser state cannot become server composition truth.
    • Raster portraits/timelines/text: rejected; semantic and consent ambiguity.

    Non-goals: APIs, schema, consent, publishing, email delivery, interview capture, editor, navigation shell, global mascot/cursor, backend, merge, deploy, spend.

    Verification gates

    • Focused Biography tests including partial retry and failure preservation.
    • TypeScript, Storybook production build, diff check, token/type gates where applicable.
    • Deterministic stories for the complete state matrix; focused axe/overflow proof if browser available.
    • Two hostile review rounds and hardenx strict with zero unwaived REAL findings.

    Harness hint

    Implement inline; use independent read-only critics after tests. Minimum two sharpen rounds, maximum four.
