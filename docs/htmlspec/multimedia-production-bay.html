Multimedia Production Bay

Turn canonical /multimedia into an authored polar production workstation while preserving every existing evidence, revision, spend, provider, review, and playback boundary. The environment is atmosphere; executable authority remains real HTML and existing code.

Spec lineage

Root bounded cycle spec. No child decomposition is warranted: one visual shell, one deterministic story seam, one verification lane.

    Egghead verdict

    High confidence: a generated background cannot honestly satisfy the operator's live-model/Flipbook ambition. It can make today's capable workstation feel authored and establish the responsive visual grammar future streaming scenes must preserve. Do not simulate streaming, provider availability, evidence, or media output in pixels.

    Strongest counterargument: this is cosmetic work on a 1,796-line screen. It survives only because the route currently has no whole-surface visual, responsive, or accessibility evidence, and because the change leaves all functional branches intact while making that evidence deterministic.

    Intellectual honesty Keep “estimate”, “example”, “dry run”, missing receipt, and provider-down language. Add no live-stream claim. Copy assertions and hostile review.

    Acceptance contract

    1. The root owns exactly one main and a decorative fixed environment with an inert veil.
    2. Three workstation regions remain real HTML and collapse without horizontal overflow at 375 × 667.
    3. Day and night preserve readable contrast over the image; image failure leaves an intentional surface.
    4. Reduced motion disables ambient transitions; it does not disable controls or change authority.
    5. Whole-surface stories perform no live API calls, expose no enabled execution control, and name every audited state exactly.
    6. Existing multimedia tests remain green; focused tests prove decoration, landmark, safe error copy, and injection scope.

    Rejected alternatives

    • Stream generated frames now: requires latency, interaction-map, GPU, websocket, auth, cost, and safety architecture absent from this bounded visual cycle.
    • Replace the workstation with an image: destroys accessibility, provenance, precision, and exact controls.
    • Rewrite the 1,796-line component: risks mature execution authority for no visual necessity.
    • Put Werner in the raster: forks mascot identity and prevents live asynchronous behavior.
    • Use Krea or Modal during stories: creates spend and nondeterminism in review infrastructure.
