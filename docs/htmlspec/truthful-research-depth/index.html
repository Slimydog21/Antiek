Truthful Research Depth

Make Antiek’s Fast/Deep choice control upstream investigation work without exposing raw provider or model authority.

Status: executedOwner: Infinite orchestrator1 sprint · 1 wave

Goal

The selected, persisted research tier must reach decomposition, evidence retrieval, parameter extraction, and graph connection through the existing dispatch router. Final synthesis remains independently pinned.

  • Fast and Deep resolve only through substrate/dispatch/research_tier.py.
  • Missing or malformed legacy metadata preserves each role’s configured route.
  • The UI makes the synthesis boundary and unknown investigation cost explicit.

Failure to avoid: a control that records intent but never changes execution, or a client-authored provider/model pair that enables model smuggling.

Architecture

StartResearch fast|deep │ persisted start event ▼ bounded immutable metadata lookup │ server-owned provider/model target ├── decomposer ├── evidence retriever (parallel) ├── parameter extractor └── connector synthesizer ── independent configured reasoning pin
  • The start event is the only investigation-scoped authority.
  • Raw provider/model values never enter the public request contract.
  • A bounded cache prevents repeated synchronous trajectory scans.
