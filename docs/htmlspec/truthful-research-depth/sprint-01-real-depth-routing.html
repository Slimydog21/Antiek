Real depth routing

Turn the existing research-depth choice into provable upstream dispatch authority while preserving synthesis isolation.

Wave 1 · Status: executed · Budget: 5 milestones · Owner: Cycle 590 workhorse + orchestrator

Parent context

Antiek is a Python/FastAPI research backend with append-only investigation events and a React/Vite reading application. POST /investigations already persists research_tier: fast|deep, but the four generic Loop 1 role bridges did not consume it.

The dispatch router accepts server-side provider/model overrides. The public API must remain a closed tier label; synthesis must keep its independent configured reasoning route. Run Python checks with /Users/slimydog/Antiek/platform/.venv/bin/python and frontend checks from apps/reading.

Goal

A selected Fast or Deep tier changes all four upstream research role dispatches and nothing else.

Technical milestones

1 Shared immutable resolver. Read the original start event, reject non-closed values, preserve defaults when absent, and cache the result with a bounded capacity.
2 Four dispatch seams. Pass the resolved target to decomposer, evidence retriever, parameter extractor, and connector.
3 Synthesis boundary. Retain and test (None, None) for Fast and Deep in the synthesizer.
4 Truthful UI. Describe upstream effect, disclose dedicated synthesis, and remove the static dollar range.
5 Mechanical proof. Cover ordering, legacy metadata, cache behavior, all four keyword seams, accessibility, and type/lint gates.

Rigor — operating manual

Do not call the static estimate a projection. If the full investigation cannot be priced, say cost depends on sources and work.

Fairness

Steelman the opaque route chooser: it is stronger long-term, but unsafe until route IDs are server-issued, re-resolved, allowlisted, and budget-checked.

Rigor

Tests must include unrelated and duplicate start-like events, all four dispatch seams, missing metadata, both tiers, and the synthesis pin.

Diligence

Use the existing event trajectory and resolve_research_tier; do not duplicate mappings or invent a second dispatcher.

Defensibility

Keep the synthesis policy and future opaque-route requirements in the master decision log so later agents can reconstruct the boundary.
