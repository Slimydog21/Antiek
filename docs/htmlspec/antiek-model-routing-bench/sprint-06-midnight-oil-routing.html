SPR-06 Midnight Oil Routing Contract

Back to master spec

Goal

Midnight oil runs are autonomous research swarms with explicit time, goals, model route policy, and approved price ceiling.

Request Contract

{
  "goal": "Explain the aircraft supply-chain bottleneck for widebody engines.",
  "work_minutes": 120,
  "price_ceiling_usd": 25.0,
  "route_mode": "auto_balanced",
  "source_policy": ["arxiv", "substack", "web", "operator_corpus"],
  "deliverable": "html_research_asset",
  "operator_acknowledged_spend": true
}

Execution Invariants

  • No spend starts without explicit operator acknowledgement and a ceiling.
  • Each subagent inherits the parent ceiling as a remaining-budget allocation.
  • Every subagent answer has route receipts and source receipts.
  • Output is an Antiek HTML information asset plus a twin note document.
  • Research and reading spawned from the output reuse the same asset/thread contract.

Acceptance Tests

  • No-ack request is denied before dispatch.
  • Budget allocation sums never exceed parent ceiling.
  • Mock swarm emits route receipts for planner, gatherer, verifier, and synthesizer roles.
  • Final artifact is HTML, not PDF, and carries source/route receipt links.
