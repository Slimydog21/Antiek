SPR-03 Decision Tree Settings UI

Back to master spec

Goal

Settings gets a practical decision tree for model choice: manual driver, auto objective, budget bars, and prompt impact preview.

UI Requirements

  • Provider/model table: ready state, primary model, tier bindings, and notes.
  • Budget bar: daily cap, spent, remaining, unknown/no-cap states.
  • Prompt estimator: paste/query prompt, expected output size, task kind, route mode.
  • Recommendation: selected provider/model/tier, estimated cost, why chosen, cache caveat.
  • Override control: choose a model manually and see budget impact before submit.

Acceptance Tests

  • Settings renders no-cap, unknown-spend, and cap-exceeded states without layout overlap.
  • Changing task kind changes the request sent to the estimator.
  • Manual override displays selected model and disables auto recommendation text.
  • Screen-reader labels describe budget and selected route without relying on color.
