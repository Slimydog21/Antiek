SPR-02 · Wave 2 · topology-gated

Let official clients keep their credentials

Goal: offer Codex/Claude subscription-backed work only through user-owned official local processes, with typed capability/auth state and no token extraction.

Parent context

T3Code’s useful lesson is process delegation: Codex app-server and Claude Agent SDK own login and provider traffic. This is not suitable as a shared server identity for friends, so the transport must bind to a user-owned workstation or isolated user sandbox.

Technical milestones

  1. Ratify topology: local companion process or per-user sandbox with user-controlled credential store; reject shared operator home.
  2. Add a typed provider-process protocol for capability probe, auth status, model list, run, cancel, logout, and sanitized receipt.
  3. Pin official CLI/SDK versions and generated protocol provenance; refuse incompatible versions.
  4. Give Codex a private shadow home and Claude a private CLAUDE_CONFIG_DIR; never symlink/copy auth files.
  5. Bind each process instance to authenticated Antiek owner and explicit action authority; no cross-owner process reuse.
  6. Map cost/usage only where the official process reports it; otherwise label subscription consumption unknown.

Five-values rigor

  • Intellectual honesty: a successful CLI response does not prove API billing or remaining subscription quota; receipts must say what the official process actually reported.
  • Fairness: users without subscriptions retain the API-key path; the UI must not imply subscription login is cheaper or more capable.
  • Rigor: kill, timeout, protocol drift, logout, concurrent owners, corrupted homes, and orphaned subprocesses are mandatory tests.
  • Diligence: reuse Codex app-server/Claude SDK contracts rather than reverse-engineering network requests or token files.
  • Defensibility: record upstream version, protocol schema hash, process identity, owner, model, and non-secret outcome in every receipt.

Dependencies

A decided local/per-user execution topology and provider terms compatible with that deployment. This cannot run as one shared operator login.

Out of scope

Direct REST calls using subscription tokens, copying credential stores, browser token return, or calling the harness “OAuth integration.”

Verification gates

  • Token strings never cross stdout/JSON-RPC or Antiek logs.
  • Owner B cannot address A’s process/home/session.
  • Logout in the official client makes subsequent Antiek execution refuse.
  • Cancellation kills child process groups and leaves no sandbox.
  • Operator-gated live smoke proves one Codex and one Claude action with zero credential export.

Handoff packet

Return topology decision, upstream pins/licenses, protocol fixtures, process cleanup proof, and live-smoke receipts with all secrets redacted.

Harness hint

Parallel Codex and Claude adapters only after one shared isolation contract is ratified.
