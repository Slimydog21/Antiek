Turn canonical evidence into reviewed local visuals

Second child of the cheapest local production master spec. It creates readable zero-network 1280×720 PNG source cards from current owner graph chunks, then hands exact bytes to the existing explicit diagram-attestation authority. It does not register a reviewed set or unlock cheapest production.

Canonical input

The server supplies asset, revision, chapter, scene, title, information purpose, and one through sixteen ordered source chunk IDs. The registry reads each chunk joined to its document from DuckDB, requires the authenticated graph owner, preserves source order, and binds document identity, full text digest, bounded display excerpt, section, title, and source URI. Missing, duplicate, foreign, empty, oversized, or changed evidence fails closed.

Deterministic rendering

Pillow is an explicit runtime dependency. The renderer uses a repository-owned DejaVu Sans file whose bytes are SHA-256 pinned, fixed dimensions, fixed palette, measured wrapping, bounded line counts, fixed layout, Pillow version in the renderer identity, and PNG compression without dynamic metadata. It performs no network, HTML, SVG, Mermaid, remote-font, or arbitrary-markup execution. The image visibly says Local source card and Diagrammatic · not archival.

Durability

Card identity derives from owner digest, canonical render input, and font digest. Private mode-0600 PNG publication uses a private mode-0700 directory, no-follow temporary file, fsync, and an atomic no-clobber link. A crash that leaves exact deterministic bytes but no row is adopted only after digest and PNG-shape verification. Conflicting bytes never overwrite. A MAC-protected row binds owner, asset/revision/chapter/scene, input and graph snapshot digests, renderer/font identities, dimensions, path, PNG digest, and creation time.

Review authority

Creating a source card is not approval. The authenticated owner must explicitly attest the original server-derived request. The registry reopens current graph state, file bytes, and its MAC row, then invokes attest_diagram. Downstream DiagramEvidenceAuthority independently rechecks the Ed25519 reviewer signature, authorized reviewer set, canonical graph snapshot, path, and bytes immediately before visual packet compilation.

Acceptance

  • A pinned fixture yields the exact golden PNG digest and visually readable 16:9 card.
  • Exact and concurrent creation converge on one identical private file and row.
  • Explicit owner attestation resolves through the existing graph evidence authority.
  • Chunk order/text/document/owner drift, missing evidence, changed request, font/renderer drift, DB/file/path/PNG tamper, foreign reviewer, duplicates, and excessive input fail closed.
  • Pillow is declared directly; focused and broad multimedia tests, Ruff, HTML parse, visual inspection, HardenX, and heterogeneous review pass.

Non-goals

No narration, paid provider, remote image, generic diagram language, automatic attestation, candidate route/UI, reviewed-set registration, coordinator, cheapest unlock, publication, merge, or deployment.
