Cycle 592 · corrective child spec

A budget meter must have an operator-set denominator.

The route instrument may show a proportional usage rail only when the operator configured the cap and Antiek read actual spend from the daemon ledger. The daemon’s $5 default remains a labeled operational reference, never a personal ceiling.

    Dead always-null projected-cost and over-budget fields are removed from this route-preview response. A trajectory projection returns only when a later measured estimator exists; a single prompt-price estimate cannot masquerade as a recursive investigation total.

    Underlying ledger correctness

    DaemonBudget.remaining_today() must honor its current configured cap against persisted spend. It must not return a remainder derived from a stale snapshot cap that the Settings reader then subtracts from a different display cap. Add a regression where the persisted cap changes between writes and reads.

    Acceptance gates

    1. No cap environment yields daily_cap_usd=null, cap_source=null, and the daemon-default reference in notes.
    2. Configured cap transports the exact value and source; invalid cap input remains visibly ignored.
    3. Missing/unreadable sidecar never produces zero spend or a meter.
    4. Known spend plus unconfigured cap never produces a ratio.
    5. Changed persisted cap cannot corrupt reported spend/remaining arithmetic.
    6. Route preview contains no dead always-null dollar or over-budget fields.
    7. Desktop, narrow, dark, screen-reader, focus, and reduced-motion states retain the same truth.
    8. Two heterogeneous adversarial rounds and HardenX finish with zero real findings.

    Five-values rigor

    HonestyThe $5 daemon default is operational context, never relabeled as the operator’s ceiling.
    FairnessPreserve useful known spend even when cap authority is absent; do not erase partial truth.
    RigorTest all four cap/spend authority cells plus stale snapshot-cap arithmetic.
    DiligenceReuse Settings budget vocabulary and shared reader rather than inventing route-local meanings.
    DefensibilityEvery rendered number identifies its authority; every absent meter has a text reason.

    Harness hint

    Execute inline. Refute default-as-ceiling, unknown-as-zero, stale snapshot arithmetic, dead response fields, and accidental meter rendering. Minimum two sharpen rounds.
