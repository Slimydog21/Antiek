SPR-01 — Honest budget provenance

Owner: one isolated implementation lane · Wave: 1 · Status: ready

Goal and context

Cycle 591 transported only cap and spend, dropping the shared reader’s provenance fields. With no operator cap configured, the daemon’s $5 reference could be rendered as “$5 ceiling” and used as a progress denominator.

Make every budget number on Research carry its real authority and make proportional geometry impossible without both a configured cap and known spend.

Milestones

  1. Correct remaining_today() to apply the current cap against persisted spend and add changed-cap regressions.
  2. Extend Research budget response with spend status, cap source, and notes; null the cap when it is only a default reference.
  3. Replace dead always-null projection fields with explicit unavailable status and reason.
  4. Update typed client and instrument copy; render the rail only for configured-cap plus known-spend.
  5. Add backend and ready-state UI coverage for every authority-matrix cell.
  6. Run codegen, focused regressions, build, heterogeneous review, and HardenX.

Rigor

  • Intellectual honesty: never infer “unset” from a numeric default; carry the shared reader’s cap source and note.
  • Fairness: when spend is known but cap is not configured, show the spend as daemon-tracked rather than discarding it.
  • Rigor: assert meter absence from rendered DOM in three unauthorized cells and exact ratio only in the fourth.
  • Diligence: inspect Settings’ vocabulary and all remaining_today() callers before changing shared arithmetic.
  • Defensibility: delete response fields that cannot be populated honestly; document the measurement required to restore them.

Out of scope

No prompt-sensitive route recommendation, per-key ledger, budget writes, spend reservation, model addition, NotDiamond authority, provider pricing inference, or synthesis routing.

Verification

Budget primitive tests; Settings budget API tests; route preview tests; StartResearch ready-state tests; Ruff; TypeScript; production build; diff check; visual evidence if browser attached; two sharpen rounds; HardenX strict 0 REAL.

Harness hint

Build inline and refute every ratio/copy path against the authority matrix.
