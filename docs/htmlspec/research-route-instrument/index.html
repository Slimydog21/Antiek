Cycle 591 · executable master spec

A truthful dispatch instrument for one research question.

The operator can see and choose the upstream research route, understand its model and thinking policy, and inspect the projected effect on the daily ceiling without leaving the composer. Antiek—not the browser—owns the eligible route set.

Outcome and boundary

question + route preview
        │ server-issued closed route IDs
        ▼
   operator selects lens ─── budget ledger: spent → projected → ceiling
        │ launch-time re-resolution
        ▼
 persisted start event ─── four upstream research roles

 synthesis ─────────────── independently config-pinned (unchanged)
  • No raw provider or model value is accepted from the browser.
  • Legacy callers may continue to submit research_tier; the composer submits a route ID.
  • Budget is advisory in this sprint: known values are visible, but no reservation or hard launch authorization is implied. Unknown price or ledger state is labeled unknown, never zero.
  • A stale, malformed, or unavailable route ID fails explicitly; it does not silently become a materially different explicit choice.

Acceptance gates

  1. Preview response is derived solely from the closed server map, registered providers, dispatch pricing, benchmark evidence, and budget ledger.
  2. Every response includes an opaque stable route ID plus a configuration fingerprint; no secret is exposed.
  3. POST launch accepts the route ID, re-resolves it, rejects stale/unknown/ineligible/unavailable IDs, and persists both route ID and resolved tier. Budget remains visibly advisory until a durable reservation ledger exists.
  4. The four upstream bridges consume the persisted resolved tier. Synthesis ignores it.
  5. The composer debounces prompt projections, survives preview failure with an honest retry state, and never blocks legacy launch merely because advisory preview is unreachable or loading.
  6. Keyboard, screen reader, narrow viewport, dark theme, and reduced-motion evidence passes.
  7. At least two heterogeneous adversarial reviews and HardenX report zero real findings.
