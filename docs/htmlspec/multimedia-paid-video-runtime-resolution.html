MSR-04B: Resolve authority without downgrade

Parent MSR-04

Spec lineage

    Runtime seam

    Extend the hardening runtime with a dedicated production-projection key and optional read-only backend composed from the already configured production worker/playback/registry authorities. The backend receives trusted owner, asset, revision, and one captured time; it returns only ProductionByteProjectionV1. It exposes a key-independence assertion for authority keys hidden inside the backend.

    Order

    1. Load authenticated current record and capture one time.
    2. Build direct snapshot. Conflict stops.
    3. If direct is valid and current video production exists, require the backend and build the projection at the same time. Unavailable or conflict stops; neither falls back.
    4. If direct is valid and current audio production exists, return stable unsupported byte-closure failure.
    5. If direct is valid and no production link exists, preserve the pre-production direct path.
    6. Only direct unavailable may select the current asset's local backend. Local evidence still proves its exact registered run and provider-row absence.

    Configuration

    Production key is pairwise distinct from execution, direct-snapshot, and local-zero keys. The production backend additionally rejects equality with narration and other internal authority keys. Incomplete optional production configuration fails at startup; it never silently disables a registered paid path.

    HTTP

    Missing asset is 404; absent route runtime is 503; unavailable/conflict/unsupported closure is stable 409 without paths, keys, identities, rows, receipts, or raw exceptions.

    Out of scope

    No request body, provider call, reconciliation, settlement, recovery, render, registration, routing mutation, or publication.
