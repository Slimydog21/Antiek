MSR-03A: Registered Local Video Authority

Parent MSR-03

Spec lineage

Leaf sprint under MSR-03.

    Contract

    Add a public read-only backend on the configured local video coordinator. From authenticated owner, asset, and exact current revision only, discover exactly one terminal registered video row and its referenced narration row. Verify both row shapes and MACs, deterministic run IDs, current config digests, executable identities, owner/asset/revision, and exact row-role linkage.

    Receipt and link closure

    • Require narration status narration_succeeded and video status registered.
    • Reopen the narration artifact and educational-video receipt with existing integrity keys and bounded private-file readers. Match row digests, narration identity, receipt identity, render/audio/video hashes, chapter IDs, dimensions, duration, and the current MultimediaProductionLink.
    • Return an immutable internal authority value containing no raw key and no caller assertion. Re-read terminal rows and the production link after receipt verification; any change rejects the result.

    Refusals

    • Missing database/table/row, zero or multiple eligible rows, nonterminal state, missing artifact, or unsupported old row is evidence_unavailable.
    • MAC, deterministic ID, role linkage, config, executable, owner, revision, digest, receipt, nested artifact, byte, or link contradiction is evidence_conflict.

    Acceptance tests

    • Registered full video chain reopens and identifies both run roles.
    • Missing table does not create a database or take a write lock.
    • Duplicate registered row, missing narration row, wrong narration reference, incomplete state, bad MAC, changed executable, stale revision, receipt tamper, media tamper, and link drift fail closed.
    • Existing production/recovery/register behavior remains unchanged.

    Files

    substrate/multimedia/local_production_coordinator.py and focused coordinator tests. Do not edit audio, hardening, provider accounting, or report schemas.

    Five-values rigor

    The two-row cardinality and deterministic references make the video provenance non-substitutable; every retained field closes a specific replay or identity ambiguity.

    Out of scope

    No production, recovery, schema creation, provider query, evidence signing, hardening, or float-cost migration.

    Harness hint

    One builder implements the read seam; a different lineage mutates each row, artifact, receipt, executable, and link boundary.
