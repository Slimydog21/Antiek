ResearchArtifact workstation view

Starting tip: exact 7105b5cbb. Lane: private Profile-B artifact consumption and canonical note persistence only.

Contract

The existing export remains the sole mutation. Its response adds the canonical view_url. A new GET reads only artifact_path_for(investigation_id); it accepts no path body or path parameter and performs no write, regeneration, import, or graph mutation.

The GET uses lstat and rejects missing files, symlinks, non-regular files, link counts other than one, files above 2 MiB, and invalid UTF-8. The opened descriptor is revalidated against the lstat device/inode to close replacement races. Unsafe states are indistinguishable as a 404.

The add-note control keeps its immediate DOM update and sends its parent a versioned, 20,000-character-bounded message containing only investigation_id, note text, and the rendered artifact's expected content hash. POST /research/{id}/artifact/notes accepts those two mutable values, never HTML, path, or view_url. The substrate reopens only the canonical path without following links, validates v2 identity and optimistic hash, append-only deduplicates, atomically replaces a private 0600 rendering using a synced same-directory temporary file, and only then records the existing agent-note event. Graph findings remain authoritative and untouched.

Workstation behavior

The existing ArtifactOutlineShelf export action exports first, then opens window kind research_artifact. Its stable ID is win:research_artifact:<investigation_id>, so the existing window store focuses a repeated open rather than stacking duplicates. The window-native host renders the canonical artifact in an iframe. Profile-B inline copy and note scripts remain intentional and enabled, but the opaque iframe origin cannot exercise API-origin authority.

The parent alone performs the typed authenticated API call. It shows concise saving/saved/error state and reloads the canonical iframe after success so the next message carries the new current hash. A stale hash is a stable 409 and does not overwrite newer artifact state.
