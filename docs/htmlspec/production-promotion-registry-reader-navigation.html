Production Promotion Registry and Reader Navigation

Outcome

A configured Antiek deployment can serve current owner-reviewed insights and questions from the canonical twin reader without accepting authority from the browser. Unconfigured production remains mounted but unavailable.

Startup Authority

  • One optional environment variable names one canonical private manifest.
  • Absence means disabled; presence makes every schema, owner, path, and 32-byte review verification key mandatory.
  • Duplicate or unknown fields, weak manifest permissions, partial owners, duplicate owners, missing files, owner/key mismatch, path aliases, links, and inode conflicts abort startup.
  • The complete registry is published only after every owner qualifies.

Discovery

  • The canonical twin response links to GET /reader/sources/{source_asset_id}/reviewed-promotions?source_hash=....
  • Authentication supplies owner identity; the request cannot supply owner, paths, keys, text, graph rows, or citations.
  • The promotion ledger enumerates at most 32 signed accepted candidate hints for the exact source revision in deterministic candidate order.
  • The existing current-authority reader revalidates every hint against signed review, canonical twin, current evidence and rights, graph node, and normalized citations.
  • Every accepted hint must prove current or the whole collection returns private 503. Overflow, stale history, or integrity failure never produces a partial response; an exact revision with no accepted promotions returns an empty complete collection.

Consistency

The complete collection is assembled while the graph coordinator excludes sanctioned graph and promotion mutation. Promotion history is append-only; canonical twin bindings are immutable. Registry identities are checked before opening and after projection. This is a coordinated read window, not a distributed transaction claim.

Privacy

Session-cookie or configured bearer identity only. Unverified Cloudflare identity remains rejected. Success, authentication failure, validation failure, method mismatch, namespace miss, not-found, and unavailable responses are private and no-store.

Acceptance

  • Empty configuration preserves private 503.
  • A complete private manifest activates the exact owner runtime.
  • Partial and permissive manifests fail closed.
  • Canonical reader navigation is URL encoded and revision bound.
  • Current summaries link to citation-bearing detail; wrong owners cannot enumerate; stale rows fail the whole collection; overflow never truncates silently.
  • Focused and coupled tests, strict typing, Ruff, HTML parsing, HardenX, and hostile review pass.

Deferred

No public sharing, review mutation, cursor pagination beyond the bounded complete collection, embedding or provider qualification, live spend, merge, deployment, or production data mutation.
