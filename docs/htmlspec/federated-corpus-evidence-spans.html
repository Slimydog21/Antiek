Bounded evidence spans—not full documents—enter research context

The operator mounts reviewed durable corpora, searches the federation, coherently fetches ranked hits, and projects each document into a deterministic character-bounded span. Every span carries its qualified corpus ID, exact offsets, source provenance, acquisition time, rights class, and an honest source tier.

Context safety

  • At most 1–50 spans; each is 200–4000 characters. Span IDs bind qualified ID, full-content digest, and exact offsets.
  • A search hit that cannot fetch is a contract failure, never silently omitted.
  • S2, OpenAlex, and CORE are aggregators and conservatively receive source tier 5.
  • Chunks output uses the live ### chunk_id: span_… format repaired by PR #839.
  • Source text is JSON-string encoded on one physical line, so embedded headings, brackets, controls, or prompt prose cannot mint canonical chunk IDs.
