Search tools + public resource

search_personal + search_public tools. Public notes resource with attribution metadata. BM25 search over substrate.

Wave 2 ~4 days

Parent context

Antiek Memory exposes a user's personal graph to external LLMs. This sprint adds the two search tools (personal + public) and the public notes resource. Search uses existing BM25 from substrate/graph/search.py.

Goal

External LLMs can search a user's personal notes and the public graph via MCP tools, with attribution metadata on public results.

Technical milestones

1
search_personal tool

BM25 search over user's personal notes. Returns ranked results with relevance scores.

Acceptance criteria
  • Query returns matching notes ranked by relevance
  • Empty query returns typed error
  • Results include note_id, title, snippet, score
services/mcp_server/tools.pytests/test_mcp_tools.py
2
search_public tool

BM25 search over public graph. Returns results with attribution-routing metadata.

Acceptance criteria
  • Query returns public notes with attribution metadata
  • Results include ip_holder_id, content_class
  • Retrieval-time gating respected (§9.0)
services/mcp_server/tools.py
3
Public notes resource

antiek://public/notes/{note_id} — read-only with attribution-routing metadata. All writes through public-notes pipeline.

Acceptance criteria
  • Public note returns content + attribution metadata
  • Read-only (no write through resource)
  • Gated notes return licensing-required error
services/mcp_server/resources.py

Rigor

Search results cite actual substrate data — no fabricated matches.

Rigor
