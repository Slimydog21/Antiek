Citation + attribution tools

cite_source + record_attribution tools. Attribution event capture at agent step. Books resource with retrieval-time gating.

Wave 2 ~4 days

Goal

External LLMs can cite sources and record attribution events at the agent step that consumed the content. Books resource respects retrieval-time gating per §9.0.

Technical milestones

1
cite_source tool

Cite a source from the substrate. Returns formatted citation with provenance chain (chunk → document → ip_holder).

Acceptance criteria
  • Returns citation with chunk_id, document_id, ip_holder_id
  • Missing source returns typed error
  • Citation format includes title, author, date
services/mcp_server/tools.pytests/test_mcp_tools.py
2
record_attribution tool

Capture attribution event at the agent step that consumed the content. Not after the fact — this is what makes rev-share work end-to-end across the MCP boundary.

Acceptance criteria
  • Attribution event written to substrate event log
  • Event includes source_id, consumer_id, timestamp
  • Idempotent (same source+consumer+timestamp = no duplicate)
services/mcp_server/tools.py
3
Books resource

antiek://books/{isbn}/{chunk_id} — per-publisher licensing state. Returns chunk OR licensing-required error per §9.0 retrieval-time gating.

Acceptance criteria
  • Public-domain book chunk returns content
  • Gated book returns licensing-required error
  • chunk_id resolves to correct text segment
services/mcp_server/resources.py

Rigor

Intellectual honesty

Evidence-calibrated

Attribution events are real substrate writes — not simulated. If the write fails, surface the error.

Rigor

Mechanical gates

Diligence
