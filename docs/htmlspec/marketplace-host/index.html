Book marketplace + seamless host-into-account

When no free PDF/HTML exists, the operator may buy a digital book and have it hosted in their Antiek account as an HTML-first reading asset. Public-domain connectors already exist under acquisition/books/; this package adds purchase-intent → ingest → HTML projection → library membership.

Seams

  • acquisition/books/* PD connectors + ingest_servable_book
  • tools/marketplace/programmatic_gate.py
  • interfaces/research/api/books.py + library routes
  • services/html_projection + engagement spine for reading interaction

Acceptance bars (master)

  1. Catalog search returns PD + purchasable stubs with license class explicit.
  2. Host-into-account path: bytes or licensed URL → staging ingest → live document_id owned by account → HTML view via projection (PDF ingest source OK; view is HTML).
  3. Purchase adapter is a pluggable protocol; default is ManualPurchaseReceipt (operator pastes proof) — no Stripe requirement for first ship.
  4. Idempotent: same content hash → same document_id; no double-host.

Non-goals

  • Full commercial payment rails, publisher legal contracts, DRM circumvention.
  • Self-hosting DRM-locked Kindle binaries as first-class (out of bounds without legal path).

Ordered sprints

  1. SPR-01 — Catalog entry + license class
  2. SPR-02 — Host-into-account ingest + HTML view
  3. SPR-03 — Purchase receipt adapter (manual first)
