Deep Research Mission Control

Base: goal/curiosity-observatory@8407d07f1. Owner: deep-research-mission-control.

Authority

  • Existing research APIs own plan creation, editing, approval, launch, session status, steering, cost, and terminal state. This sprint changes no backend or authority.
  • The generated environment is decorative architecture only. Problems, plans, questions, status, spend, results, actions, and errors remain live HTML.
  • The existing single shell Werner remains authoritative. This surface does not render a second mascot or make Werner follow the pointer.

Behavior

  • One synchronous operation fence prevents duplicate create/edit/approve/launch requests before React commits busy state.
  • Unmount and monotonic operation generations suppress stale completions. Successful responses alone change the plan/session.
  • Boundary failures use fixed private-safe copy and never expose provider, credential, trace, or backend exception strings.
  • Initial, creating, draft-plan, connecting, active-monitor, and failure states read as one continuous mission-control narrative without hiding any existing control.

Visual and access

  • The full-bleed polar mission-control raster crops gracefully at 1280, 1024, and 768; a veil protects readable contrast.
  • The mission header and phase badge expose state in text, never color alone. The decorative raster is pointer-inert, empty-alt, and hidden from assistive technology.
  • All existing keyboard controls remain ordinary HTML. Shared motion-safe utilities only; no new ad-hoc keyframes.
  • Whole-surface Storybook fixtures cover ready, creating, draft plan, active monitor, and failure; responsive Lost-Pixel baselines prove live geometry.
