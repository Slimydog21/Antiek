MSR-01: Direct Provider Accounting Snapshot

Parent program. This sprint closes the false-authority path without pretending to solve production attribution.

Goal

Add a read-only immutable snapshot for all direct provider executions bound to one authenticated owner, asset, and exact revision; make hardening consume that snapshot; remove caller cost floats; fail closed when no supported authority exists.

Truth boundary: v1 counts all directly bound paid executions, including attempts that did not contribute selected bytes. It reports charged_cents under Antiek's settlement authority, not provider-invoice actual cost. Narration child revisions and local zero-cost paths are classified as unsupported until MSR-02/03.

Contract

  • MultimediaShipCostSnapshotV1: schema version, evidence ID, owner identity digest, asset ID, revision ID, generated-at cutoff, basis direct_settled_provider_executions, canonical execution rows, charged-cent total, snapshot MAC.
  • Each row: execution ID, authorization ID, provider/model/route/capability/catalog identity, execution status, charged cents, settled timestamp.
  • The evidence builder discovers rows server-side. Empty closure raises typed evidence_unavailable; it never yields local zero.
  • One DuckDB read snapshot verifies execution MAC, authorization signature, succeeded status, settled claim and timestamp, settled call hold, exhausted reservation, nonnegative bounded cents, exact owner/asset/revision, and cutoff.
  • Canonical sort and unique execution IDs make replay deterministic. Snapshot MAC covers every field except itself.

Hardening integration

  • Delete budget_usd and actual_cost_usd from evaluate_multimedia_asset.
  • Require cost_snapshot. Missing/invalid evidence produces a failed cost_and_budget gate with a stable code; manifest rows cannot pass it.
  • Embed the immutable snapshot in MultimediaHardeningReport. Legacy reports parse with no snapshot but are non-authoritative.
  • API runtime supplies DB path, signing key, snapshot key, and clock. Missing runtime returns 503; unavailable or contradictory evidence returns 409. No request accepts cost or execution identifiers.
  • The report remains manual_review when all automated gates pass because rights/publication remains manual.
