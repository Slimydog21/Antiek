MSR-03D: Immutable Local Zero Evidence

Parent MSR-03

Spec lineage

Leaf sprint under MSR-03.

    Contract

    Define a strict, frozen LocalZeroExternalCostEvidenceV1 signed by an independent snapshot key. This is a third evidence label, not an empty paid projection. It is generated at one current UTC cutoff and asserts only zero external provider charge for the verified local production path.

    Schema

    • Identity: evidence ID, owner digest, asset, exact revision, generated cutoff, run kind video or audio, and basis local_registered_zero_external_provider_charge.
    • Authorities: video has exactly local_narration plus local_video; audio has exactly one local_audible. Each row records run ID, input digest, config digest, terminal status, artifact/receipt digest as applicable, and updated time.
    • Production: exact receipt digest, canonical current-link digest, excluded revision IDs, provider_execution_count=0, external_cost_cents=0, limitation text, and snapshot MAC.
    • Evidence ID hashes every unsigned field. Snapshot MAC covers the evidence ID and every payload field. Keys must be independent from coordinator and receipt keys.

    Verifier

    • Verify schema, identity, cutoff, sorted unique scope, exact role cardinality, deterministic run IDs, terminal statuses, all digest shapes, literal integer zero fields, evidence ID, and MAC.
    • The immutable verifier does not reopen live state. The builder owns live authority; the verifier proves the signed envelope and caller identity bindings.

    Acceptance tests

    • Video and audio evidence sign and verify with exact role sets.
    • Wrong key/owner/asset/revision, float zero, nonzero cost/count, missing/duplicate role, unsorted/duplicate scope, changed digest, cutoff, evidence ID, or MAC fails.
    • Paid snapshot and production-byte projection models remain byte-compatible and reject this basis.

    Files

    substrate/multimedia/local_zero_cost_evidence.py, exports, and focused schema/builder tests. Consume 03A/03B authority values and 03C exclusion; do not duplicate their readers.

    Five-values rigor

    The schema's type-level zero, exact role cardinality, explicit scope, and separate basis make its meaning hard to vary or accidentally merge.

    Out of scope

    No persistence ledger, historical reconstruction, live-state verification in the envelope verifier, paid constituent rows, or local economic valuation.

    Harness hint

    Build strict models and live builder separately, then synthesize through mutation tests.
