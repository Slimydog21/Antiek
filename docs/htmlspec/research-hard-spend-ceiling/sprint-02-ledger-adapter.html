ANT-RHC / sprint 02

Durable research reservation adapter

Owner: budget-ledger agentWave 17 milestonesStatus: proposed

Parent context

Antiek already has strong reservation semantics in substrate/midnight_oil/budget_ledger.py: atomic holds, per-role allocation, settlement, release, and event history. Cascade research currently uses an in-memory BudgetManager that charges realized floating-point USD after work.

This sprint creates a research-owned interface around the proven transaction primitive. It preserves product boundaries: research does not inherit Midnight Oil's role allocation, run timing, or automatic lifecycle.

Goal

Persist integer-cent run ceilings and atomic call holds so concurrent cascade workers can never reserve more than approved headroom, with replay-safe settlement/release and append-only evidence.

Technical milestones

  1. Choose reuse seam. Extract a product-neutral core only if Midnight Oil behavior remains identical; otherwise use a narrow research adapter. Acceptance: decision and differential tests are checked in. Files: substrate/research_spend/ledger.py and, only if justified, substrate/midnight_oil/budget_ledger.py.
  2. Persist authority. Add run, hold, and event records with owner, session/plan binding, fixed USD, ceiling, authorized spent, observed provider spend, held, status, timestamps, and opaque IDs. Acceptance: database constraints reject negative values, non-USD runs, and invalid states. Files: substrate/research_spend/ledger.py and its schema migration.
  3. Reserve atomically. Verify active binding and conditionally update ceiling - authorized_spent - held >= projected_max in one immediate transaction. Acceptance: separate-connection races cannot over-reserve. Files: substrate/research_spend/ledger.py, tests/test_research_spend_ledger.py.
  4. Handle free calls explicitly. Append an idempotent zero-cost attempt receipt in prepared, then transition it to completed or failed; replay of prepared resumes the same bound local operation and never claims completion early. Acceptance: free/local calls are auditable and never mutate held/spent balances. Files: substrate/research_spend/ledger.py, tests/test_research_spend_ledger.py.
  5. Settle, release, and breach idempotently. Within one transaction, known actual within hold decrements held by projected maximum and increments both authorized and observed spend by actual. Above-hold actual decrements held by projected maximum, increments authorized spend by only that projected authorized maximum, increments observed spend by the complete actual charge, and marks ceiling_breached; no excess becomes authorized and no resolved hold remains. Unsent failure decrements held and records release. Acceptance: replay is stable, changed intent conflicts, and all balances remain honest. Files: substrate/research_spend/ledger.py, tests/test_research_spend_ledger.py.
  6. Model unsent, unknown, and execution-closed outcomes. A reserved hold with no send marker is provably unsent and may atomically release or resume exact intent after restart. Sent/unknown holds remain fully held. Cancellation closes execution to new work; closed_unresolved still permits evidence-only reconciliation, transitioning to closed_reconciled after the last hold settles/releases. Acceptance: timers or abandonment never restore ambiguous headroom. Files: substrate/research_spend/ledger.py, tests/test_research_spend_ledger.py.
  7. Prove crash/replay/concurrency. Acceptance: multi-connection races and injected failures at every commit boundary preserve authorized invariant and observed accounting after reopen. Files: tests/test_research_spend_ledger.py.

Five-values rigor

Intellectual honesty

Do not call a Python lock durable or cross-process safe. Demonstrate the invariant with separate database connections and restart tests.

Fairness

Preserve Midnight Oil's behavior if extracting shared code; run its existing ledger suite unchanged and report any semantic divergence before proceeding.

Rigor

Assert authorized_spent + held <= ceiling after every operation and injected crash point while separately asserting complete observed provider spend. Idempotency keys bind all material intent fields, not just a caller-chosen request ID.

Diligence

Cover zero-cent calls, exact-headroom holds, overflow, malformed values, stale approval revisions, duplicate settlement, changed-intent replay, closure with unknown holds, and migration rollback.

Defensibility

Provide a state-transition table and transaction pseudocode in the handoff. A reviewer should be able to identify the single database statement that prevents over-reservation.

Dependencies

No implementation dependency on SPR-01. Coordinate only on the immutable hold fields. Existing Midnight Oil ledger tests must remain green.

Out of scope

No pricing/projection, provider calls, browser/API exposure, automatic unknown-hold release, exchange rates, mixed-currency runs, refunds, per-leaf allocation policy, or migration of historical float-based accounting.
