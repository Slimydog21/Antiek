Open a multimedia twin as verified HTML

Stacked on PR #1201. Turn the displayed twin identifier into an owner-bound human-readable information asset without creating a generic graph-document escape hatch.

Backend authority

The route reopens the current owner asset and its exact knowledge link, then reads only that linked twin row. It verifies current asset/revision, source and twin document identities, graph owner, document type, personal-reading content class, source URI, title, source/twin investigation equality, exact metadata, bounded raw HTML, SHA-256, and script-free projection before returning bytes.

Failure model

Foreign owner, absent link or row, stale revision, detached source, wrong graph owner/type/class/URI/title/investigation, malformed metadata, digest drift, oversized HTML, or active content produces no readable twin. Missing and foreign twins are opaque 404; integrity disagreement is 409.

Browser boundary

The client cross-binds asset, revision, source document, twin document, and digest to the already displayed knowledge link. It renders only a matching response in an iframe with an empty sandbox token set, so the document receives no scripts, forms, navigation, popups, or same-origin authority. Asset or revision change closes the viewer.

Acceptance

  • Finalized owner opens exact twin HTML.
  • Unfinalized and foreign assets are opaque.
  • Each graph-row and link tamper fails closed.
  • Client rejects cross-asset, cross-revision, cross-document, or cross-digest responses.
  • Viewer is titled, closable, bounded, and scriptless.
  • No model/provider call, publication, generic document reader, merge, or deploy.
