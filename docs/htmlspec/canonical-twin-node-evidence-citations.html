Canonical Twin Node Evidence Citations

Cycle 117. Give reviewed twin insights and questions normalized, ordered, owner-private provenance without pretending documents or chunks are graph nodes.

Authority

Citations are a hash-only DuckDB projection committed in the same transaction as the node. They are not independent truth or serving authority. Every reusable view must reopen the pinned signed promotion and revalidate the canonical twin, source evidence, rights, takedown state, node projection, and citation projection.

Schema

  • Ordinal zero names the canonical twin document and chunk with its exact chunk hash.
  • Ordinals one through sixteen preserve owner-reviewed evidence order, document/chunk IDs, exact character range, excerpt/chunk/document/envelope hashes, and rights class.
  • Rows contain no source or excerpt text and use soft references so legal deletion is never blocked.
  • Deterministic IDs and uniqueness by node plus ordinal make replay exact; any conflicting pre-existing projection aborts the node transaction.

Failure Contract

Absent, foreign, stale, taken-down, malformed, incomplete, substituted, or path-replaced authority returns the same historical_withheld shape. Historical node and citation rows remain available only for audit and cannot authorize reuse.

Acceptance

  • Node and all citations commit or roll back together; replay writes nothing new.
  • Current reads verify exact ordered rows while one promotion snapshot remains pinned.
  • Foreign owners, missing rows, field substitutions, evidence drift, takedown, and late failure fail closed without disclosure or deletion.
  • Coupled tests, strict typing, Ruff, HTML parsing, security scan, and independent hostile review pass.

Deferred

No graph-edge vocabulary change, HTTP/UI, public sharing, embedding/provider dispatch, production mutation, merge, deployment, or spend.
