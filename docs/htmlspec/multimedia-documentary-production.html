Produce a reviewed Ken Burns documentary

Stacked on PR #777. This sprint closes the missing production call graph between reviewed visual evidence and the real local renderer.

Contract

Compile every selection through its configured evidence authority, consume the sealed visual packet only inside the renderer callback, reopen the render artifact under its independent integrity key, then cross-check asset, revision, timeline, ordered scenes, labels, source chunks, and exact copied bytes.

Failure model

Selection drift, forged evidence, packet tamper, renderer forgery, identity substitution, timeline substitution, and input substitution fail closed. A failed render may leave a valid visual packet for an explicit retry; it never creates a successful production artifact.

Non-goals

No provider routing, generation, graph mutation, HTTP route, frontend, automatic publication, live spend, campaign mutation, merge, or deploy.
