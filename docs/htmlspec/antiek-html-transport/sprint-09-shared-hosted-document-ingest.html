SPR-AHT-09 · One hosted-document ingest boundary

Make Wrestle uploads and Marketplace entitlements converge on one owner-scoped canonical HTML document without making research uploads pretend to be purchases.

Gap and decision

Wrestle keeps PDF bytes in browser memory and renders PdfViewer. Marketplace stores PDF/EPUB placeholders. The missing owner is a general hosted-document application service. Marketplace policy wraps it; it does not own document format or research identity.

Ownership map

  1. acquisition/documents/extract.py owns bounded byte extraction for PDF, EPUB, HTML, and text. It returns content, title/author, source hash, extractor version, truncation, viewability, and an explicit failure reason.
  2. services/hosted_documents/ owns owner-scoped identity, idempotent admission, canonical HTML projection, extraction receipts, and read DTOs. It calls acquisition and substrate; neither lower layer imports interfaces or Marketplace.
  3. substrate remains authority for document, chunks, rights, owner, and provenance. Derived HTML never becomes an independent rights oracle.
  4. interfaces/research/api/hosted_document_routes.py binds authenticated owner identity and exposes ingest/read. Wrestle calls this API.
  5. Marketplace verifies catalog/receipt entitlement, then calls the same service with the resolved rights intent and preserves the returned document identity.

Contracts

POST /hosted-documents/ingest: base64 bytes, declared format, filename/title hint, investigation id, and intent user_owned|marketplace_entitled. Owner comes only from middleware. Response: document id, canonical content hash, source-byte hash, source event id, viewability/reason, extraction receipt, projection hash/version, title/author, page count, and HTML. GET /hosted-documents/{id}/html repeats the owner gate and regenerates pending/stale projections from substrate.

Identity and transaction invariants

  • Identity derives from owner scope plus exact source-byte hash and is shared across Wrestle, Library, Marketplace, twins, highlights, research spawns, and Write handoff.
  • The server emits document.loaded; clients never pre-emit a competing document id or content hash.
  • PDF/EPUB bytes are ingest sources only and are never returned as the reading surface.
  • Extraction below the word threshold yields a non-viewable receipt, never placeholder prose presented as book content.
  • Rights and owner scope commit before viewable HTML. Publication uses pending/ready hash acknowledgement and takedown is fail-closed.
  • Repeated identical admission is idempotent. Changed bytes create a distinct source identity; explicit revision linkage is additive.

Extraction rules

  • PDF reuses acquisition.books.reader.read_pdf and records page/TOC quality.
  • EPUB uses bounded ZIP reads, resolves container/OPF spine order, rejects traversal/encryption/zip bombs, and extracts sanitized XHTML text. Missing or malformed spine becomes an explicit non-viewable receipt.
  • HTML passes the positive allowlist; text is decoded with declared/UTF-8 fallback and bounded length.
  • Every path records source format, extractor/version, source hash, canonical hash, word count, truncation, and failure reason.

Execution slices

  1. Land extraction DTO plus adversarial PDF/EPUB/HTML/text fixtures.
  2. Land the shared service and owner-bound API with compatibility adapters for Marketplace.
  3. Remove Marketplace placeholder authority and prove purchase/free hosting uses extracted content or a receipt.
  4. Replace Wrestle PdfViewer state with server HTML ingest/read and sanitized hosted rendering.
  5. Prove highlight to floating/full research, twins, collective merge, and Write carry the same document id.

Gates

Backend: extraction adversaries, owner A/B denial, identical double-run, low-text/scanned PDF, multi-section EPUB, malformed/encrypted/oversized EPUB, Marketplace receipt mismatch, pending repair, and takedown. Frontend: no PdfViewer import in Wrestle, no client-minted document id, upload loading/error/non-viewable/viewable states, route rehydrate, sanitized DOM, highlight/research/twin/Write identity parity. Run Ruff, mypy, focused pytest, TypeScript typecheck, Vitest, build, and an independent security/convergence review.
