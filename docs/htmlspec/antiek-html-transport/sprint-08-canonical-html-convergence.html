SPR-AHT-08 · Canonical safe HTML convergence

Keep the substrate as semantic authority while requiring every human-viewed research asset and book to resolve to one safe, hash-linked, provenance-bearing HTML projection.

Why this child exists

The 2026-06-24 parent completed its narrow optional-snapshot contract. Current product authority is stronger: optional HTML, regex sanitization, PDF-primary Wrestle, placeholder-only marketplace books, stale artifact hashes, reversed compose conflicts, and raw full-text APIs are no longer acceptable.

Non-negotiable invariants

  1. Untrusted source HTML passes a positive element/attribute/URL allowlist before disk or DOM exposure.
  2. Every viewable URL, book, marketplace asset, and research result has canonical HTML; otherwise it is explicitly non-viewable.
  3. Every HTML projection binds source content hash, source event or receipt, projection version, truncation state, rights scope, and owner scope where applicable.
  4. No PDF renderer, object URL, embed, or placeholder-only document is an authoritative human reading surface.
  5. HTML editing cannot silently invalidate or bypass the declared content hash.
  6. Compose conflicts mean divergent versions of the same logical artifact, never coincidental equality across different investigations.

Wave 1 · Stored-XSS and provenance

Owning files: acquisition/snapshot/reader_html.py, URL/book adapters, snapshot tests.

  • Replace regex stripping with an offline positive allowlist.
  • Reject event handlers, active/foreign elements, unsafe schemes, malformed active content, and encoded scheme bypasses.
  • Stamp source hash, source event, sanitizer version, and truncation disclosure.

Gate: pytest -q tests/test_reader_snapshot.py tests/test_acquisition_urls.py tests/test_acquisition_books.py; Ruff and mypy on changed Python surfaces.

Wave 2 · Always-resolvable projections

  • Remove the opt-in snapshot authority for successful URL/book ingest.
  • Project low-word-count or extraction failures as explicitly non-viewable receipts, not absent paths.
  • Reject changed bodies on ignore; explicit replacement archives referenced chunks, admits one current version, and records pending/ready projection repair state.
  • Revalidate alias HTML against current substrate and rights authority on every resolution.
  • Persist rights-holder, owner scope, and servability provenance in book HTML.

Wave 3 · Reader and marketplace convergence

  • Replace Wrestle's PDF-primary viewer with ingest-to-HTML and canonical hosted-document rendering.
  • Route marketplace PDF/EPUB bytes through real extraction; placeholder-only output is non-viewable.
  • Add canonical HTML serving/linkage to the book API while preserving deny-by-default rights gates.
  • Prove highlight, recursive research, twin notes, and Write handoff use the same HTML asset identity.

Wave 4 · Artifact integrity and compose truth

  • Verify embedded ResearchArtifact JSON against its declared canonical hash before import.
  • Define a notes-only revision transition that cannot mutate graph-derived fields.
  • Version artifacts so compose can detect divergent revisions of the same investigation.
  • Render visible, machine-readable conflict receipts without flattening graph authority.

Adversarial verification

Fixtures must include event attributes, entity-encoded and control-character URL schemes, SVG/MathML, iframe/srcdoc, malformed tags, oversized sources, changed re-ingest, low-text extraction, multi-page PDF/EPUB, cross-owner rights, stale artifact hashes, and the four compose identity/hash combinations. All CI proof is offline; live acquisition and purchases remain operator-gated.
