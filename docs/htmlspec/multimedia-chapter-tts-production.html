ANTIEK / MULTIMEDIA / EXECUTABLE SUB-SPEC

Chapter TTS Production

Turn one grounded chapter into paid provider audio exactly once, normalize the returned bytes into private PCM WAV, and seal them through the existing narration-production authority.

Outcome And Boundary

Milestone boundary: version 1 accepts exactly one non-empty chapter and one signed authorization. Multi-chapter orchestration is deferred until a parent execution can reserve every chapter atomically and resume from independently sealed chapter results.

This restriction is deliberate. Sequential paid calls followed by a process crash can otherwise leave an unknowable partial bundle. The module must reject zero or multiple spoken chapters before claiming authority or invoking the callback.

Owned files are substrate/multimedia/chapter_tts_production.py and tests/test_multimedia_chapter_tts_production.py. Existing modules are dependencies and must not be modified by this sprint.

Public Contract

SymbolRequirement
prepare_chapter_tts_request(...)Normalize the plan's spoken lines, bind chapter text, voice, speed, provider, model, capability, asset and revision into canonical JSON, and expose its SHA-256 digest for authorization issuance.
produce_chapter_narration(...)Verify exact authorization fields, claim and reserve with begin_reserved_provider_submission, call the injected synthesizer at most once, normalize bytes, derive actual media facts, and invoke produce_narration_track.
ChapterTTSProductionArtifact.reopen(...)Verify schema, MAC, request identity, receipt identity, narration artifact, and every persisted file hash before returning replay authority.
get_chapter_tts_attempt(...)Return a MAC-verified durable attempt. Missing, malformed, or tampered rows fail closed.

The synthesis callback receives an immutable prepared request and returns raw audio bytes plus an optional provider request identifier. The callback does not report duration or cost; duration comes from ffprobe, while spend is settled only from independently trusted billing evidence in a later reconciliation lane.

Durable State Machine

StateDurable factAllowed next state
intentAuthorization consumed, full ceiling reserved, exact request persisted.sending
sendingSend marker committed before callback invocation.received or outcome_unknown
receivedBounded response bytes durably staged and hashed.sealed
sealedWAV and narration artifact published; replay returns persisted authority.terminal
outcome_unknownCallback raised or process recovery found stale sending; full hold charged conservatively.terminal; operator reconciliation only
No retry: any caller observing sending, received, or outcome_unknown must not invoke the provider. A stale send is quarantined, never guessed to be unsent.

The external callback must execute after the send transaction and coordinator lock are released. Concurrent callers race only on the conditional send-marker update; exactly one winner may call.

Media And Integrity

  1. Reject empty responses and responses above 64 MiB before publication.
  2. Create staging under a caller-owned absolute private directory; reject symlinks and group/world-accessible roots.
  3. Write response bytes with mode 0600; invoke absolute executable paths with argument arrays, timeouts, -nostdin, and no shell.
  4. Normalize to mono pcm_s16le WAV at 24 kHz. Probe output codec, channels, sample rate, and millisecond-rounded positive duration.
  5. Create GeneratedFile and ChapterAudio solely from normalized bytes and probed duration. paragraph_spans remains empty because chapter-level synthesis provides no word timing.
  6. Call existing produce_narration_track; publish the outer artifact only after its signed artifact reopens successfully.
