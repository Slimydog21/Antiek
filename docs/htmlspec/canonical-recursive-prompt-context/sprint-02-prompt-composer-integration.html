Parent context and goal

ContentUnit exists; this sprint proves the real research prompt receives it under a fixed budget.

Technical milestones

1 Select the one consumer.
Trace the production research prompt path; choose the existing context-pack assembly seam. Do not add a parallel prompt builder.
2 Serialize safely.
Delimit units as data, escape prompt-control syntax, label authority/kind/source, preserve exact text and ordinal; never concatenate raw metadata as instructions.
3 Enforce token economics.
Reserve system/user/evidence floors first; recursive notes consume a configured ceiling. Estimate and record proposed/actual tokens; deterministic truncation never splits Unicode or provenance pairs.
4 Emit consumption receipt.
Context-pack/dispatch event records unit IDs, digests, authority, included/excluded counts, token estimate and policy version; no private text in logs.
5 Prove downstream receipt.
Spy at actual provider/role boundary and assert exact bounded unit text is present. Red control removes context layer and must change the captured prompt.

Five-values rigor

Intellectual honesty

A context-pack event is not proof; capture the actual role/provider request before claiming consumption.

Fairness

Recursive notes cannot starve current evidence or the user’s explicit question.

Rigor

Test injection strings, Unicode boundaries, zero budget, stale refs and exact deterministic truncation.

Diligence

Use the existing ResearchRunner/context-pack path and document why it is authoritative.

Defensibility

Receipt policy/version and unit digests must replay the exact prompt layer without logging text.
