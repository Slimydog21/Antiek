Recursive feedback proof

← Master

Parent context and goal

The consumer now receives canonical units. This sprint learns which units helped without turning noisy usage into truth.

Goal: record privacy-preserving outcome receipts and use them only as advisory ranking features with replayable weekly evaluation.

Where this sits: closes the recursive loop after content and consumption are proven.

Technical milestones

1 Define outcome vocabulary.
Explicit user saved/cited/merged/followed-up, abandoned, contradicted, or no-signal. Absence is never negative evidence.
2 Bind receipts.
Link context receipt ID, unit IDs/digests, task class, model/policy version and bounded outcome; never store prompt/unit text.
3 Build advisory rank feature.
Time-decayed, per-task and diversity-aware; cannot change canonical content, rights, owner scope or evidence validity.
4 Guard feedback poisoning.
Rate bounds, account isolation, minimum samples, outlier caps, no self-reinforcing synthetic signals, and opt-out deletion semantics.
5 Weekly replay report.
Compare baseline versus advisory ranking on blinded historical sessions; report uncertainty and never auto-promote policy.

Five-values rigor

Intellectual honesty

No-signal is unknown, not failure; report confidence intervals and sparse task classes.

Fairness

Diversity and contradiction units cannot be buried solely because familiar notes receive more clicks.

Rigor

Poison, replay, time-decay, deletion and cross-account isolation require explicit red controls.

Diligence

Reuse Antiek-bench judged-evidence patterns without granting the benchmark dispatch authority.

Defensibility

Every ranking change carries policy version, evidence window, sample count and human promotion decision.

Dependencies

Upstream

SPR-02 consumption receipts accepted.

External

Antiek-bench replay patterns, without dispatch authority.

Out of scope

Automatic benchmark rewrite, model router authority, canonical note edits, public analytics.

If tempted: keep feedback advisory and log the proposed expansion.
