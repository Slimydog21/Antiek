MSR-02B: Selected Visual Closure

Parent MSR-02

Spec lineage

Leaf sprint under MSR-02.

    Contract

    Open the one owner/asset/revision reviewed set through its MAC-verifying registry. Require ordered equality between each selection and final receipt packet row for scene ID, SHA-256, visual label, and source chunks. Emit the retained execution ID only for ai_generated selections.

    Refusals

    • Missing registry row, invalid MAC, changed reviewed bytes, count/order/scene/hash/label/source mismatch, duplicate generated execution ID, or a generated selection missing either execution or artifact receipt identity.
    • Never derive an execution ID from a filename, candidate ID, path, provider search, or revision-wide query.

    Tests

    • Mixed generated and sourced rows emit only generated executions.
    • Every equality dimension has an independent negative test.
    • Duplicate execution attribution and malformed selection classification fail closed.

    Out of scope

    Rights approval remains manual. Provider settlement is MSR-02D.

    Five-values rigor

    Generated spend and sourced rights remain different categories even when their bytes share one render.

    Harness hint

    Classify exact matched rows, return identifiers only, and test mixed media.
