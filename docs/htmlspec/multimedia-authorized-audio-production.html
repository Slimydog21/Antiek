Antiek Multimedia / Cycle 19

Produce paid Audible lessons

Close the executable gap for balanced and highest-quality audio without weakening the separate cheapest-local lane.

Outcome

An authenticated owner can turn one current, ready, exactly grounded audio revision plus a complete signed chapter-authorization set into a private verified WAV, a paid-audio receipt, a durable audio production link, and reopenable playback.

Permanent separation

  • cheapest remains local-only and is rejected before paid synthesis.
  • The paid receipt has a distinct schema and contains a MAC-verified NarrationProductionArtifact; it never claims cost_usd=0 or embeds LocalAudibleProductionArtifact.
  • Video continues through reviewed visuals and the educational-video receipt. Paid audio requests no visual authority.

Stage order

  1. Load the authenticated owner, exact current revision, ready audio kind, and non-cheapest route.
  2. Transform the exact-extract plan with the existing Audible signposts, remember beats, recaps, and learned-claim authority.
  3. Re-prepare every chapter request from that transformed plan and verify the complete ordered signed authorization set.
  4. Reload owner-scoped, non-taken-down canonical graph chunks and verify document identity, whole-chunk digest, and UTF-8 spans before any provider callback.
  5. Run the existing durable narration orchestrator. Exact retries reopen sealed narration and perform no second callback.
  6. Issue a private paid-audio receipt binding owner digest, asset, revision, transformed-plan digest, narration artifact, ordered chapters, retention markers, learned claims, source authority, and timestamp.
  7. Recheck the current revision, reopen verified playback from the receipt, and attach the existing audio production link.

Receipt and playback

  • The receipt independently reopens narration MAC and every bound audio byte.
  • Chapter IDs and durations equal narration source order and total duration.
  • Learned claims equal exact factual transformed lines and retain source chunk IDs plus deterministic follow-up prompts.
  • Playback cross-binds owner digest, asset, revision, receipt digest, audio digest, byte size, duration, chapter IDs, retention count, learned-claim count, and source count.
  • Receipt files and media remain private, bounded, regular, non-symlinked, digest-verified, and atomically published.

HTTP and workstation

  • POST /multimedia/assets/{asset_id}/audio-production accepts the same bounded chapter authority body as video production and returns only the current asset record.
  • Balanced/highest-quality audio displays Produce audio lesson only after all spoken chapters have current authorities.
  • The command never requests reviewed visuals. Success reopens the paid audio playback projection.
  • Steering continues to invalidate the audio production link and requires fresh authorization.

Acceptance

  1. Balanced and highest-quality grounded audio produce real verified playback and a current audio link.
  2. Exact retry returns the same receipt/link with zero additional synthesis callbacks.
  3. Foreign, stale, unready, video, cheapest, legacy-grounded, unsourced, incomplete, duplicate, reordered, expired, tampered, wrong-body, wrong-provider, or wrong-model requests fail before synthesis.
  4. Canonical text, document, ownership, or takedown drift fails before synthesis.
  5. Receipt, narration MAC, media bytes, path, owner, revision, plan digest, chapter order, learned claim, source authority, or timestamp tamper fails closed.
  6. Paid audio never enters local-zero evidence; settled provider closure remains the cost authority.
  7. Focused and broad tests, frontend typecheck/build, Ruff, HTML parse, HardenX, and independent review pass.

Non-goals

No new TTS provider, no automatic fallback, no visual generation, no route mutation, no invoice claim, no knowledge-finalization mutation, no publication, and no merge without operator order.
