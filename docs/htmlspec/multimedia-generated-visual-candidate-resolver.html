Resolve final visual choices from signed state

Child of the visual review spec. This removes the private static JSON catalog from reviewed-set registration and derives every generated candidate from durable authorization, execution, quarantine, and reviewer records.

Authority chain

  1. Load the candidate by server-issued ID and verify its MAC.
  2. Reopen the signed provider execution and require a successful Krea result bound to the authenticated owner, asset, and current revision.
  3. Resolve the execution authorization ID through an owner-scoped, bounded scan of MAC-protected visual authorization rows; verify the embedded authorization signature and recover its exact chapter and scene.
  4. Reopen the MAC-protected quarantine receipt and verify private regular-file bytes.
  5. Construct a generated selection from server records and require an authorized Ed25519 provenance attestation through VisualEvidenceAuthority.
  6. Pass the proven selection to the reviewed-set registry, which independently snapshots and digests it.

Runtime

Startup requires reviewed-set storage/integrity authority, visual authorization database/signing authority, provider execution database/signing authority, operator verification key, evidence authority key, and a non-empty reviewer allowlist. Configuration is all-or-nothing. CATALOG_PATH is no longer an authority mode.

Plan binding

Scene IDs are opaque plan identifiers, not a naming convention. Registration proves that the scene belongs to the requested chapter and that scene and chapter grounding chunks agree. Public receipts recover chapter IDs from the current plan relationship.

Failure contract

Foreign owner, stale revision, wrong chapter, incomplete execution, missing receipt, missing attestation, unauthorized reviewer, altered MAC/signature, changed bytes, or ambiguous plan binding is unavailable to the caller. Infrastructure failures remain service-unavailable and do not leak provider or storage internals.

Non-goals

No Krea call, polling, download, preview, automatic attestation, aesthetic scoring, browser-supplied paths or digests, rendering, publication, merge, or deploy.

Done bar

Real signed-chain tests and tamper tests pass, the complete multimedia suite remains green, lint and HTML parsing pass, security review reports no real finding, and an independent heterogeneous critic accepts the change.
