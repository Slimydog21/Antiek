Graph-backed diagram evidence authority

Stacked on PR #774. A diagram is renderable only after an operator signature binds its exact private path and bytes to an ordered snapshot of canonical graph chunk IDs, owning document IDs, and text digests.

Runtime

The resolver holds the public verification key, re-reads every chunk, preserves source order, and refuses missing, changed, empty, duplicate, unbounded, or malformed graph evidence. Non-diagram selections delegate unchanged to the accepted #774 authority.

Non-goals

No diagram generation, graph mutation, network, model inference, routes, frontend, spend, publication, or automatic rights decision.

Verification

Test signature and reviewer failures, chunk text/document/order/deletion drift, file/path/symlink/tamper, exact and conflicting races, fallback delegation, Python 3.11 parsing, stacked multimedia compatibility, strict types, hardenx, and independent refutation.
