Authorize one exact generated documentary visual

Child of the reviewed-visual and authorized-production specs. This sprint closes the authority gap before Krea submission; it does not spend.

Five values

  • Server derivation: current owner asset, revision, chapter, storyboard intent, route tier, model, dimensions, seed, catalog, and recovery terms are trusted server inputs.
  • Explicit spend: the operator supplies only request ID, expected revision, chapter, acknowledged ceiling, and TTL.
  • Atomic replay: signed quote and V2 authorization are created and stored in one transaction; exact replay is byte-identical across clock changes.
  • Grounding: the scene and source chunks must exactly match the current plan.
  • Separation: authorization is neither submission, generation, quarantine, review, nor production.

Canonical request

One spoken chapter maps to its canonical storyboard scene and an Imagen3Request. Balanced uses 1280x720; highest quality uses 1920x1080. The seed is deterministically derived from owner, asset, revision, chapter, and scene. The prompt states that the image is generated and not archival and carries the plan's educational visual intent and information purpose.

Authority transaction

The registry validates ready video state, non-cheapest route, current revision, spend acknowledgement, configured maximum, chapter/scene uniqueness, and exact source-chunk grounding. It prepares pinned Krea bytes, issues a signed quote and V2 authorization with the same issuance/quote-expiry authority, HMACs the complete row, and commits once. Reusing request ID with changed terms conflicts.

HTTP

POST /multimedia/assets/{asset_id}/visual-authorizations is owner-authenticated. The response includes chapter/scene, dimensions, seed, prepared digest, signed quote, and signed V2 authorization. It contains no signing key, provider credential, internal path, provider URL, or mutable prompt.

Non-goals

No Krea submit/poll, candidate URL persistence, quarantine, attestation, aesthetic review, reviewed-set registration, renderer, publication, merge, or deploy.

Acceptance

Foreign, stale, unready, audio-only, cheapest, unknown/duplicate chapter, scene drift, grounding drift, excessive/unacknowledged ceiling, malformed config, and conflicting replay fail before authority. Exact replay is stable after clock movement. Database/MAC tampering fails closed. Focused and broad tests, lint, HTML parse, HardenX, and independent review pass.
