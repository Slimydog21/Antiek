Turn completed investigations into one inspectable HTML research set

Decision and external boundary

Cycle 40 does not add another simulated Bedrock authority layer. AWS exposes batch-job status, record counters, tags, and output artifacts, while billed dollars are available through billing reports at an attribution granularity that does not prove an exact synchronous final invoice for one batch job. CloudTrail can independently identify an assumed-role session, but only from a deployed account's audit trail. Exact billing and credential-provenance closure therefore require operator-owned AWS deployment evidence.

The unblocked product frontier is already substrate-backed: compose_artifacts exports deterministic self-contained ResearchArtifact HTML and detects duplicate content hashes, but it is only reachable from a CLI. The live workstation sidebar cannot select completed investigations and compose them for joint review.

User contract

  1. The operator enters selection mode from the Investigations sidebar.
  2. Only completed investigations are selectable; in-progress, failed, stopped, and session-container rows are visibly ineligible rather than silently accepted.
  3. Two through twenty distinct investigations may be selected. Selection order is explicit and is the order of the composed artifact.
  4. Compose performs no model, retrieval, provider, graph mutation, or paid dispatch. It projects existing investigation truth into HTML.
  5. Success returns a server-served HTML URL plus exact member IDs, content hashes, and hash conflicts. The client opens that URL in a new tab while retaining the current workstation.
  6. Failures retain the selection and present one actionable message. A repeated request is safe and deterministically addresses the same ordered member set.

Authority and security

  • The API derives operator identity from authenticated request state; no owner field is accepted.
  • The API validates ID count, exact string shape, uniqueness, completed lifecycle evidence, and canonical event-file containment before writing output.
  • Never return or accept arbitrary filesystem paths. Serve the composed bytes from an opaque, deterministic composition ID and use relative member links served by authenticated routes.
  • HTML escapes every label and ID. Embedded machine metadata is canonical JSON with hashes for every member and an ordered-set digest.
  • Composition does not imply synthesis, claim reconciliation, graph merge, or agreement. Equal hashes are reported as duplicate-content conflicts for operator review.

Done bar

  • Focused backend and frontend suites pass; repository-adjacent artifact and workstation tests pass.
  • TypeScript, Ruff, compileall, production frontend build, and HTML parsing pass.
  • An independent engine attempts to break authorization, filesystem containment, lifecycle validation, deterministic replay, and UI state.
  • HardenX reports zero real findings. The diff states the AWS deployment blockers without claiming production Bedrock billing or credential authority.

Explicit non-goals

No LLM synthesis across investigations, no automatic graph merge, no write-draft generation, no public sharing, no collaboration ACL, no production Bedrock qualification, and no exact invoice claim. Those require separate authority and product contracts after this deterministic review surface exists.
