OpenAlex corpus CLI

Status: implemented as an operator-reachable child of the durable publication corpus stack.

  • sync-search QUERY --yes uses the real cursor client and requires OPENALEX_MAILTO; 1–100 selected records commit atomically before success.
  • The raw per-item client cache is explicitly non-authoritative. SQLite stores canonical selected payloads with per-record digests, schema/application identity, full synchronous transactions, private paths, and integrity checks.
  • search and fetch reopen authoritative records and make no network call.
