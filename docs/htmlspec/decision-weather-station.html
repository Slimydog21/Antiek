Decision Weather Station

Transform canonical /backtest/:synthesisId from raw JSON into a visually distinctive, semantically honest evidence-aging instrument. The generated polar observatory is decorative atmosphere; native HTML owns every fact and action.

Goal and catastrophic failure

Goal: let a researcher see what changed around an archived synthesis, what changed underneath its cited evidence, and what humans later observed—without silently converting any of those facts into a verdict.

Catastrophic failure: global graph churn reads as evidence against the synthesis; absence of detected cited drift reads as proof of truth; observer outcomes become an automatic confidence score; malformed rows become raw JSON; decorative art conveys measured state.

Five-values acceptance

  1. Truth: ambient and cited change are visibly and verbally distinct; stable never means true.
  2. Legibility: no raw JSON, truncation, or color-only state; long identifiers wrap.
  3. Agency: outcome grading remains an explicit linked next act; backtest stays read-only.
  4. Restraint: one generated environment and canonical Werner; no extra mascot pose, animation spectacle, or invented meter.
  5. Continuity: existing API and route remain unchanged; presentation boundary supports deterministic Storybook.

Acceptance and proof

  • Presentational BacktestView receives deterministic state/report props; default route owns fetch and ignores stale requests.
  • Stories cover quiet weather, cited drift, outcome records, mismatch, malformed rows, loading, not-found, error, narrow, and night.
  • Behavior tests assert semantic separation, row rendering, integrity disclosure, safe fallbacks, states, and retry.
  • Focused tests, TypeScript/build, Storybook, tagged axe audit, overflow harness, security review, and merge bar run before ship; unrelated baseline blockers are recorded, never hidden.

Rejected alternatives and non-goals

Rejected: traffic-light grade (invented authority); aggregate confidence (unsupported); raw expandable JSON (illegible); art-embedded interface (inaccessible/stale); WrestleApp redesign (active ownership collision).

Non-goals: API/schema/query/scoring/cohort changes; Outcomes grading redesign; synthesis archive changes; route taxonomy; graph writes; global shell or mascot system; backend behavior.
