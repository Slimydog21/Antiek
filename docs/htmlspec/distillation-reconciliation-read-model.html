Distillation reconciliation read model

Status: Cycle 94 execution spec. Parent: Cycle 93 PR #2739 at 93eb8bbc3.

Purpose

Give an authenticated operator a truthful, redacted account of one distillation command and every approved provider hold it traversed. This is evidence for a later reconciliation decision, not authority to release, settle, retry, abandon, or contact a provider.

Authority joins

  1. Resolve operator identity only from authenticated middleware methods; local unauthenticated mode is insufficient.
  2. Load the exact command by bounded request-event ID and require complete run, chain, manifest, fallback-index, and hold correlation.
  3. Load the spend run and return 404 unless its durable owner equals the authenticated operator. Missing and foreign resources are indistinguishable.
  4. Find the owner-scoped fallback chain across bounded pagination and require exact chain and manifest digest equality.
  5. Load every append-only command hold correlation. Indices must be contiguous from zero through the command current index, and the final hold must equal the command current hold.
  6. Cross-check every hold against the same spend run and corresponding manifest route provider, model, index, and projected maximum.

Response contract

The response may expose command state, full manifest digest, run/chain IDs, budget totals, fallback index, redacted provider/model, hold state, projected maximum, settled actual cents, and evidence requirement. It must not expose prompts, provider idempotency keys, endpoints, raw receipts/evidence, rate credentials, tokens, account identifiers, or secret material.

Derived guidance

  • reserved: ledger proves no send marker; a future signed command may release it.
  • dispatch_possible or unknown: authoritative provider lookup is required; local guesses and abandonment cannot restore exposure.
  • settled or released: terminal, no reconciliation action.
  • Every response sets action_executable=false.

Failure semantics

Unauthenticated is 401. Foreign owner and missing command are value-free 404. Partial correlation, missing chain, substituted digest, noncontiguous lineage, wrong run, route mismatch, or missing hold are value-free 409. No failure response reveals which authority check failed.

Acceptance

  • Fresh and migrated command rows, owner isolation, pagination, complete lineage, every hold state, corruption, redaction, OpenAPI, and no-write tests.
  • Ruff, strict isolated typing, HTML parse, HardenX zero REAL, and hostile security/correctness review.

Next sprint

Add signed, idempotent evidence-only mutations. Reserved release requires ledger proof of absent send marker. Dispatched or unknown resolution requires a qualified provider adapter and authoritative lookup by the persisted provider idempotency identity. UX abandonment remains non-financial.
