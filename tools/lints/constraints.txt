# WHY THIS FILE EXISTS
# --------------------
# The mypy --strict gate resolves the REAL import graph, so its findings
# depend on the EXACT installed dependency set, not just on the pinned
# ruff/mypy versions. A dated baseline (tools/lints/baselines/*.json) is
# only reproducible if CI installs the same resolved set it was captured
# against. Two ways the gate can red SPURIOUSLY on clean code without this
# lock:
#   1. A MISSING extra (e.g. installing only `.[dev]`) drops an import, so
#      mypy can't see a third-party symbol's types and a baselined key
#      flips into a NEW error. Verified locally: `.[dev]`-only produced 11
#      spurious NEW mypy violations in acquisition/urls/extract.py,
#      acquisition/books/reader.py, substrate/graph/rlm_tools.py and
#      substrate/research_bridge/extractors.py — NONE a real regression.
#   2. TRANSITIVE-PIN DRIFT: a future `pip install` resolving a different
#      transitive version (numpy, torch, pydantic, …) could shadow a
#      different error at a baselined site, flipping a baselined key NEW.
#
# This `-c` constraints file removes (2): it pins the FULL resolved set the
# committed baselines were captured against, so the gate's import graph is
# reproducible. The workflow installs the full extras superset
# `.[dev,arxiv,pdf,urls,embedding,youtube,rss]` UNDER this constraint.
#
# PROVENANCE
# ----------
# Captured 2026-05-29 (origin/main @ 5413fdc) from a clean venv:
#     python3.14 -m venv .venv && . .venv/bin/activate
#     pip install -e '.[dev,arxiv,pdf,urls,embedding,youtube,rss]'
#     pip install ruff==0.15.15 mypy==2.1.0
#     pip freeze --exclude-editable   # -> this file
# In that exact environment BOTH gates were observed rc=0 / 0 NEW against
# the committed baselines (the G2 "green on HEAD" contract). Platform:
# macOS arm64 / CPython 3.14.5 (the runner is ubuntu-latest / 3.14 — see
# the residual note in tools/lints/README.md; the PR's own runner is the
# binding G2 evidence).
#
# `-c` SEMANTICS: a constraint pins the version of a package ONLY IF that
# package gets installed. Platform-conditional deps that resolve only on
# one OS (e.g. uvloop/httptools wheels) are simply not constrained where
# they are not pulled — so this file is safe to apply on ubuntu even though
# it was frozen on macOS. Version strings here exist on PyPI for both.
#
# REGENERATION (rare, deliberate): only when a pin is bumped or an extra is
# added — and ONLY together with re-capturing the matching baseline in the
# SAME PR, which (per tools/lints/README.md) may only ever SHRINK the
# baseline. Re-freeze with the command block above. Do NOT hand-edit a
# single line to chase a red: that desyncs the lock from the baseline.
